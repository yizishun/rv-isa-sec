This PR clarifies the single-step TVM creation triggered by the sbi_covh_promote_to_tvm() call. Specifically, it provides missing description of how the TSM retrieves information about the number of TVM's vcpus and the boot vcpu's program counter. It also clarifies ways to recreate VM data in confidential memory when CoVE implementation supports a dynamic memory conversion mechanism or static memory partitioning. It also updates the related description of the promote call and static memory partitioning in the deployment model 3.
