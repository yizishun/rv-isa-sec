This PR contains a number of commits over the last few weeks while working with Jamie (@jrgrimm11) to add normative rule tags in the ISA manuals for the I extension. I edited many YAML files for all the base RV32I and RV64I instructions to add normative rules to them. Also added in coverage points from the CVW project (https://github.com/openhwgroup/cvw-arch-verif) to demonstrate to them how UDB can be used to generate a test plan (CTP) instead of having a hand-written test plan that duplicates information in UDB.

In the process of adding normative rules for the I extension, since this is the first use of the normative rule tooling UDB I made many changes/enhancements to the tooling to get good results. Going forward I'll keep adding normative rules to UDB YAML files to work towards having everything in the RVI20 Profiles be covered. There should be fewer changes to the tooling and mostly just additions to existing YAML files.
