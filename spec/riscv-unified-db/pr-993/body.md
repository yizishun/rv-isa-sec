This pull request introduces schema validation and its associated tests into the backend generators. To verify correctness, we created a dedicated test suite under `backends/generators/tests` with unit tests covering valid inputs, missing top-level fields, and missing nested fields. These tests confirm that schema changes or omissions are caught early, helping maintain consistency and integrity of the data definitions. Additionally, the GitHub Actions CI workflow has been updated to automatically run these tests as part of the validation step, ensuring that future contributions are checked for schema compliance before being merged. This improves reliability, prevents schema drift, and strengthens the quality assurance process of the repository.
