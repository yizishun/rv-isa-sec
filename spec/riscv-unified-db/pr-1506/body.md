### [`v5.1.1`](https://redirect.github.com/fsfe/reuse-tool/blob/HEAD/CHANGELOG.md#v511---2025-09-05)

##### Fixed

- Fixed repository file detection using jujutsu versions 0.19.0 or later.
  ([#&#8203;1191](https://redirect.github.com/fsfe/reuse-tool/issues/1191))
- Fixed a bug that caused not all strings to be marked translatable. This bug
  was introduced in v5.0.0. Strings that were already translated *before* the
  release of v5.0.0 are now translated again. ([#&#8203;1216](https://redirect.github.com/fsfe/reuse-tool/issues/1216))

### [`v5.1.0`](https://redirect.github.com/fsfe/reuse-tool/blob/HEAD/CHANGELOG.md#v510---2025-09-04)

[Compare Source](https://redirect.github.com/fsfe/reuse-tool/compare/v5.0.2...v5.1.0)

##### Added

- Added new file extensions:
  - `.dtd` ([#&#8203;1141](https://redirect.github.com/fsfe/reuse-tool/issues/1141))
  - `.gperf` ([#&#8203;1131](https://redirect.github.com/fsfe/reuse-tool/issues/1131))
  - Erlang `.erl` and `.hrl`, leex and yecc Erlang parser generators `.xrl` and
    `.yrl` ([#&#8203;1117](https://redirect.github.com/fsfe/reuse-tool/issues/1117))
  - Elixir (`.ex` and `.exs`) ([#&#8203;1117](https://redirect.github.com/fsfe/reuse-tool/issues/1117))
  - Gleam (`.gleam`) ([#&#8203;1117](https://redirect.github.com/fsfe/reuse-tool/issues/1117))
  - Lean (`.lean`, `.olean`, and `.ilean`) ([#&#8203;1188](https://redirect.github.com/fsfe/reuse-tool/issues/1188))
- Added `--json` flag to the `supported-licenses` subcommand. ([#&#8203;1187](https://redirect.github.com/fsfe/reuse-tool/issues/1187))

##### Changed

- Revert `Cargo.lock` to uncommentable. ([#&#8203;1169](https://redirect.github.com/fsfe/reuse-tool/issues/1169))
- `reuse annotate` previously would insert a newline after a header, which is
  not always a desirable behavior. Instead of inserting a newline,
  `reuse annotate` will now respect the existing whitespace of the file where
  the header is being placed. When the license header is being added to a file
  for the first time, a space will be added after the license, but subsequent
  updates to the header will leave the whitespace alone. ([#&#8203;1136](https://redirect.github.com/fsfe/reuse-tool/issues/1136))
- Updated `spdx-license-list-data` to v3.27.0.
