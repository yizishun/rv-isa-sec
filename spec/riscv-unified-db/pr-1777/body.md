Designed to replace the handwritten [`rvtest_config.h`](https://github.com/riscv/riscv-arch-test/blob/b27b0cd9e00a35b267cebd9a0ce2a6445bc47d64/config/sail/sail-RVA23S64/rvtest_config.h) files used in ACT4.

Creates a header from a UDB config that contains all of the supported extensions (`#define EXTENSION_SUPPORTED`) and all of the param values.
