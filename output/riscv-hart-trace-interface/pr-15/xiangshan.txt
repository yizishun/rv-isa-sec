PR #15  target=xiangshan  overall=bug_confirmed
Spec: notrace[1] security inhibit must be driven by hardware security monitors (PMP, WorldGuard, secure-mode state); hardwiring it to 0 permanently disables trace security inhibition and leaks retired-instruction addresses from secure contexts
Violation: When XiangShan's trace interface implements only the legacy single-bit halted signal (wired to notrace[0]) and ties notrace[1] permanently to 0, or when the SoC-level trace sink ignores the security inhibit bit, the hart will emit full instruction trace during security-sensitive execution (e.g., secure monitor, TEE trusted applications, or PMP-protected regions), leaking retired-PC sequences, branch targets, and exception PCs of the secure context
Consequence: info_leak
Pattern: notrace\[1\].*:=.*0\.B|halted.*notrace|io_trace_halt|TraceEncoder.*halted|notrace_wire.*GND|notrace.*false\.B
