PR #77  target=xiangshan  overall=compliant
Spec: Trace encoder unconditionally emits ilastsize even when iretire==0, leaking stale internal hardware state through the debug trace port and causing trace decoders to misinterpret phantom instruction sizes.
Violation: In XiangShan RTL, the trace encoder writes a non-zero or stale ilastsize field into the trace packet while iretire equals 0. This occurs when the trace packet generation logic does not gate ilastsize on (iretire != 0), allowing whatever value sits in the hardware buffer (e.g., leftover from a previous retired instruction, or uninitialized register state) to be emitted over the trace interface.
Consequence: info_leak
Pattern: ilastsize.*(=|<=|:=).*\n(?!.*iretire|iretime)
