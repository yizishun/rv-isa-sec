PR #85  target=xiangshan  overall=compliant
Spec: XiangShan trace interface exports CSR privilege state (cause/tval/mstatus) but not CSR instruction write data values; external encoder cannot populate sdata for CSR dtype 4-6 without a hardware data path for the written CSR operand value
Violation: XiangShan exports raw trace signals (iaddr, itype, iretire, ilastsize, priv, cause, tval, mstatus) via TraceCoreInterface but does NOT export CSR write data (the value written by CSRW/CSRS/CSRC instructions) or operand data for store/atomic instructions. The external trace encoder receiving these signals therefore cannot populate sdata for CSR writes (dtype 4-6) because the written CSR data value is never forwarded out of the core. Even if the encoder implements dtype 4-6 sdata validity per the corrected spec, XiangShan's trace interface lacks the data path to supply the CSR write operand.
Consequence: info_leak
Pattern: TraceCoreInterface.*toEncoder|sdata|CSRWriteData|csr_wdata|dtype.*[4-6]|storeData.*trace|MEM._STORE._DATA.*trace
