PR #45  target=xiangshan  overall=compliant
Spec: Trace encoder auto-include logic for context/time at trap entries and privilege changes: if ctype=0 is relied upon but auto-inclusion hardware is missing, security-critical context switches become invisible in the trace stream, enabling attackers to hide privilege escalation and trap handler execution from trace-based security monitors.
Violation:
  In XiangShan RTL, the trace encoder logic fails to automatically include
  *context* and *time* fields in trace packets when reporting the 1st
  instruction of a trap handler or after a privilege change, AND the external
  *ctype* signal is held at 0 (as now explicitly permitted by the updated
  spec). This dual condition — missing auto-inclusion logic plus ctype=0 —
  causes context/time information to be silently dropped during privilege
  transitions and trap entries.
Consequence: info_leak
Pattern:
  trace.*context|trace.*ctype|auto.*include.*context|priv.*change.*trace|trap.
  *handler.*trace|context.*packet.*priv|ctype.*zero.*trap
