PR #265  target=qemu  overall=not_implemented
Spec: PR removes all mandated trap-and-zero behavior when msdcfg.SIDN is invalid, leaving QEMU without a spec-defined safe fallback; unvalidated SIDN can index into internal interrupt-domain arrays out-of-bounds, leaking interrupt state across supervisor domains.
Violation:
  When QEMU writes an out-of-range value to msdcfg.SIDN (i.e., SIDN >= number
  of implemented supervisor interrupt domains), the removed spec rules no
  longer mandate that mip.SEIP be forced to 0, that siselect/sireg and stopei
  accesses raise illegal instruction exceptions, or that
  hstatus.vgein/hgeip/hgeie be read-only zero. QEMU may inadvertently expose
  stale or uninitialized interrupt state from internal arrays indexed by the
  invalid SIDN, or allow CSR access paths that should trap.
Consequence: info_leak
Pattern:
  msdcfg.*SIDN.*write|siselect.*sireg.*SIDN|stopei.*SIDN|hgeip.*SIDN|hgeie.*SI
  DN|mip.*SEIP.*SIDN|msideip.*SIDN
------------------------------------------------------------
