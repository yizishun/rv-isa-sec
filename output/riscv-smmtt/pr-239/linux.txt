PR #239  target=linux  overall=compliant
Spec: SRL must be strictly less than RCIDLEN when SSRM=1 (and SML < MCIDLEN when SSMM=1) to prevent degenerate srmcfg range constraints; violation in M-mode firmware allows supervisor to write unbounded RCID/MCID values and escape per-VM resource isolation
Violation:
  M-mode firmware (or any msdcfg writer) sets SSRM=1 with SRL ≥ RCIDLEN, or
  SSMM=1 with SML ≥ MCIDLEN, causing the legal-value-range formula for
  srmcfg.RCID/srmcfg.MCID to produce a degenerate (empty or wrap-around)
  interval. A supervisor-mode write to srmcfg in this degenerate state yields
  implementation-defined behavior, bypassing the intended RCID/MCID resource-
  isolation bounds.
Consequence: privilege_escape
Pattern:
  msdcfg.*SSRM.*1.*SRL.*RCIDLEN|msdcfg.*SSMM.*1.*SML.*MCIDLEN|SRL\s*=\s*RCIDLE
  N|SML\s*=\s*MCIDLEN|write_msdcfg|csr_write.*msdcfg
