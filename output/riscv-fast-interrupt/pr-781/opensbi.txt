PR #781  target=opensbi  overall=potential_risk
Spec: If OpenSBI grants S-mode read access to a shared CLIC vector table via PMP, S-mode can leak M-mode interrupt handler addresses; if write is granted, S-mode can redirect M-mode interrupt handling to arbitrary code.
Violation: OpenSBI configures PMP/ePMP entries covering a shared interrupt vector table (CLIC/CLINT) that grants S-mode more than execute-only permission (e.g., R=1 or W=1 under L=0 standard PMP, or misconfigured Smepmp L=1 shared-code region), exposing M-mode interrupt handler pointers to lower privilege levels.
Consequence: privilege_escape
Pattern: pmp_set|pmpcfg_write|pmpaddr_write.*region.*(?:vector|clic|clint|interrupt).*table|grant.*[rw].*[su]-mode.*(?:xivt|xeivt|vector.table)
