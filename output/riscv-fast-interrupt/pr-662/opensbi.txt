PR #662  target=opensbi  overall=bug_confirmed
Spec: New ACLIC indirect CSRs (xacliciprio[k], xaclicsourcecfg[k]) added by Smidctrl/Ssidctrl require explicit save/restore across HSM suspend/resume; a firmware unaware of these extensions will silently lose interrupt priority and source configuration, corrupting M-mode and S-mode interrupt delivery after wakeup
Violation: OpenSBI HSM suspend handler saves/restores existing AIA CSRs (eip, eie, eithreshold) but does not save/restore the newly added xacliciprio[k] and xaclicsourcecfg[k] indirect CSR state, because these registers are introduced in the Smidctrl/Ssidctrl extension that OpenSBI was not previously aware of
Consequence: data_corruption
Pattern: HSM suspend/resume CSR save-restore loop that iterates over a fixed list of CSRs without awareness of Smidctrl/Ssidctrl xacliciprio and xaclicsourcecfg indirect register state
------------------------------------------------------------
[bug_confirmed] lib/sbi/sbi_hsm.c:408-433  __sbi_hsm_suspend_non_ret_save
  HSM non-retentive suspend does not save Smidctrl/Ssidctrl ACLIC indirect CSR state (xacliciprio[k] and xaclicsourcecfg[k]). Only 5 CSRs are saved (MIE, MIP, MEDELEG, MIDELEG, MENVCFG). On resume, the hart-local APLIC domain interrupt priority and source configuration registers are lost if the platform implements the Smidctrl/Ssidctrl extensions, causing data corruption of peripheral interrupt routing configuration.

  | if (sbi_hart_priv_version(scratch) >= SBI_HART_PRIV_VER_1_12)
  | 	hdata->saved_menvcfg = csr_read64(CSR_MENVCFG);

[bug_confirmed] lib/sbi/sbi_hsm.c:435-446  __sbi_hsm_suspend_non_ret_restore
  HSM non-retentive resume restores only the 5 saved CSRs and does not restore acliciprio[k] or aclicsourcecfg[k] indirect CSR state. After warm-boot resume, the S-mode ACLIC interrupt domain priority and source configuration registers are reset to their hardware default values (typically 0), which means: (a) all configured interrupt priorities are lost, (b) source delegation bits (D=1 for delegated interrupts) are cleared, causing all external interrupts to route to M-mode instead of S-mode, and (c) any software-configured sourcecfg delegation child index is lost.
  | if (sbi_hart_priv_version(scratch) >= SBI_HART_PRIV_VER_1_12)
  | 	csr_write64(CSR_MENVCFG, hdata->saved_menvcfg);
  | csr_write(CSR_MIDELEG, hdata->saved_mideleg);
  | csr_write(CSR_MEDELEG, hdata->saved_medeleg);
  | csr_write(CSR_MIE, hdata->saved_mie);
  | csr_set(CSR_MIP, (hdata->saved_mip & (MIP_SSIP | MIP_STIP)));
