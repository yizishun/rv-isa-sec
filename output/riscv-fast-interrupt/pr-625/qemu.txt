PR #625  target=qemu  overall=compliant
Spec: M-mode eisourcecfg D-bit write must atomically zero full source config when Ssaclic absent; partial WARL enforcement creates unauthorized interrupt delegation to non-existent S-mode interrupt file
Violation: QEMU emulates a write to the D (delegate) bit in an M-mode `eisourcecfg` indirect-CSR without zeroing the entire 11-bit source configuration when the Ssaclic extension is not present in the hart's feature set, violating the WARL constraint that 'writing '1' to the D (delegate) bit of an interrupt's source configuration causes the interrupt's entire source configuration to be set to zero instead'
Consequence: privilege_escape
Pattern: smaclic.*sourcecfg.*write|eisourcecfg.*delegate|csrind.*0x1000|siselect.*source.*config.*D.*bit|rmw_xireg.*sourcecfg|riscv.*aclic.*cfg.*zero
