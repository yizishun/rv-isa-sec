PR #735  target=linux  overall=compliant
Spec: CLIC interrupt push/pop now uses previous-privilege-mode translation (MPRV/SUM) for stack memory accesses; kernel must guarantee the interrupted context's SP points to translation-valid, writable (push) or readable (pop) memory at that privilege level, or hardware push/pop faults silently into unrecoverable failure
Violation: The kernel enables CLIC hardware interrupt push/pop (smip/ssip) but the interrupted context's stack pointer (xscratch or architectural SP) references memory not accessible at that context's privilege level, causing the hardware register save (push) or restore (pop) to fault during address translation or permission checks — especially when MPP/SPP=U but SP points to supervisor-only memory, or when user space deliberately sets SP to unmapped/unwritable pages
Consequence: denial_of_service
Pattern: csr_write.*[ms]scratch|csr_write.*[ms]iselect|CSR_XSCRATCH|mnxti|snxti|clint|CLIC_CTRL|mstatus_MPRV|sstatus_SUM|smip|ssip|smclic|snclic|handle_clic|clic_irq
