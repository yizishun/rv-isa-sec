PR #735  target=qemu  overall=compliant
Spec: CLIC interrupt push stores and pop loads must use the effective privilege mode (previous mode for push, MPP/SPP for pop) for address translation and protection; failure causes GPR save/restore to target wrong physical addresses, corrupting the interrupted context's architectural state on mret/sret
Violation: QEMU's implementation of CLIC/Smip interrupt push/pop (mipopret/sipopret) performs memory load/store operations using the current privilege mode's address translation (mem_idx) instead of the effective privilege mode specified by the spec: previous privilege mode for push stores, mstatus.MPP for mipopret loads, and sstatus.SPP for sipopret loads. Additionally, mipopret loads fail to apply MPRV semantics and sipopret loads fail to apply SUM semantics during translation.
Consequence: data_corruption
Pattern: helper_mipopret|helper_sipopret|clint.*push|clic.*stack|cpu_stl_data|cpu_ldl_data.*mipopret|sipopret.*translate|smip.*mem_idx|get_physical_address.*clic|riscv_cpu_do_interrupt.*clic|smip.*ld|smip.*st
