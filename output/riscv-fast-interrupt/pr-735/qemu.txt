PR #735  target=qemu  overall=compliant
Spec: CLIC interrupt push/pop memory accesses must use the interrupted context's privilege mode for address translation and protection — failing to set MPRV-equivalent override during stores (push) and loads (pop) causes guest register save/restore to target wrong physical memory, enabling privilege-boundary bypass
Violation: QEMU TCG emulates CLIC interrupt push (mncause/sncause register save stores) or interrupt popreturn (mipopret/sipopret register restore loads) using the current privilege mode's memory translation and protection, instead of switching to the previous (interrupted) privilege mode's effective translation/protection as required by the spec.
Consequence: privilege_escape
Pattern: TCG load/store op in CLIC push/pop path without prior MSTATUS_MPRV or equivalent privilege-mode override for memory access
