PR #714  target=linux  overall=compliant
Spec: Kernel ACLIC CSR access unconditionally assumes Smstateen mstateen0[53] is set by firmware; a cleared bit causes unhandled illegal-instruction traps
Violation: Linux kernel (S-mode) accesses acliciprio[k] or aclicsourcecfg[k] CSRs while M-mode firmware has mstateen0[53] (ACLIC) cleared, causing an unexpected illegal instruction trap in kernel context
Consequence: denial_of_service
Pattern: csr_read|csr_write.*aclic(iprio|sourcecfg)
