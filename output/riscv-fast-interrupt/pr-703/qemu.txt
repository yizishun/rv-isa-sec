PR #703  target=qemu  overall=compliant
Spec: CLIC-enabled interrupt trap modifications (GPR save on interrupted stack) are incompatible with mtvec.MODE=0 shared entry points; QEMU must reject or fault this configuration to prevent asymmetric state corruption when exceptions and interrupts share a handler
Violation: QEMU permits CLIC (aclic) interrupt-trap modifications to be active when mtvec.MODE = 0 (direct mode), causing interrupts and synchronous exceptions to share a single trap entry point while CLIC applies asymmetric save/restore behavior only to interrupts — spec explicitly forbids this combination
Consequence: privilege_escape
Pattern: clic.*enabled|mclicbase.*enable|cliced.*enable without adjacent mtvec.mode != 0 guard; or CLIC trap-entry logic (GPR save/restore, stack switching) that does not branch on mtvec.MODE before applying interrupt-specific behavior
