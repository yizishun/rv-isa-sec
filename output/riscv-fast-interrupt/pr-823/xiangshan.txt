PR #823  target=xiangshan  overall=compliant
Spec: Smcsps push/pop must hardwire x2 as swap register; any configurable register selection in RTL decode bypasses the architectural invariant and enables arbitrary GPR corruption via interrupt-stacked context swaps
Violation: The instruction decoder for Smcsps push/pop operations does not hardwire the swap source/destination to x2 (register index 0b00010), instead allowing the register to be selected via a configurable CSR field, instruction encoding bits, or microarchitectural override — i.e., any path where the RTL swaps a GPR other than x2 during xspcs-mediated push/pop
Consequence: privilege_escape
Pattern: CSR_xspcs.*(?:rs1|rs2|rd|srcReg|dstReg|swap_reg|sp_reg_sel)|xSPCS.*push.*pop.*(?:io\.reg|regIdx|regSel)|xspcs.*swap.*(?:reg[^=]*!=.*2|reg[^=]*=/=.*x2)
