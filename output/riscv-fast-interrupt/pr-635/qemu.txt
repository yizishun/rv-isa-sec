PR #635  target=qemu  overall=compliant
Spec: mcause/scause exception code field changes to hold Major[15:0] and Minor[XLEN-2:16] interrupt identities when xtvec.mode=11 for external interrupts; QEMU TCG trap delivery must conditionally pack both identities or guest interrupt dispatch breaks
Violation: When QEMU takes an external interrupt with xtvec.mode=11 (vector table mode) but fails to encode the major interrupt identity in mcause/scause bits 15:0 and the minor interrupt identity in bits XLEN-2:16, instead using the legacy exception code format
Consequence: data_corruption
Pattern: helper_riscv_trap|riscv_cpu_do_interrupt|set_mcause|set_scause.*cause.*interrupt|MCAUSE_|IRQ_.*cause
------------------------------------------------------------

  Smivt (xtvec.mode=11) is explicitly NOT implemented. Mode values >= 2 are rejected with a LOG_UNIMP warning. Silently dropping the write (WARL behavior) is spec-compliant for reserved modes. No Smivt-related security vulnerability exists because the feature is not claimed.
  | /* bits [1:0] encode mode; 0 = direct, 1 = vectored, 2 >= reserved */
