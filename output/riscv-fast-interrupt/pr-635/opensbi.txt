PR #635  target=opensbi  overall=compliant
Spec: OpenSBI trap handler dispatches external interrupts by raw mcause exception-code bit patterns; vector-table mode (mtvec.mode=11) re-encodes mcause exception code into major/minor identity fields, breaking external interrupt recognition and silently dropping all external interrupts.
Violation: When the CLIC is configured in interrupt vector table mode (mtvec.mode=11 or stvec.mode=11), OpenSBI's sbi_trap_nonaia_irq() reads mcause, masks off only the top-level interrupt bit via ~MCAUSE_IRQ_MASK, and directly compares the result against fixed exception-code constants (IRQ_M_EXT, IRQ_M_TIMER, IRQ_M_SOFT). Under vector table mode, external interrupts encode major identity in bits 15:0 and minor identity in bits XLEN-2:16 within the exception code field, so the raw value no longer equals the single-bit IRQ_M_EXT constant—the case IRQ_M_EXT dispatch is silently missed and external interrupts fall through to the default/unhandled path.
Consequence: denial_of_service
Pattern: mcause exception-code dispatch that uses bitmask (mcause & ~MCAUSE_IRQ_MASK) compared against hardcoded interrupt-ID constants (IRQ_M_EXT, IRQ_M_TIMER, IRQ_M_SOFT) without first reading mtvec.mode to check for vector-table-mode encoding semantics
