PR #718  target=qemu  overall=compliant
Spec: On interrupt delivery, xithreshold must be set to IPRIO (unmask all priorities), not to iprio[i] (the taken interrupt's priority); using iprio[i] would block higher-priority interrupts from preempting, breaking Smnip fast-preemption guarantees and causing guest interrupt starvation (DoS).
Violation: In QEMU's Smnip interrupt delivery path (riscv_cpu_do_interrupt or a CLIC-specific handler), when the emulated xithreshold CSR is written with iprio[i] — the priority of the specific interrupt being taken — instead of the constant IPRIO (maximum/all-mask-off value), the interrupt threshold is set to mask out interrupts at or below the current interrupt's priority.
Consequence: denial_of_service
Pattern: xithreshold\s*=\s*(iprio|irq_priority|int_prio)\s*\[
