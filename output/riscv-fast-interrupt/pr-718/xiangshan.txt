PR #718  target=xiangshan  overall=compliant
Spec: Writing iprio[i] instead of IPRIO to xithreshold on interrupt trap entry causes the interrupt-priority threshold to be set to a source-specific value rather than the architecturally-defined level-wide threshold, violating the interrupt masking hierarchy and enabling lower-priority interrupts to preempt execution when they should be blocked.
Violation: In the CLIC/AIA CSR hardware module, when a trap is taken on interrupt i into privilege level x, the RTL writes iprio[i] (the priority of the specific interrupting source) to the xithreshold CSR field instead of IPRIO (the interrupt priority threshold value associated with privilege level x). This occurs in the trap-entry microarchitectural state machine that updates xithreshold and xpistatus.pithreshold.
Consequence: privilege_escape
Pattern: xithreshold\s*:?=\s*iprio\[|xithreshold.*iprio\[i\]|trap.*entry.*threshold.*iprio|when.*taken.*interrupt.*xithreshold.*write
