PR #640  target=opensbi  overall=compliant
Spec: Smaiae extension removed; OpenSBI must rewire all M-mode AIA CSR gating from Smaiae to Smaia detection, or interrupt controller init and context save/restore will be silently skipped
Violation: OpenSBI M-mode code probes for 'Smaiae' as a distinct ISA extension string or device-tree property to gate AIA CSR access, save/restore, or initialization paths. After Smaiae removal, hardware reports Smaia directly, causing extension detection to miss, thereby skipping M-mode AIA CSR configuration (e.g., mvip, mvien writeability determination) that was previously conditioned on Smaiae presence.
Consequence: function_loss
Pattern: "smaiae" OR "Smaiae" OR "SMAIAE" in extension discovery, CSR capability probing, or conditional CSR access guards
