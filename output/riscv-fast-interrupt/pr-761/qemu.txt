PR #761  target=qemu  overall=compliant
Spec: Off-by-one in xiselect upper bound (0x1100 vs 0x10FF) causes QEMU to expose 257 indirect CSR slots where the architected limit is 256, enabling out-of-bounds access to uninitialized or stale CSR state via xireg/xireg2/xireg3 reads beyond the highest defined acliprio/aclicsourcecfg entry.
Violation: QEMU implements the old xiselect upper bound (0x1100) for the valid range of acliprio/aclicsourcecfg indirect access, causing an off-by-one where xiselect=0x1100 indexes entry 256 in a 256-entry (0..255) array, or QEMU has a bounds-check mismatch between the illegal-instruction trap range (xireg4-xireg6 reserved) and the actual valid indirect-access range, leading to either an out-of-bounds read of stale/uninitialized CSR state or a spurious illegal-instruction fault on a valid access.
Consequence: info_leak
Pattern: xiselect >= 0x1000 && xiselect <= 0x1100
