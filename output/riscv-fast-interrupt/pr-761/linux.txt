PR #761  target=linux  overall=compliant
Spec: xiselect range off-by-one: kernel using old inclusive 0x1100 bound on corrected hardware causes illegal instruction trap in supervisor mode when accessing nonexistent acliciprio256/aclicsourcecfg512, crashing the kernel during interrupt context save/restore or KVM virtual interrupt delivery.
Violation: Kernel code iterates xiselect over the old inclusive upper bound [0x1000, 0x1100] instead of the corrected [0x1000, 0x10FF], causing a CSR access at xiselect=0x1100 to an undefined indirect register slot, which triggers an illegal instruction exception in supervisor mode.
Consequence: denial_of_service
Pattern: for (i = 0x1000; i <= 0x1100; i++)|xiselect.*0x1100|NR_ACLIC_IPRIO.*257|ACLIC_IPRIO_MAX.*0x1100
