PR #668  target=freebsd-src  overall=compliant
Spec: FreeBSD's CLIC driver may incorrectly gate interrupts via xithreshold by using raw iprio[i] instead of the spec-mapped IPRIO value, causing spurious interrupt suppression or unexpected delivery
Violation: FreeBSD kernel code in the RISC-V CLIC/APLIC driver directly compares raw iprio[i] values against xithreshold without first converting to IPRIO per the spec mapping (saturate >255 to 255, handle priority-0 default based on relative ordering to machine external interrupt), causing the threshold mask to misclassify whether an interrupt should be disabled.
Consequence: denial_of_service
Pattern: iprio\[|IPRIO|xithreshold|xtopei|CLIC.*priorit|APLIC.*priorit|threshold.*interrupt
