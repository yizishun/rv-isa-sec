PR #669  target=opensbi  overall=compliant
Spec: OpenSBI context save/restore may fail to preserve interrupt threshold across domain/HSM suspend transitions because it targets the old eithreshold CSR while Smidctrl/Ssidctrl moves threshold into the new mithreshold CSR with different scope (major+minor identity)
Violation: In OpenSMI, when Smidctrl/Ssidctrl is present and OpenSBI saves/restores interrupt controller context (e.g., during HSM suspend/resume or domain context switch) but only saves eithreshold/eidelivery instead of the new mithreshold CSR that replaces eithreshold's threshold functionality under Smidctrl/Ssidctrl scope
Consequence: denial_of_service
Pattern: CSR_RS mithreshold|CSR_RW mithreshold|mithreshold.*save|mithreshold.*restore|eithreshold.*save.*context|eithreshold.*restore.*context|sbi_hsm_hart_suspend.*interrupt|CSR_RSW.*mithreshold
