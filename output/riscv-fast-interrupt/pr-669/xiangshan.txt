PR #669  target=xiangshan  overall=compliant
Spec: Spec removes eithreshold/eidelivery CSRs from Smidctrl/Ssidctrl and replaces them with mithreshold (IPRIOLEN-bit, covering both major and minor interrupt identities); XiangShan InterruptFilter.scala priority comparator and CSRAIA.scala indirect register routing must not retain stale eithreshold CSR logic, else interrupt priority thresholding is bypassable, enabling lower-priority interrupts to preempt higher-priority execution contexts in violation of the Priority Ceiling Protocol isolation guarantee.
Violation: XiangShan CSR module (NewCSR/CSRAIA.scala) or interrupt filter (NewCSR/InterruptFilter.scala) implements the removed eithreshold CSR as a readable/writable register at its AIA-defined indirect CSR address, or fails to implement the newly mandated mithreshold CSR with exact IPRIOLEN-bit width and correct major+minor-identity threshold semantics. Specifically: (a) if the interrupt priority comparator in InterruptFilter.scala:minSelect() compares pending interrupt priorities against an eithreshold-like threshold that only gates the APLIC/IMSIC external interrupt path rather than the new mithreshold that must gate ALL interrupt sources (both major and minor interrupt identities) at M-mode; or (b) if the CSR indirect access state machine (NewCSR.scala:1025-1110) incorrectly routes read/write requests to a stale eithreshold register slot instead of the mithreshold CSR address, causing a write to a wrong CSR bit field that software believes is controlling interrupt priority thresholding.
Consequence: privilege_escape
Pattern: InterruptFilter.*threshold|mithreshold|eithreshold|IPRIOLEN|mireg.*threshold|indirect.*threshold|CSRAIA.*threshold
