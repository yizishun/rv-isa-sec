PR #653  target=qemu  overall=compliant
Spec: Smip makes context save (x10-x15 push to stack) an automatic side-effect of interrupt trap entry rather than an explicit instruction; QEMU must perform guest memory writes during riscv_cpu_do_interrupt() and implement ipopxret for restore, otherwise interrupted-context caller-saved registers are silently corrupted
Violation: QEMU claims Smip support (e.g. via misa or ISA string) but the interrupt trap entry path in riscv_cpu_do_interrupt() does not automatically save registers x10-x15 to the guest memory stack before delivering control to the trap handler, or the ipopxret instruction is unimplemented/misimplemented such that x10-x15 are not restored before xret
Consequence: data_corruption
Pattern: riscv_cpu_do_interrupt OR riscv_cpu_trap OR s_mode_trap OR m_mode_trap without automatic GPR stacking to sp; ipopxret not decoded in translator; ctx_save or ctx_restore missing x10-x15
