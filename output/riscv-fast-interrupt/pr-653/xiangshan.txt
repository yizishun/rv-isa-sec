PR #653  target=xiangshan  overall=compliant
Spec: Smip moves context save from explicit tpush instruction to implicit trap-entry microcode that writes x10-x15 to stack before handler fetch; late preemption during this non-atomic multi-store sequence can leave stack memory corrupted if hardware does not guarantee save-completion or full sp rollback before vectoring to higher-priority interrupt
Violation: In XiangShan RTL, when a higher-priority interrupt arrives during the automatic context save sequence (x10-x15 stores + sp adjustment) that is now part of trap entry behavior, if the hardware either (a) takes the new interrupt without completing or properly rolling back the in-flight stack writes, causing partially-written stack frames to be exposed to the preempting handler, or (b) fails to preserve the original sp value so the preempting handler's own stack frame overwrites the interrupted handler's partially-saved context, or (c) the ipopxret instruction restores x10-x15 from a stack frame that was corrupted by a late-preempted nested interrupt without correct architectural rollback of sp and re-execution of the full save sequence on resume
Consequence: data_corruption
Pattern: automated register save to memory during interrupt trap entry, late-preemption abort of in-flight stack writes, sp adjustment rollback on nested interrupt, restartable partially-executed implicit store sequence in trap FSM
