PR #629  target=qemu  overall=compliant
Spec: ACLIC redesigned from indirect-CSR to APLIC-subset MMIO: sourcecfgK embeds read-only IE/IP mirrors replacing pending/enable arrays; QEMU must enforce RO semantics or guest can forge interrupt state
Violation: QEMU ACLIC MMIO write handler permits modification of read-only IE and IP fields in sourcecfgK registers, allowing guest software to fabricate interrupt-pending and interrupt-enable state that should only be controlled through setipnum/clripnum/setienum/clrienum
Consequence: data_corruption
Pattern: sourcecfgK IE/IP fields writable despite RO spec | ACLIC mmio_write sourcecfg no RO mask
