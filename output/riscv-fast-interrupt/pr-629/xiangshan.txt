PR #629  target=xiangshan  overall=compliant
Spec: Spec eliminates CSR-based ACLIC indirect register access and ACLIC-specific delivery mode (eidelivery=0x20000000, domaincfg.DM=2) in favor of MMIO APLIC direct-delivery subset — stale CSR-to-MMIO mismatch causes undeliverable external interrupts across all privilege modes
Violation: When XiangShan RTL implements ACLIC but retains the old spec's CSR-based indirect access path (xaclicsourcecfg[k] at xiselect indices 0x1000-0x1100 via xireg2/xireg3, xacliciprio[k] at the same index range) AND/OR the ACLIC-specific eidelivery=0x20000000 delivery mode in the IMSIC CSR routing logic, while software follows the new MMIO-only APLIC direct-delivery spec (DM=0, setipnum/clripnum/setienum/clrienum by IID, sourcecfg with IE/IP at bits 31:30)
Consequence: function_loss
Pattern: CSR.*xaclic(sourcecfg|iprio)|xiselect.*0x1[01]\d0|eidelivery.*0x20000000|domaincfg.*DM.*=.*\(2|miregiprios.*sourcecfg|CSRAIA.*aclic
