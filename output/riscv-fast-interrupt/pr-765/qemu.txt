PR #765  target=qemu  overall=compliant
Spec: Inverted mithreshold comparison in QEMU CLIC/CLINT emulation would mask higher-priority interrupts instead of lower-priority ones, causing guest OS to miss critical interrupts
Violation: QEMU's CLIC/CLINT emulation inverts the mithreshold comparison direction — masking interrupts with priority number LESS than the threshold value instead of masking interrupts with priority number GREATER than the threshold value (or vice versa, depending on interpretation of 'lower-priority'). Specifically, if QEMU implements `irq_enabled = (irq_priority >= mithreshold)` when the spec requires `irq_enabled = (irq_priority <= mithreshold)`, the threshold masks the wrong set of interrupts.
Consequence: denial_of_service
Pattern: mithreshold.*>=|<=\s*priority|threshold.*comparison|clic_threshold_filter|plic.*threshold|interrupt.*threshold.*check
