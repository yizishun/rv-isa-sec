PR #765  target=qemu  overall=compliant
Spec: mithreshold is WLRL with IPRIOLEN-bit width implementing priority cutoff masking; an off-by-one or inverted threshold comparison would invert which interrupts are delivered vs masked, breaking guest supervisor interrupt-security assumptions
Violation: In QEMU TCG, when emulating the mithreshold WLRL CSR write, the implementation either (a) fails to truncate the written value to IPRIOLEN bits before legalization, (b) uses an inverted comparison (>= instead of <= or vice versa) when evaluating whether an interrupt's priority meets the threshold cutoff for masking, or (c) reads from the IMSIC eithreshold register (ISELECT 0x72) return a value inconsistent with the architected mithreshold CSR state after a write.
Consequence: privilege_escape
Pattern: mithreshold.*write|mithreshold.*read|eithreshold.*threshold.*compare|WLRL.*mithreshold|IPRIOLEN.*trunc
