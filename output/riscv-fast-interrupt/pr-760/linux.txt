PR #760  target=linux  overall=compliant
Spec: Smivt handler-address computation fix: kernel vector-table layout must use vtoffset (not exccode) as the byte-offset index into VTBASE, or hardware fetches handlers from mismatched slots leading to arbitrary code execution on interrupt delivery.
Violation: When the kernel sets up the in-memory interrupt vector table (VTBASE) allocating entry slots indexed by the full exccode field (up to XLEN bits wide) while hardware indexes using the narrower vtoffset field. The resulting offset mismatch causes the hart to fetch handler addresses from unintended table offsets, redirecting interrupt delivery to wrong or unmapped kernel code.
Consequence: privilege_escape
Pattern: VTBASE|vtbase|vector_table|vtoffset|exccode.*XLEN/8|smivt|SMIVT
