PR #760  target=freebsd-src  overall=compliant
Spec: Using exception code (exccode) instead of vector offset (vtoffset) to index the ACLIC handler table lands interrupts on wildly wrong handlers—e.g., a machine timer interrupt vectors to a low-memory null handler instead of the clock ISR.
Violation: When FreeBSD's RISC-V trap entry code (or bhyve VMCS setup) computes the interrupt handler address by indexing the vector table with the raw mcause/scause exception code (which encodes the interrupt/exception flag in the top bit) instead of the architecturally-defined vtoffset, causing the calculated entry to be offset by 2^(XLEN-1) entries for interrupts versus exceptions of the same cause number.
Consequence: denial_of_service
Pattern: exccode|mcause.*>>|scause.*>>|cause.*index|vtbase.*exccode|vtbase.*cause
