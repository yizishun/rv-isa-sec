PR #775  target=xiangshan  overall=compliant
Spec: APLIC indirect CSR access to acliciprio[0] target[0] field and aclicsourcecfg[0] must be hardwired read-only-zero (ROZ) since APLIC domains do not implement target[0]; writable RTL implementation would allow software to configure a non-existent interrupt target, causing undefined interrupt routing behavior and potential privilege boundary violations.
Violation: In XiangShan RTL, when a CSR write (csrrw/csrrs/csrrc) targets the APLIC indirect access register xireg with xiselect set to access acliciprio[0] or aclicsourcecfg[0], the hardware writes the data value into the corresponding target[0] or sourcecfg[0] storage flop instead of forcing those bits/storage to zero and ignoring the write. Specifically: (1) xiselect=0x0000 accesses acliciprio[0] — the 8-bit field corresponding to target[0].iprio must be hardwired to read-as-zero and ignore writes, but the RTL may implement it as a writable register. (2) XLEN=32, xiselect=0x1000 accesses aclicsourcecfg[0] via xireg2 — the register must return zero and discard writes, but the RTL may instantiate it as a functional writable CSR slice mirroring a non-existent sourcecfg[0].
Consequence: privilege_escape
Pattern: target\[0\].*iprio|sourcecfg\[0\]|acliciprio\[0\]|aclicsourcecfg\[0\]|ROZ.*target.*zero|xiselect.*0x0000|xiselect.*0x1000
