PR #775  target=linux  overall=compliant
Spec: sourcecfg[0] and target[0] are hardwired read-only zero: the kernel must skip interrupt 0 during APLIC initialization or writes are silently dropped, leaving interrupt 0 permanently disabled and unrouted
Violation: Linux kernel APLIC driver writes to sourcecfg[0] or target[0] (bits in acliciprio[0]) expecting configuration to take effect, but the hardware silently ignores those writes because these fields are read-only zero
Consequence: denial_of_service
Pattern: writel|writeq|iowrite32|iowrite64.*(sourcecfg\[0\]|target\[0\]|acliciprio\[0\]|0x1000|interrupt.*0.*config)
