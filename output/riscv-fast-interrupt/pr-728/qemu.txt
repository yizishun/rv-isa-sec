PR #728  target=qemu  overall=compliant
Spec: Smip/Ssip automatic context save depends on Smcsps/Sscsps CSR push mechanism; enabling without the dependency causes interrupted-context CSR corruption in QEMU TCG SMP emulation
Violation: QEMU advertises or enables Smip/Ssip (interrupt handler push/pop) without first validating and implementing the dependent Smcsps/Sscsps extensions. When a guest hart takes an interrupt, QEMU's TCG would attempt automatic context save/restore via xcause/scause push, but the underlying CS push/pop mechanism from Smcsps is absent or incomplete, causing the interrupted context's CS state (mepc/mstatus etc.) to be saved to wrong locations or silently corrupted.
Consequence: data_corruption
Pattern: misa.Smip || misa.Ssip set without (misa.Smcsps || misa.Sscsps) guard; CLIC CSR write allowing xcause push enable (mclicbase + xcause push) while xcsps mechanism not implemented; TCG translate path for clic vector fetch that invokes automatic push without checking csps dependency sat
