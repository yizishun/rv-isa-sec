PR #728  target=linux  overall=compliant
Spec: Kernel enabling Smip/Ssip push/pop without Smcsps/Sscsps would access undefined CSRs, triggering illegal instruction traps and kernel panic
Violation: Linux kernel probes Smip/Ssip via ISA extension discovery and enables push/pop context save/restore on interrupt entry/exit without also verifying Smcsps/Sscsps presence, then accesses CS_PUSH/CS_POP configuration CSRs that require Smcsps/Sscsps support
Consequence: denial_of_service
Pattern: riscv_isa_extension_available(NULL, Smip) || riscv_isa_extension_available(NULL, Ssip) without corresponding Smcsps/Sscsps check before CS_PUSH/CS_POP CSR access
