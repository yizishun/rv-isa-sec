PR #785  target=qemu  overall=potential_risk
Spec: Inactive-source eip/eie bits must read as zero — failing to mask them leaks platform interrupt topology or stale cross-hart pending state to the guest
Violation: QEMU emulates ACLIC eip/eie register reads without masking bits for inactive interrupt sources (sources not configured/enabled in the connected APLIC domain), or updates interrupt-pending bits without adhering to the AIA 'Precise effects on interrupt-pending bits' ordering rules (e.g., updating pending bits mid-instruction instead of at instruction-retirement boundaries in TCG).
Consequence: info_leak
Pattern: ACLIC eip/eie read handlers that return raw pending/enable array values without AND-masking against the set of active source IDs from the APLIC domain; or CSR read functions for ACLIC registers that do not apply source-activity gating.
