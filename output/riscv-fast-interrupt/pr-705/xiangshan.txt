PR #705  target=xiangshan  overall=compliant
Spec: Reserved indirect CSR registers (xireg4-6 in APLIC domain) and odd xiselect on XLEN=64 must raise illegal-instruction exception; failure to trap allows untrusted M/S-mode software to probe or alias unmapped interrupt-priority register space, creating a privilege-escalation primitive through undefined CSR decode behavior
Violation: In XiangShan RTL, when the indirect CSR access logic for the APLIC domain (xiselect/xireg CSR pair) does NOT check whether xiselect falls in the reserved range 0x1000-0x1100 for xireg indices 4-6, or when XLEN=64 and xiselect is an odd value in 0x1000-0x1100, and instead silently decodes the access—either returning garbage from unmapped register addresses or aliasing onto adjacent valid registers—the hardware violates the spec-mandated illegal-instruction trap.
Consequence: privilege_escape
Pattern: xiselect decode NOT propagating illegal-instruction exception for (a) xireg[4:6] when xiselect in [0x1000,0x1100), or (b) odd xiselect in [0x1000,0x1100) when XLEN=64; silent passthrough to APLIC register file with out-of-bounds address, or default/WARL behavior that returns data instead of trapping
