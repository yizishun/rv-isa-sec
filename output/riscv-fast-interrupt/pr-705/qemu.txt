PR #705  target=qemu  overall=compliant
Spec: QEMU must raise illegal-instruction exception on indirect CSR window access to reserved xireg4–xireg6 (xiselect 0x1000–0x1100) and odd-select XLEN=64 accesses; missing guard leaks uninitialized indirect-register shadow state to the guest
Violation: QEMU's software implementation of indirect CSR access (siselect/sireg* and miselect/mireg*) permits guest read/write to xireg4–xireg6 when xiselect is in range 0x1000–0x1100 without raising an illegal-instruction exception, or permits any xireg access with an odd xiselect in that range on XLEN=64
Consequence: info_leak
Pattern: ISELECT_IPRIO|0x1000|ireg.*indirect|rmw_xireg|siselect.*range|aclic.*illegal
