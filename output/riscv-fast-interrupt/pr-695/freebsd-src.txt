PR #695  target=freebsd-src  overall=compliant
Spec: Smnip CSR address errata: FreeBSD kernel must use corrected addresses (msp=0x349, ssp=0x149, mithreshold=0x347, sithreshold=0x147) to avoid aliasing mipreemptcfg as msp and corrupting interrupt-priority state on context switch
Violation: FreeBSD kernel or bhyve hypervisor hardcodes stale Smnip draft CSR addresses (msp at 0x348 instead of 0x349, ssp at 0x148 instead of 0x149, mithreshold at 0xFB1 instead of 0x347, sithreshold at 0x1B1 instead of 0x147) that were corrected by this spec errata. Hardware implementing the final spec will decode the old addresses as different CSRs (e.g., 0x348 is now mipreemptcfg, not msp), causing the kernel to read/write the wrong architectural state during context switch, trap entry/exit, or bhyve guest save/restore.
Consequence: data_corruption
Pattern: grep -rn '0x348\|0x148\|0xFB1\|0x1B1' sys/riscv/ --include='*.h' --include='*.c' | grep -i 'csr\|msp\|ssp\|threshold\|smnip'
