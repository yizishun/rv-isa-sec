PR #696  target=freebsd-src  overall=bug_confirmed
Spec: Delegating IPRIO derivation entirely to AIA breaks hardcoded default-priority assumptions in FreeBSD's interrupt masking logic: if bhyve or the kernel caches old iprio[i]=0 rules, threshold gating may silence critical interrupts or leak masked ones through
Violation: FreeBSD kernel code or bhyve VMM uses the pre-PR#696 IPRIO derivation rules (distinguishing iprio[i]=0 cases as 'higher/lower than machine external interrupt') to compute threshold comparisons when hardware implements the simplified IPRIO-delegated-to-AIA definition, causing xtopi-reported priority to diverge from the kernel's expected masking behavior
Consequence: denial_of_service
Pattern: iprio.*0|threshold.*priority.*default|xtopi.*iprio|mip.*threshold|xithreshold.*compare|PR_HIGHER_THAN|PR_LOWER_THAN|default_priority.*external
------------------------------------------------------------
