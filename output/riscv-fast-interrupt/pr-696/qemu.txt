PR #696  target=qemu  overall=potential_risk
Spec: IPRIO for threshold comparison must use xtopi CSR-reported value (read_mtopi/read_stopi path), but riscv_cpu_pending_to_irq() derives a different effective priority (1 vs 0) for iprio=0 high-default-priority interrupts — using the wrong derivation for threshold filtering would incorrectly mask high-priority local interrupts
Violation: QEMU's interrupt priority derivation is inconsistent: read_mtopi() reports iprio=0 (unmasked) for local interrupts with iprio[]=0 and default_priority <= IPRIO_DEFAULT_M, but riscv_cpu_pending_to_irq() assigns effective priority=1 to the same interrupts. The spec now mandates that the threshold masking condition IPRIO >= xithreshold & NIPPRIO_MASK must use the xtopi CSR-reported IPRIO value. If QEMU adds local interrupt threshold filtering (or repurposes pending_to_irq's prio for threshold comparison), the priority mismatch means iprio=0 sources with high default priority would be compared as prio=1 instead of prio=0, causing them to be incorrectly masked when xithreshold=1.
Consequence: denial_of_service
Pattern: (read_mtopi|read_stopi|riscv_cpu_pending_to_irq|rmw_iprio).*iprio.*default_priority|(!prio|!iprio).*(IPRIO_DEFAULT|extirq_def_prio|IPRIO_MMAXIPRIO)

[potential_risk] target/riscv/cpu_helper.c:433-470  riscv_cpu_pending_to_irq
  pending_to_irq() derives effective priority differently from read_mtopi/read_stopi: for iprio[]=0, it splits into three branches — (a) irq==extirq → prio=extirq_def_prio (16 or 19), (b) default_priority < extirq_def_prio → prio=1, (c) otherwise → prio=IPRIO_MMAXIPRIO (255). Branch (b) assigns prio=1, which contradicts read_mtopi/read_stopi's iprio=0 for the same source. Currently only branch (a) is reachable with current defaults, since all non-extirq local interrupts have default_priority > extirq_def_prio. The divergence from xtopi CSR-reported IPRIO makes this function unsuitable for threshold-aware interrupt selection unless unified.
  | prio = iprio[irq];
  | if (!prio) {
  |     if (irq == extirq) {
  |         prio = extirq_def_prio;
  |     } else {
  |         prio = (riscv_cpu_default_priority(irq) < extirq_def_prio) ?
  |                1 : IPRIO_MMAXIPRIO;
  |     }
  | }
