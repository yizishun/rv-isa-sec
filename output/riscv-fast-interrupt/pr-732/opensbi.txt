PR #732  target=opensbi  overall=compliant
Spec: Exception handler enabling MIE without save-then-enable protocol corrupts mpistatus.pithreshold via nested interrupt, causing mret to restore wrong interrupt threshold
Violation: OpenSBI M-mode exception handler enables MIE (mstatus.MIE=1) to allow nested interrupts without first saving mpistatus to a software context. A nested interrupt arriving during the exception handler window will overwrite mpistatus.pithreshold with the handler's current mth, destroying the original pre-exception threshold value. When the nested interrupt returns via mret, mth is restored from the corrupted mpistatus.pithreshold, and the subsequent mret from the exception handler restores an incorrect threshold to the original context.
Consequence: function_loss
Pattern: M-mode trap handler that branches on mcause to exception path, then sets mstatus.MIE without first reading and saving mpistatus to a software save area; or saves mpistatus AFTER enabling interrupts rather than before
