PR #609  target=qemu  overall=compliant
Spec: ACLIC sourcecfgK register format changes based on D bit — QEMU must zero/remap fields on D-bit transitions or else guest-stashed values in IPRIO/SM positions (D=0) become readable as Child-Index bits (D=1), leaking prior configuration state across delegation boundaries
Violation: QEMU emulates sourcecfgK as a single flat register without zeroing/remapping fields when the D (delegation) bit transitions between 0 and 1 in M-domain. When D=0, bits 23:16 hold IPRIO and bits 2:0 hold SM; when D=1, bits 9:0 hold Child Index. A guest writes a value in one format, toggles D, then reads back the other format, observing stale bits from the previous format at aliased bit positions.
Consequence: info_leak
Pattern: sourcecfg.*write.*d_bit|sourcecfg.*delegation.*format|aclic.*sourcecfg.*transition
