PR #609  target=freebsd-src  overall=compliant
Spec: Smaclic/Ssaclic no longer depend on Smaiae; FreeBSD must handle ACLIC interrupts via APLIC direct-delivery IDC registers (topi/claimi/idelivery/ithreshold) rather than unconditionally using the IMSIC CSR interface (stopei), and must check for a TBD mstateen0 bit before accessing ACLIC configuration registers
Violation: When FreeBSD's RISC-V external interrupt handler reads the stopei CSR to claim/identify interrupts on hardware that implements Smaclic/Ssaclic (ACLIC) without Smaiae, because the kernel assumes external interrupt delivery always implies Smaiae presence—this assumption was valid under the old spec (Smaclic depended on Smaiae) but is broken by this PR removing that dependency.
Consequence: denial_of_service
Pattern: Grep for reads of stopei CSR or checks for Smaia/Ssaia ISA extension strings in sys/riscv/riscv/intr_machdep.c and exception.S that gate external interrupt handling without also checking for the ACLIC (APLIC direct-delivery) path
