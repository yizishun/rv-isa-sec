PR #609  target=freebsd-src  overall=compliant
Spec: Smaclic/Ssaclic no longer depends on Smaiae, so ACLIC-only harts lack IMSIC CSRs; FreeBSD's intr handler reading stopi/sclaimi gets zero → all external interrupts silently lost
Violation: FreeBSD kernel executing on a hart that implements Smaclic/Ssaclic without Smaiae (IMSIC) reads the CSR-based stopi/sclaimi registers in the trap handler to claim external interrupts; these CSRs do not exist on such a system, so the read returns zero, causing the kernel to silently drop all external interrupts routed through the ACLIC
Consequence: denial_of_service
Pattern: csr_read.*[st]opi|csr_read.*[st]claimi|CSR_[ST]OPI|CSR_[ST]CLAIMI|CSR_SIE.*SEIE
------------------------------------------------------------
