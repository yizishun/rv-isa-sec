PR #706  target=qemu  overall=compliant
Spec: Unimplemented or incorrectly gated automatic stacking on interrupt entry corrupts guest hardware context when MIPU/SIPU bits are set, and misapplication to popret return paths violates the spec exemption that these bits do not influence mipopret/sipopret behavior
Violation: QEMU exposes MIPU/SIPU bits as writable in mstatus/sstatus (once encoding is allocated) but does not implement automatic hardware context stacking on interrupt entry at the corresponding privilege level, OR QEMU incorrectly applies automatic stacking behavior to mipopret/sipopret return paths despite the spec explicitly exempting them
Consequence: data_corruption
Pattern: write_mstatus.*MIPU|write_mstatus.*SIPU|mstatus.*stack|riscv_cpu_do_interrupt.*SMCLIC|clc_save.*mstatus|smstateen.*clc
------------------------------------------------------------

Bits 0-42 and 63 (SD) are fully allocated to known extensions (UIE, SIE, MIE, UPIE, SPIE, UBE, MPIE, SPP, VS, MPP, FS, XS, MPRV, SUM, MXR, TVM, TW, TSR, SPELP, SDT, MPELP, GVA, MPV, MDT). No CLIC-spec MIPU/SIPU bits exist, so they cannot be improperly exposed as writable.
