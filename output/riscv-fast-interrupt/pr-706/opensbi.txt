PR #706  target=opensbi  overall=compliant
Spec: Unallocated MIPU/SIPU bits in mstatus are at risk of being clobbered by OpenSBI's HSM context save/restore paths that use hardcoded mstatus field masks, causing loss of automatic interrupt stacking on resume
Violation: OpenSBI saves and restores mstatus (e.g., during HSM suspend/resume or domain context switch) without preserving the not-yet-allocated MIPU/SIPU bits. Since the encoding is undefined, existing OpenSBI code that does read-modify-write on mstatus fields using hardcoded masks will inadvertently clear or corrupt these bits, silently breaking the automatic stacking behavior expected by the interrupt handler.
Consequence: denial_of_service
Pattern: mstatus.*&=|mstatus.*\|=|csr_write.*mstatus|csr_read.*mstatus.*csr_write|save.*mstatus|restore.*mstatus
