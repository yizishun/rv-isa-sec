PR #822  target=qemu  overall=bug_confirmed
Spec: mstateen0 bit 58 gates S/U-mode access to ACLIC CSRs reused from IMSIC (stopei/eip/eie); QEMU must raise illegal instruction exception when bit 58 is zero, else lower-privilege guest code bypasses state-enable access control
Violation: QEMU allows S-mode or U-mode access to stopei, eip[k], or eie[k] CSRs when Smstateen is implemented and mstateen0 bit 58 (IMSIC) is zero, without raising an illegal instruction exception. This occurs if the CSR read/write handler for these CSRs does not check the mstateen0[58] state-enable bit before permitting access from lower privilege levels.
Consequence: privilege_escape
Pattern: csr_ops handler for stopei/eip/eie missing mstateen0 bit-58 check before s-mode/u-mode access; or mstateen0 CSR definition missing bit 58 as a writable/readable field when Smstateen is present
