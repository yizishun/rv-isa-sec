PR #822  target=xiangshan  overall=compliant
Spec: Missing mstateen0 bit-58 (IMSIC-gate) decode on Smidctrl-reused IMSIC CSRs (stopei/eip/eie) enables S-mode privilege escape when Smstateen is implemented but IMSIC gate is zeroed, bypassing M-mode access control on external-interrupt CSR state.
Violation: When Smstateen is implemented and Smidctrl reuses IMSIC CSRs (stopei, eip[k], eie[k]) accessible to S-mode, the CSR privilege-check gate logic tests only mstateen0[53] (ACLIC gate) without also testing mstateen0[58] (IMSIC gate). If mstateen0[58]==0 but mstateen0[53]==1 (ACLIC enabled but IMSIC gate cleared), S-mode access to stopei/eip[k]/eie[k] proceeds without trapping. The hardware failure modes: (1) the mstateen0 read-and-mask datapath in the CSR privilege decoder only extracts bit 53 and omits bit 58, (2) the stopei/eip/eie CSR access FSM gates on the ACLIC stateen signal rather than the IMSIC stateen signal, or (3) the bit index in the stateen mask register is mis-encoded (e.g., using index 53 for the IMSIC-gated CSRs instead of index 58).
Consequence: privilege_escape
Pattern: mstateen0\[58\]|mstateen.*58|hstateen0\[58\]|sstateen0\[58\]|IMSIC.*stateen|stateen.*IMSIC|stopei.*stateEnable|eip\[.*stateEnable|eie\[.*stateEnable|Smstateen.*gate|bit58.*mstateen
