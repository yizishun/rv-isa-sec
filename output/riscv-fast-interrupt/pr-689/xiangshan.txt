PR #689  target=xiangshan  overall=compliant
Spec: ACLIC not implemented in XiangShan; this PR corrects child index 1→0 in spec, but a future RTL implementation hardcoding the wrong child index would route delegated interrupts to null domain, effectively dropping S-mode interrupts—a silent privilege-escalation DoS.
Violation: XiangShan does NOT currently implement ACLIC (no sourcecfg CSR, no child index fields, no CLIC/ACLIC interrupt controller). If ACLIC were implemented in future RTL and the sourcecfg[i] Child Index field were hardcoded to 1'b1 (instead of 1'b0) when D=1 in Machine mode, the domain hierarchy pointer would reference a non-existent child domain, causing interrupt delegation to silently break.
Consequence: privilege_escape
Pattern: sourcecfg.*child.*index.*1|ChildIndex.*:=.*1\.U|sourcecfg.*D.*:=.*1\.U.*child.*1
