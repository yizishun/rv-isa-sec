PR #819  target=opensbi  overall=compliant
Spec: Spec omission of seivt from mstateen0.ACLIC gating breaks Smstateen access-control model: S-mode bypasses M-mode firmware CLIC restrictions via un-gated seivt
Violation: OpenSBI programs mstateen0 in mstatus_init() with bit 53 (ACLIC) cleared, intending to deny S-mode all CLIC CSR access — but hardware following the pre-fix spec leaves seivt un-gated by ACLIC, allowing S-mode to read/write seivt and redirect external interrupt vectors despite M-mode firmware's explicit Smstateen access-denial policy.
Consequence: privilege_escape
Pattern: mstateen0 write without SMSTATEEN0_ACLIC define; CSR_MSTATEEN0 programming not covering bit 53 for CLIC vector table CSRs
