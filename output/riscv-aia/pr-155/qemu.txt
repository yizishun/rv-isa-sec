PR #155  target=qemu  overall=compliant
Spec: SSAMB extension assigns major interrupt code 14 as a local asynchronous memory buffer interrupt; QEMU must update all CSR bitmask definitions (mip/mie/mideleg/mvien), iprio array layouts (miprio bytes 14, siprio/hviprio bits 55:48), local interrupt classification tables, and AIA interrupt-priority-ordering logic to treat bit 14 as a functional writable/readable local interrupt instead of reserved-zero
Violation: QEMU's CSR bitmask definitions for mip/mie/mideleg/mvien/mvip and AIA iprio CSR layouts (miprio/siprio/hviprio) still treat bit 14 as reserved/hardwired-zero, while guest software running the Ssamb extension expects bit 14 to be a functional local interrupt (asynchronous memory buffer interrupt). Specifically: (a) CSR read of mip bit 14 returns constant 0 regardless of pending LAMBI state, (b) CSR write to mie bit 14 is silently ignored, (c) mideleg bit 14 is hardwired-zero preventing delegation, (d) iprio register fields for interrupt 14 (e.g., miprio bits 119:112, siprio bits 55:48) remain reserved-zero ignoring guest priority configuration, (e) the local interrupt classification table still categorizes code 14 as 'not local interrupt' causing incorrect interrupt filtering and prioritization in the AIA interrupt delivery path.
Consequence: denial_of_service
Pattern: interrupt number 14.*reserved|bit 14.*zero|MIP_*_MASK.*14|mideleg.*14|IRQ_.*14.*hardwired|iprio.*14.*reserved|local_interrupt.*13.*15.*but.*not.*14
