PR #155  target=opensbi  overall=bug_confirmed
Spec: New local interrupt 14 (LAMBI) adds CSR state in miprio/siprio priority arrays and mie/mideleg bits that OpenSBI HSM save/restore and delegation init must cover; stale or zeroed priority after context switch creates priority inversion or spurious M-mode trap races.
Violation: OpenSBI HSM context-save/restore or mideleg configuration iterates over known local interrupts (e.g., only codes 0-13) and fails to include interrupt code 14 (LAMBI), leaving its priority state in miprio/siprio CSR arrays unsaved across suspend/resume or its delegation unconfigured, while Ssamb hardware drives asynchronous memory buffer events.
Consequence: race_condition
Pattern: for.*intr.*<=.*13|case 13:|interrupt.*13|mideleg.*~(?!.*14)|miprio.*save|miprio.*restore
