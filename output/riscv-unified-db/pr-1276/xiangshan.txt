PR #1276  target=xiangshan  overall=compliant
Spec: Zfinx path replaces mstatus.FS check with stateen CSR chain (mstateen0/sstateen0/hstateen0.FCSR); if stateen CSRs are not fully implemented or wired into the decode stage, FP instructions execute without any privilege gate, bypassing both the old mstatus.FS and the new stateen checks
Violation:
  When Zfinx is implemented in XiangShan RTL but the
  mstateen0/sstateen0/hstateen0 CSR chain is not fully wired into the
  instruction decoder's floating-point legality check, or when these stateen
  CSRs are hardwired (e.g., mstateen0.FCSR tied to 1), the spec-mandated
  check_f_ok function would skip the legacy mstatus.FS gate without enforcing
  the replacement stateen-based gate, allowing floating-point instructions to
  execute in privilege contexts where they should trap with
  IllegalInstruction.
Consequence: privilege_escape
Pattern:
  check_f_ok.*Zfinx|mstateen0.*FCSR|sstateen0.*FCSR|hstateen0.*FCSR|stateen.*i
  llegal.*instruction|FPU.*decode.*stateen|FloatPoint.*check.*legal
