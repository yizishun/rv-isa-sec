PR #1297  target=linux  overall=compliant
Spec: mseccfg/mseccfgh are gated on Sm≥1.12 AND anyOf{Zkr,Smmpm,Zicfilp}; kernel code must not access them based on Sm version alone, or it will trap on hardware lacking field-defining extensions
Violation:
  In the Linux kernel, code reads or writes CSR_MSECCFG/CSR_MSECCFGH after
  checking only that Sm >= 1.12, without also verifying that at least one of
  Zkr, Smmpm, or Zicfilp is present in the ISA string. On hardware with Sm >=
  1.12 but none of those field-defining extensions, the CSR does not exist and
  access raises an illegal instruction exception.
Consequence: denial_of_service
Pattern:
  csr_read\(CSR_MSECCFG\)|csr_write\(CSR_MSECCFG\)|CSR_MSECCFGH
------------------------------------------------------------
[compliant] arch/riscv/include/asm/csr.h:429-430  N/A
  CSR_MSECCFG (0x747) and CSR_MSECCFGH (0x757) are defined but never accessed
  via csr_read() or csr_write() anywhere in the kernel. MSECCFG_PMM bit
  aliases at lines 245-249 are also never used to form CSR accesses. Pointer
