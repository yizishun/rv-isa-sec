PR #1365  target=freebsd-src  overall=not_implemented
Spec: FreeBSD is little-endian; if a process enables big-endian U-mode via sstatus.UBE (Ssube), all kernel-user data boundaries—copyin/copyout, signal frames, ptrace, coredumps, and context switches—become endianness-mismatch surfaces that the kernel has no code to handle, silently corrupting process data.
Violation:
  FreeBSD kernel accesses user memory (copyin/copyout, signal frame setup,
  ptrace, core dump) without byte-swapping when the current process has
  sstatus.UBE=1, OR the context-switch path fails to save/restore sstatus.UBE,
  leaking endianness state between processes.
Consequence: data_corruption
Pattern:
  sstatus.*UBE|copyin|copyout|siginfo|sigframe|ptrace.*user|proc.*read|proc.*w
  rite|set_mcontext|get_mcontext|exec_setregs|cpu_switch|cpu_fork
------------------------------------------------------------
