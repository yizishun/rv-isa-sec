PR #1380  target=opensbi  overall=potential_risk
Spec: Smepmp mseccfg.MML repurposes pmpcfg.L from 'locked' to 'M-mode-only' and RLB allows bypassing locks — OpenSBI must explicitly clear MML before setting locked PMP entries and must zero RLB before S-mode handoff, otherwise domain isolation via PMP locking is silently defeated
Violation:
  OpenSBI sets pmpcfg.L on PMP entries to enforce domain isolation or region
  locking, but mseccfg.MML=1 silently changes L-bit semantics from 'locked' to
  'M-mode-only', allowing S-mode domains to access regions OpenSBI intended to
  be fully locked. Additionally, if mseccfg.RLB=1 is left set when jumping to
  S-mode, locked PMP entries become modifiable by M-mode SBI handlers invoked
  from S-mode, defeating firmware-enforced isolation.
Consequence: privilege_escape
Pattern:
  sbi_mseccfg_write|pmp_set.*LOCK|pmpcfg.*CSR_TBL_L|mseccfg.*RLB|mseccfg.*MML(
  ?!\s*==\s*0|\s*&\s*0)|pmp_lock_hart|__pmp_lock
