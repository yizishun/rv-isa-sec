PR #1238  target=linux  overall=not_implemented
Spec: Smctr/Ssctr CTR buffer holds branch history (source/target PCs, transfer type, cycle count) accessible via indirect CSRs (Smcsrind/Sscsrind); failing to save/restore this state on context switch leaks precise inter-process control flow data that defeats KASLR and enables side-channel key extraction.
Violation:
  Linux kernel context-switches a RISC-V hart with active CTR (Smctr/Ssctr)
  state without saving and restoring the CTR buffer (ctrsource, ctrtarget,
  ctrdata across all depth entries), cycle counter (CC/CCV), and CTR
  configuration, allowing the next scheduled task to read the previous task's
  control flow transfer history.
Consequence: info_leak

  The switch_to() macro saves/restores FPU state (via __switch_to_fpu), vector
  state (via __switch_to_vector), and envcfg (via __switch_to_envcfg), but has

  Smctr/Ssctr without Smstateen (where mstateen0.CTR would not gate access),

  ctrtarget, ctrdata across all depth entries), sctrstatus (WRPTR, FROZEN),
  sctrctl, sctrdepth, and the cycle counter (CC/CCV) are not preserved across
  context switches, allowing a subsequent task to read the previous task's
  control flow transfer history.
