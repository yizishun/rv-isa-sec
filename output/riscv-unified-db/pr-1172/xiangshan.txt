PR #1172  target=xiangshan  overall=not_implemented
Spec: sctrctl/vsctrctl alias mctrctl in hardware but have narrower read masks (missing M, MTE bits); returning raw mctrctl state without per-CSR masking leaks M-mode-only configuration fields to S/VS-mode via CSR read instructions
Violation:
  sctrctl/vsctrctl read path in RTL directly returns mctrctl hardware register
  state without applying the correct per-CSR read mask. The sctrctl read mask
  (0x787F9F80000DC3) excludes bit 2 (M field) and bit 9 (MTE field) present in
  the mctrctl mask (0x787F9F80000FC7). If the Chisel CSR module implements
  sctrctl as a simple alias that reads the raw mctrctl wire without masking,
  S-mode and VS-mode can observe M-mode CTR enable and M-mode trap enable
  bits, leaking M-mode configuration state to lower privilege levels.
Consequence: info_leak
Pattern:
  sctrctl.*alias.*mctrctl|vsctrctl.*mask.*0xDC3|CSR.*0x14E.*read.*mask|sctrctl
  .*Bits.*63.*0|CSRMap.*sctrctl.*mctrctl
