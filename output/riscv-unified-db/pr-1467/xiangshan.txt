PR #1467  target=xiangshan  overall=compliant
Spec: vle8.v spec changed from sign-extended to zero-extended 8-bit loads and all unit-stride LS ops now require misaligned-access gating and vm mask support; incorrect RTL matching of these semantics causes silent data corruption on vector memory accesses
Violation:
  XiangShan RTL vector load/store unit executes vle8.v with sign-extension of
  the loaded 8-bit value (sext to VLEN) when the updated spec mandates zero-
  extension (the sext was removed: read_memory<8> without sext). Additionally,
  if the RTL's vector LSU does not gate misaligned unit-stride accesses on
  VECTOR_LS_MISALIGNED_LEGAL, misaligned addresses silently proceed instead of
  raising an address-misaligned exception. If vm==0 mask support is absent
  (spec marks it TODO/unpredictable), masked-off elements may be overwritten
  instead of retaining undisturbed values.
Consequence: data_corruption
Pattern:
  sext.*read_memory|sign.?extend.*vle8|vle8.*sext|VECTOR_LS_MISALIGNED|misalig
  n.*unit.?stride|vm.*mask.*vector.?load.*store|vstart.*skip|undisturbed.*poli
  cy.*tail
