PR #1555  target=xiangshan  overall=compliant
Spec: Spec change replaces unconditional IllegalInstruction trap on AMO-with-misa.A=0 with a configurable reserved_instruction() that may enter unpredictable state instead of trapping, creating a privilege escape where clearing misa.A fails to disable atomic memory operations in hardware
Violation:
  In XiangShan RTL, when CSR misa.A is cleared (A extension disabled at
  runtime) but the decode stage does not reject Zaamo/Zabha opcodes before
  execution, the AMO instruction proceeds to the execute stage. If the RTL's
  TRAP_ON_UNIMPLEMENTED_INSTRUCTION parameter is false (or the
  reserved_instruction implementation defaults to unpredictable), the hardware
  enters undefined microarchitectural state instead of raising
  IllegalInstruction—potentially allowing the AMO to complete with arbitrary
  results. Additionally, Zabha (byte/halfword AMO) instructions may lack any
  misa.A gating entirely per the review comment that Zabha checks were removed
  from the final code.
Consequence: privilege_escape
Pattern:
  TRAP_ON_UNIMPLEMENTED_INSTRUCTION|misa\.A|misa_a|reserved_instruction|Illega
  lInstruction.*AMO|amo(alr|aq|rl).*decode|Zabha.*misa
