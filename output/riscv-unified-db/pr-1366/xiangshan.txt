PR #1366  target=xiangshan  overall=compliant
Spec: sstatus.UXL CSR write datapath must WARL-mask to 1 (32-bit) only when Ssu32xl is asserted; a mask-versus-behavior mismatch between UXL field storage and XLEN-dependent datapath truncation creates a cross-width privilege-escalation primitive.
Violation:
  XiangShan RTL writes to sstatus.UXL are not properly WARL-masked to the set
  of supported values: if Ssu32xl is claimed but the CSR module hardwires UXL
  to 2 (64-bit only) or masks bit writes such that value 1 (UXLEN=32) cannot
  be stored, the spec is violated. Conversely, if Ssu32xl is not implemented
  but UXL write logic contains a bit-encoding bug that allows value 1 to
  persist, U-mode executes with inconsistent XLEN semantics—register
  read/write paths in the integer datapath truncate to 32 bits while address-
  generation and memory-access paths use 64-bit full-width, creating an
  attacker-controllable mismatched-width execution state.
Consequence: privilege_escape
Pattern:
  (sstatus.*UXL|UXL.*WARL|Cat\(.*UXL|MuxLookup.*UXL|when.*uxl===1|uxl_wen|uxl_
  field).*
