PR #1164  target=qemu  overall=compliant
Spec: SCTRCLR indirect-CSR clear loop must be WARL-bounded on sctrdepth.DEPTH and must atomically zero CTR_CYCLE_COUNTER/CCV_HW, otherwise stale cross-context branch history leaks through ctrdata reads
Violation:
  QEMU implements the SCTRCLR instruction but fails to bound the write loop by
  the hardware-WARL-limited sctrdepth.DEPTH value, allowing writes through
  siselect/sireg indirect CSR aliasing to indices beyond the physically
  implemented CTR buffer entries (max depth 16 << WARL_DEPTH_max).
  Additionally, if QEMU omits clearing the internal CTR_CYCLE_COUNTER and
  CCV_HW state on SCTRCLR execution, a subsequent ctrdata read exposes stale
  control-flow history (source/target PC, transfer type, elapsed cycles) from
  a prior security context.
Consequence: info_leak
Pattern:
  sctrclr.*DEPTH.*bound|siselect.*0x200.*sireg|CTR_CYCLE_COUNTER.*clear|CCV_HW
  .*clear|indirect_csr.*ctr.*write|sctrdepth.*warl
