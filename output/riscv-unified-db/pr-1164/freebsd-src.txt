PR #1164  target=freebsd-src  overall=compliant
Spec: Smctr/Ssctr CTR transfer-history FIFO is not architecturally invisible per ASID/VMID; failing to clear or save/restore CTR state (via SCTRCLR or indirect CSR access) on context switch in cpu_switch() leaks cross-process control-flow traces including kernel-space return addresses
Violation:
  In the FreeBSD kernel, when Smctr/Ssctr is implemented in hardware but the
  kernel does not execute SCTRCLR or save/restore CTR indirect CSR state
  (siselect+sireg1-3 for CTR entries, CTR_CYCLE_COUNTER, CCV_HW) during
  context switch in cpu_switch(), a process can read another process's control
  transfer history (source/target PCs, transfer type, elapsed cycles) via the
  indirect CSR interface, revealing execution traces including kernel return
  addresses from prior context windows.
Consequence: info_leak
Pattern:
  cpu_switch.*sctrclr|cpu_throw.*sctrclr|sctrclr.*swtch|mstateen0.*CTR|sstatee
  n0.*CTR|sctrdepth|siselect.*0x200|ctrsource|ctrtarget|ctrdata|CTR_CYCLE_COUN
  TER|CCV_HW|Smctr.*context.switch|Ssctr.*context.switch
