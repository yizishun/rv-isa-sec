PR #1236  target=qemu  overall=compliant
Spec: sie CSR fields are defined as aliases of mie bits gated by mideleg; implementing sie as independent storage causes guest kernel interrupt masking to malfunction silently
Violation:
  When QEMU emulates `sie` (0x104) as an independent storage register without
  implementing the alias propagation to/from `mie` based on `mideleg`
  delegation state. The spec defines `sie.SSIE`, `sie.STIE`, `sie.SEIE`, and
  `sie.LCOFIE` as aliases of the corresponding `mie` fields when the
  respective `mideleg` bits are set. If QEMU reads/writes `sie` from a private
  backing array without forwarding writes to `mie` (and reflecting `mie`
  values on read when delegated), guest supervisor software's interrupt enable
  writes are silently discarded — the underlying `mie` bits never change, so
  interrupts the guest kernel believes it has enabled remain masked (or vice
  versa, interrupts it believes are masked fire anyway).
Consequence: function_loss
Pattern:
  sie CSR read/write handlers that manipulate a private `env->sie` field
  without reading/updating `env->mie` when `env->mideleg &
  MIE_SSIE/STIE/SEIE/LCOFIE`
