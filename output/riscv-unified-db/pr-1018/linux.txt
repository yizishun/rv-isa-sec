PR #1018  target=linux  overall=compliant
Spec: mvip writes are silently dropped by hardware when the corresponding mvien bit is read-only zero (WARL constraint); KVM virtual interrupt injection via SBI must verify mvien configuration first, or guest interrupts are silently lost
Violation:
  In Linux KVM on RISC-V, a virtual interrupt is injected into a guest via
  mvip (through SBI call to M-mode firmware) without the corresponding enable
  bit in mvien being writable and set to 1; the hardware silently drops the
  mvip write per the WARL constraint, causing the injected virtual interrupt
  to be lost with no error indication to the kernel
Consequence: denial_of_service
Pattern:
  kvm_riscv_aia_inject|kvm_riscv_vcpu_aia_imsic_inject|riscv_sbi_set_vip|CSR_W
  RITE\(.*mvip|aia.*inject.*imsic
