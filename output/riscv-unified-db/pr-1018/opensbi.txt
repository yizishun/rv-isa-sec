PR #1018  target=opensbi  overall=compliant
Spec: mvip write silently dropped if mvien enable bit is not set first — virtual interrupt injection from M-mode OpenSBI to VS-mode guest requires mvien→mvip write ordering
Violation:
  OpenSBI writes to mvip (to inject virtual interrupts for VS-mode) before
  ensuring the corresponding mvien bits are set to 1, or writes mvip bits for
  interrupt numbers not in the MACHINE_VIRTUAL_INTERRUPTS WARL set. The spec
  gates mvip writability on mvien being both writable AND enabled: write to
  mvip.VSSIP returns 0 unless mvien.VSSIE==1. If OpenSBI sets mvip first then
  mvien, or sets mvip without checking mvien WARL constraints, the virtual
  interrupt injection is silently dropped.
Consequence: denial_of_service
Pattern:
  csr_write.*mvip.*before.*mvien|mvip.*csrw.*without.*mvien.*set|virtual.*inte
  rrupt.*inject.*order
