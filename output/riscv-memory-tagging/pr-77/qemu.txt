PR #77  target=qemu  overall=compliant
Spec: HLV/HSV tag-check opt-out via hstatus.MTAG_I and VS-stage PTE.X: if QEMU TCG helper_hyp_load/store does not suppress MTE tag checks when hstatus.MTAG_I==1 or VS-stage leaf PTE.X==1, the hypervisor experiences spurious tag faults on code-page accesses, allowing a malicious guest to construct page tables where hypervisor-emulated loads diverge from guest-native loads and bypass memory tagging enforcement
Violation: QEMU's TCG implementation of HLV*/HSV* performs memory tag checks without first consulting hstatus.MTAG_I (which should suppress checks when set) and without checking VS-stage leaf PTE.X (which also forces unchecked loads), causing tag faults or unchecked accesses at times the spec forbids
Consequence: privilege_escape
Pattern: helper_hlv.*tag|hlv.*mte|hlv.*check.*tag|hstatus.*MTAG|MTAG_I.*hlv|riscv_cpu_tlb_fill.*hlv|get_physical_address.*hlv|helper_hyp_load|helper_hyp_store
