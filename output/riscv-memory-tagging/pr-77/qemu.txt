PR #77  target=qemu  overall=compliant
Spec: Failure to implement MTAG opt-out logic for HLV/HSV/HLVX and MPRV paths causes QEMU to either spuriously inject tag-check faults during hypervisor guest-memory emulation (breaking nested virtualization) or silently skip required tag checks, creating a privilege-domain violation where the hypervisor observes memory access behavior inconsistent with the guest's configured page-table MTAG policy.
Violation:
  QEMU's HLV/HSV/HLVX emulation does not inspect VS-stage page table MTAG and
  execute bits to decide tag-check applicability, and does not populate
  hstatus.MTAG_I/mstatus.MTAG_I on trap entry with the code-page MTAG bit.
  Specifically: (1) HLV/HSV always generate checked or unchecked accesses
  without considering VS-stage PTE.X or hstatus.MTAG_I opt-out; (2) HLVX does
  not collect the VS-stage leaf PTE MTAG bit into hstatus.MTAG_I; (3) on trap
  to HS/M-mode with nonzero htinst/mtval, the MTAG bit from the trapping
  instruction's code page is not deposited into hstatus.MTAG_I/mstatus.MTAG_I;
  (4) MPRV=1 with MXR=1 does not collect first-stage PTE MTAG into
  mstatus.MTAG_I and does not suppress tag checks when the effective-mode leaf
  PTE has X set or mstatus.MTAG_I is set.
Consequence: privilege_escape
Pattern:
  hlv.*_mte|hsv.*_mte|helper_hlv|helper_hsv|hlvx_inst|MTAG_I|mstatus_mtag|hsta
  tus_mtag|mte_tag_check|riscv_cpu_do_interrupt.*mstatus|riscv_cpu_do_interrup
  t.*hstatus|MPRV.*mte|mprv.*tag
