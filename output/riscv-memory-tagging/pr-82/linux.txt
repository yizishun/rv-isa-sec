Spec: New hstatus.MTAG_I and mstatus.MTAG_I bits act as opt-out overrides for tag checking on HLV/HSV/MPRV accesses; if the kernel or KVM fails to context-switch these bits, a guest code page's MTAG bit can leak across VM boundaries to suppress tag checks on hypervisor emulated accesses, letting a malicious guest bypass memory tagging on loads/stores emulated by the hypervisor
Violation:
  Linux KVM does not save/restore hstatus.MTAG_I on VM-entry/VM-exit, or
  OpenSBI/Linux does not save/restore mstatus.MTAG_I across M-mode trap
  handlers that use MPRV, causing stale MTAG_I values to incorrectly suppress
  or enable tag checks on HLV/HSV/MPRV memory accesses that cross security
  boundaries
Consequence: privilege_escape
Pattern:
  (hstatus|mstatus).*MTAG_I|MTAG_I.*(save|restore|switch|context)|HLV|HSV|MPRV
  .*(tag|check|mte)
------------------------------------------------------------
[not_implemented] N/A (not implemented in this codebase):0-0  N/A
  The RISC-V memory tagging extension (MTE) with hstatus.MTAG_I /
  mstatus.MTAG_I CSR fields for HLV/HSV/MPRV tag-check control does not exist
  in this Linux kernel tree. The hstatus register defined in csr.h (lines
  135-153) contains only: HUPMM, VSXL, VTSR, VTW, VTVM, VGEIN, HU, SPVP, SPV,
  GVA, VSBE. No MTAG_I bit exists. The KVM hstatus save/restore in
  vcpu_exit.c:74 and vcpu.c:799-861 correctly uses csr_swap(CSR_HSTATUS, ...)
  for VM-entry/VM-exit, which would correctly preserve any hypothetical future
  MTAG_I field. The RISC-V privileged spec (hypervisor.adoc:167-220) defines
  the hstatus register with no MTAG_I field — the only MTE bit in the ISA
  manual is in mctrctl (smctr.adoc:38) for Control Transfer Recording,
  unrelated to memory tagging.
  | // csr.h: hstatus flags — no MTAG_I defined
  | #define HSTATUS_SPV _AC(0x00000080, UL)
  | #define HSTATUS_GVA _AC(0x00000040, UL)
  | 
  | // vcpu_exit.c:74 — correct hstatus swap for HLV/HSV
  | old_hstatus = csr_swap(CSR_HSTATUS, vcpu->arch.guest_context.hstatus);
  | csr_write(CSR_HSTATUS, old_hstatus);
