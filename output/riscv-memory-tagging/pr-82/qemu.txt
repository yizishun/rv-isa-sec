PR #82  target=qemu  overall=potential_risk
Spec: mstatus/hstatus MTAG_I bits control opt-out of tag checks on HLV/HSV/MPRV memory accesses based on code-page PTE.MTAG; QEMU must correctly deposit these bits on trap entry and evaluate them during emulated memory access translation, or guest memory-tagging isolation is silently broken.
Violation: QEMU TCG does not deposit the MTAG bit from the trapping instruction's code-page PTE into mstatus.MTAG_I (on M-mode trap with mtinst written nonzero) or hstatus.MTAG_I (on HS-mode trap with htinst written nonzero), AND QEMU fails to consult mstatus.MTAG_I / hstatus.MTAG_I to suppress tag checks during MPRV-influenced loads/stores or HLV/HSV hypervisor accesses — causing tag checks to be applied when the spec mandates unchecked access (MTAG_I=1), or skipped when the spec mandates checked access (MTAG_I=0).
Consequence: info_leak
Pattern: helper_hyp_hlv|helper_hyp_hsv|check_access_hlsv|mstatus.*MTAG|hstatus.*MTAG|mte_tag|mtag_i|MPRV.*load|MPRV.*store|tcg_gen_qemu_ld|tcg_gen_qemu_st|riscv_cpu_do_interrupt|get_physical_address.*MTAG|pte_mtag|PTE_MTAG
