PR #81  target=qemu  overall=compliant
Spec: Removal of Zitagelide: QEMU must not emulate the nietc instruction, TTCD hart state, or SPTTCD/MPTTCD CSR bits; stale emulation would give guests an unauthorized MTE tag-check bypass overriding page-table-enforced tag protection
Violation: QEMU emulates the removed Zitagelide extension: decodes the nietc instruction (C.MOP.3 encoding), maintains the transient tag check disable (TTCD) hart state, and exposes SPTTCD (mstatus/sstatus/vsstatus bit 24) and MPTTCD (mstatus bit 42) fields as readable/writable, allowing guest software to elide MTE tag checks on tagged data pages when the ratified spec no longer authorizes this mechanism
Consequence: privilege_escape
Pattern: nietc|TTCD|tag_check_elide|SPTTCD|MPTTCD|mstatus.*bit.*24|mstatus.*bit.*42|C\.MOP\.3.*tag|elide.*tag|tag_check_disable
