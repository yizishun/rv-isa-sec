PR #81  target=qemu  overall=compliant
Spec: Removal of Zitagelide renders SPTTCD (mstatus/sstatus bit 24) and MPTTCD (mstatus bit 42) as WPRI — QEMU must hardwire these bits to zero and remove all TTCD state spill/restore logic to prevent guest info leaks through now-reserved CSR fields
Violation:
  QEMU retains writable SPTTCD (bit 24) and MPTTCD (bit 42) fields in
  mstatus/sstatus/vsstatus after the Zitagelide extension is removed, allowing
  guests to write to bits that the current spec defines as WPRI (read-only
  zero). Additionally, if the TTCD state machinery (spill on trap, restore on
  mret/sret) is not removed, stale or attacker-controlled TTCD values could
  influence tag check enforcement on memory accesses.
Consequence: info_leak
Pattern:
  mstatus.*bit.*24|mstatus.*bit.*42|SPTTCD|MPTTCD|TTCD|nietc|tag.*elide|tag_ch
  eck_elide
