PR #76  target=qemu  overall=compliant
Spec: Spec mandates stval2/htval2/mtval3 capture the faulting VA on tag-mismatch software check exceptions; QEMU failure to write these CSRs leaks stale register content to the guest and breaks the kernel's ability to identify the faulting access. Async mode adds ordering and trap-boundary resolution requirements that, if violated, can inject spurious exceptions into higher-privilege trap handlers.
Violation:
  QEMU raises a software check exception (tval=4) for a tag mismatch on a
  regular load/store or checktag instruction but does NOT populate
  stval2/htval2/mtval3 with the virtual address of the faulting load/store, OR
  in asynchronous mode defers a store tag-mismatch exception past a trap-entry
  or trap-return boundary, OR reports multiple pending async tag mismatches
  out of program order.
Consequence: info_leak
Pattern:
  raise.*software.check.*tval.*4|riscv_raise_exception.*RISCV_EXCP_SW_CHECK.*4
  |stval2|htval2|mtval3|MT_ASYNC|tag.mismatch.*async|tag_check.*store
