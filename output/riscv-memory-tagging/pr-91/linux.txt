PR #91  target=linux  overall=not_implemented
Spec: Spec fix: MTAG+executable page is 'tagcheck-exempt' (loads/stores unchecked), not 'tagcheck-required' — kernel must not set MTAG on code pages expecting tag enforcement, or memory tagging silently degrades to no-op
Violation:
  Kernel sets the MTAG bit in a PTE for an executable page expecting that tag
  checks will be performed on loads/stores emitted by that code, but hardware
  (per the corrected spec) treats any page with MTAG+execute as 'tagcheck-
  exempt' — meaning loads/stores from that page skip tag checks entirely,
  silently defeating memory safety enforcement.
Consequence: function_loss
Pattern:
  PTE_MTAG set together with PTE_EXEC (pte_val() & (_PAGE_MTAG | _PAGE_EXEC))
  == (_PAGE_MTAG | _PAGE_EXEC) without recognizing this creates a tagcheck-
  exempt page whose loads/stores bypass tag checks
------------------------------------------------------------
[not_implemented] arch/riscv/include/asm/pgtable-bits.h:9-76  N/A (PTE bit definitions)
  The RISC-V Linux kernel defines no _PAGE_MTAG or equivalent memory-tagging
  PTE bit. The current PTE bits are: _PAGE_PRESENT(0), _PAGE_READ(1),
  _PAGE_WRITE(2), _PAGE_EXEC(3), _PAGE_USER(4), _PAGE_GLOBAL(5),
  _PAGE_ACCESSED(6), _PAGE_DIRTY(7), _PAGE_SOFT(8-9). No MTAG PTE bit exists
  to combine with _PAGE_EXEC, so the vulnerability pattern ((pte_val() &
  (_PAGE_MTAG | _PAGE_EXEC)) == (_PAGE_MTAG | _PAGE_EXEC)) cannot occur. The
  RISC-V Pointer Masking (Zpm) extension controls tag masking via CSR bits
  (menvcfg.PMM, senvcfg.PMM, mseccfg.PMM) rather than through PTE bits, and
  the spec explicitly states tag checks themselves are implementation-defined
  software or hardware features. The described MTAG+EXEC 'tagcheck-exempt' PTE
  behavior does not correspond to any ratified RISC-V extension or kernel
  implementation.
  | #define _PAGE_PRESENT   (1 << 0)
  | #define _PAGE_READ      (1 << 1)    /* Readable */
  | #define _PAGE_WRITE     (1 << 2)    /* Writable */
  | #define _PAGE_EXEC      (1 << 3)    /* Executable */
  | #define _PAGE_USER      (1 << 4)    /* User */
