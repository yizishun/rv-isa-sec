PR #91  target=xiangshan  overall=not_implemented
Spec: Logic inversion in tag-check gating: RTL implementing the pre-fix spec would AND the tagged-data-page condition with 'instruction IS from tagcheck-exempt code page' instead of 'is NOT', systematically inverting which code regions trigger memory tag checks and effectively disabling tag protection for the majority of code.
Violation:
  In XiangShan RTL, the LSU/LDU tag-check enable logic evaluates:
  tag_check_applies = (data_page.MTAG_bit_set && xIE_bit_clear) &&
  (code_page.MTAG_bit_set && xIE_bit_set). This means load/store instructions
  fetched from a tagcheck-exempt code page (MTAG=1, X=1) trigger tag checks,
  while instructions fetched from normal code pages (MTAG=0) bypass tag checks
  — the exact inverse of the intended semantics where tagcheck-exempt code
  pages should always generate unchecked accesses per Rule 3 of the
  TAGGED_PAGE section.
Consequence: privilege_escape
Pattern:
  tag_check_enable &lt;= is_tagged_data_page &amp;
  is_tagcheck_exempt_code_page
