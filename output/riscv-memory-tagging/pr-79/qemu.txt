PR #79  target=qemu  overall=compliant
Spec: Cross-page instruction straddling between tagcheck-exempt and normal code pages must force unchecked-access treatment to the safer normal-page path, and tagged-data page classification must require execute=0 — failure in either causes guest memory-tagging bypass or spurious tag faults
Violation: QEMU TCG translates an instruction that straddles a page boundary between a tagcheck-exempt code page (MTAG=1, X=1) and a normal code page (MTAG=0 or no X), but does not apply the spec rule that the instruction is 'assumed to be fetched from normal code page' — causing loads/stores issued by that instruction to incorrectly bypass tag checks when they should be checked, or QEMU's page table walker in get_physical_address() fails to check the execute permission bit alongside the MTAG bit when classifying a page as 'tagged-data page' (requiring MTAG=1 AND X=0), causing code pages with MTAG=1 to be misclassified as tagged-data pages.
Consequence: privilege_escape
Pattern: straddl|page_cross|insn_cross|mtag.*execute|xwr|tagged.data.page.*!.*x|tagcheck.exempt|riscv_cpu_tlb_fill.*mtag|get_physical_address.*mtag
