PR #1197  target=xiangshan  overall=bug_confirmed
Spec: dcsr.cause always reports 3 (Haltreq) for all debug interrupts; halt-group-induced halts (which must report cause=6 Group per PR #1197) are indistinguishable from direct halt requests because hgDebugInt and hrDebugInt are ORed into a single interrupt line with no sideband cause-differentiation
Violation: When any hart in a halt group halts, the Debug Module asserts hgDebugInt for all other harts in that group (debug_module.adoc:245, Debug.scala:1134). This signal is ORed with hrDebugInt into a single debug interrupt line (Debug.scala:1146). In the CSR trap-entry logic, all debug interrupts unconditionally write dcsr.cause = 3 (Haltreq) via causeIntr = DcsrCause.Haltreq.asUInt (TrapEntryDEvent.scala:57, CSR.scala:1474). The DcsrCause.Group value (6) is defined (DebugLevel.scala:339) but never referenced in any trap-entry code path. The hardware has no mechanism to distinguish halt-group interrupts from direct halt-request interrupts, so it can never set cause=6 for group-induced halts as required by the tightened spec.
Consequence: function_loss
Pattern: dcsr.cause.*:=.*(HALTREQ|3\.U|Haltreq)|hgDebugInt.*\|.*hrDebugInt|causeIntr.*Haltreq|CAUSE_HALTREQ
