PR #1189  target=qemu  overall=compliant
Spec: Unvalidated dcsr.prv write allows debugger to force hart into unsupported privilege mode on Debug Mode exit, escaping architectural privilege boundaries
Violation: QEMU's dcsr write handler does not enforce WARL behavior on dcsr.prv: writing an unsupported privilege mode (e.g., S-mode when only M/U are implemented, or a reserved encoding) is accepted verbatim rather than being warped to a supported mode. When the hart exits Debug Mode, it resumes in an invalid or nonexistent privilege level.
Consequence: privilege_escape
Pattern: dcsr.*prv.*write|write_dcsr|dcsr.*=.*val|dcsr_write|s->debugger_dcsr
