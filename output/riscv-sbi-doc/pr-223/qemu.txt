PR #223  target=qemu  overall=compliant
Spec: QEMU must recognize event ID 0xffff0001 as a valid standard local SSE event (local unknown NMI) and route it to the target hart; failure to do so means guest supervisor software never receives notification of unknown NMIs, violating the security contract the spec establishes.
Violation:
  QEMU's SSE event routing or validation logic treats event ID 0xffff0001 as
  reserved (e.g., by using a static whitelist or outdated range check that
  only reserves 0xffff0001-0xffff3fff), causing a hardware-injected unknown
  NMI to be silently dropped instead of delivered as a local SSE event to the
  target hart.
Consequence: function_loss
Pattern:
  SSE event_id range check that maps 0xffff0001 into the
  reserved/unimplemented bucket, or a switch-case / lookup-table that lacks a
  handler for event ID 0xffff0001
