PR #27  target=linux  overall=compliant
Spec: New Sspesa shpmsdetailsbt1/2 CSRs capture branch target PCs that, when sampled in kernel context, carry raw kernel code addresses; exposing these in userspace perf sample records bypasses KASLR unless the kernel explicitly sanitizes the record before delivery.
Violation: The kernel reads shpmsdetailsbt1 or shpmsdetailsbt2 when a sample was taken during kernel-mode execution, and exposes the raw branch target PCs to userspace via the perf sample record without zeroing or applying KASLR offset masking. Additionally, if the kernel does not context-switch (save/restore) these CSRs on thread migration, branch targets from one address space leak into another.
Consequence: info_leak
Pattern: shpmsdetailsbt[12]|Sspesa.*sample.*record|Pesa Branch Target PC|perf.*pesa.*branch
