Spec: New shpmsdetails extension exposes retire-stage microarchitectural state (RSTATE: stall/flush/drain, CAUSE: cache-miss/branch-mispredict events per sampled instruction) and cycle-counter reload with AutoRun streaming mode — without CDE privilege gating or minimum-period hardware enforcement, these CSRs provide a high-resolution side channel leaking pipeline timing, retire bandwidth loss causes, and control-flow targets across privilege boundaries
Violation:
  shpmsdetailsdata.RSTATE exposes retire-stage state (retiring=00, stalled=01,
  flushed=10, drained=11) and CAUSE exposes per-instruction blocking events
  (I$miss, ITLBmiss, branch mispredict, D$miss, DTLBmiss) accessible from
  S-mode without menvcfg.CDE=1 gate. shpmsdetailscc writable SAMPLEINITVALUE
  field lacks hardware minimum-interval comparator (spec recommends ≥2^8
  cycles), allowing untrusted S-mode software to configure near-zero sample
  periods and saturate trace buffer/memory bandwidth. shpmsdetails WARL bits
  (32-bit field in shpmsdetailsdata plus full-width shpmsdetailsbt1/bt2) are
  readable without hardwired-zero-on-reset, leaking prior-sample internal
  state across privilege boundaries.
Consequence: function_loss
Pattern:
  PesaSampleDetailBundle|shpmsdetailsdata|RSTATE.*stall|RSTATE.*flush|CAUSE.*m
  iss|CAUSE.*mispredict|SAMPLEINITVALUE.*guard|sample_period.*min|shpmsdetails
  .*WARL.*hardwire|AutoRun.*stream|trace_buffer.*overflow
