PR #46  target=xiangshan  overall=compliant
Spec: Physical/guest-physical addresses stored to pdisadr2 must be right-shifted by 2 bits (PMP-style encoding) to accommodate addresses wider than XLEN; missing this shift causes all reported physical addresses to be off by factor of 4, leaking incorrect memory layout to untrusted consumers of profiling data
Violation: When pdisadr2 is written with a physical or guest-physical address without right-shifting by 2 bits (i.e., storing the full address instead of addr[63:2] concatenated with the low 2 bits implied by the virtual address), the hardware violates the spec requirement that physical addresses in pdisadr2 use the same shift-by-2 encoding as PMP address registers and page table entries.
Consequence: info_leak
Pattern: pdisadr2.*physical.*address|pdisadr2.*PA.*write|PDIS.*addr.*shift|PDISSampleData.*adr2
