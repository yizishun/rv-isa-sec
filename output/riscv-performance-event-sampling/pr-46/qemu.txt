PR #46  target=qemu  overall=not_implemented
Spec: Physical/guest-physical addresses written to pdisadr2 must be right-shifted by 2 bits matching PMP-address encoding; failure to apply or consume this shift corrupts guest physical address data in PDIS sample records, leaking wrong addresses to the guest profiler.
Violation:
  QEMU writes the full (unshifted) physical address or guest physical address
  to pdisadr2 sample record field for explicit memory access samples, instead
  of shifting the address right by 2 bits as required by the spec change.
  Conversely, QEMU applies the right-shift-by-2 encoding but guest software
  (or another QEMU component) interprets pdisadr2 as a full unshifted address,
  causing a 4x mismatch in physical address values.
Consequence: info_leak
Pattern:
  pdisadr2.*phys|physical.*address.*shift|pdis.*addr2|spdisdata.*adr2|sample.*
  record.*address
