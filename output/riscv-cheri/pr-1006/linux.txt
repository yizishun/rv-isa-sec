PR #1006  target=linux  overall=compliant
Spec: P-bit (formerly M-bit) in PCC controls CHERI Execution Mode across context switches; kernel must propagate it faithfully and respect that CSRRW writes to extended CSRs in Address Mode apply SCADDR (stripping capability metadata), otherwise a process could escape its capability bounds after resume or return-to-userspace.
Violation: Linux kernel context-switch, KVM world-switch, or signal-delivery code saves PCC (containing the P-bit) and later restores it without preserving the P-bit value, or writes to extended YLEN CSRs (sscratch_y, mscratch_y, vsscratch_y, stvec_y, mtvec_y, vstvec_y, sepc_y, mepc_y, vsepc_y) using CSRRW while in Address Mode without applying SCADDR semantics, causing capability metadata (tag, bounds, permissions) to be silently stripped or corrupted across privilege boundaries.
Consequence: privilege_escape
Pattern: (save|restore|swap|switch).*(pcc|sscratch|mscratch|stvec|mtvec|sepc|mepc).*(capability|cheri|p_bit|m_bit|ctag)|CSRRW.*scratch|__switch_to.*cap|kvm_arch.*(save|restore).*cheri|cpu_switch_to.*pcc|cheri_pcc_(save|restore|get|set)
