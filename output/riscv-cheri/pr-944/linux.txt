PR #944  target=linux  overall=compliant
Spec: ymodew spec codifies that integrity failure implies tag=0 by construction; kernel capability save/restore and KVM emulation must never decouple integrity state from tag validity, or a guest could craft a tagged capability with broken integrity to bypass capability-based memory protection
Violation: In the Linux kernel, any capability save/restore or manipulation path (context switch, signal frame construction, ptrace regset get/set, KVM capability emulation) that treats 'integrity check failure' and 'tag=0' as independent conditions—for example, by clearing integrity metadata without also clearing the tag, or by exposing a tagged-but-integrity-failed capability to userspace—violates the architectural guarantee that failed integrity forces tag to 0 by construction.
Consequence: privilege_escape
