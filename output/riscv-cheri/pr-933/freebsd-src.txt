PR #933  target=freebsd-src  overall=compliant
Spec: 4-bit RVY PTE field replaces single CRW bit; residual stale bits in pmap-constructed PTEs cause silent capability tag corruption or spurious CLCR faults when Svyrg is enabled, and SYRG/UYRG context-switch omission leaks revocation-generation state across processes
Violation: FreeBSD kernel context-switch path (cpu_switch/cpu_throw in sys/riscv/riscv/swtch.S) saves and restores sstatus without preserving the new per-thread SYRG and UYRG fields, or the pmap PTE constructor (pmap_enter/pv_to_pte in sys/riscv/riscv/pmap.c) writes the legacy single-bit CRW into the now-4-bit RVY PTE field, leaving bits [2:0] carrying stale state from a previously freed page table page. When sstatus.RGE is subsequently set, the hardware interprets the residual bits as YRG/YW/YD — producing spurious CHERI Load Capability Faults (denial_of_service) or silently clearing capability tags on loads from pages believed to be capability-enabled (data_corruption).
Consequence: data_corruption
Pattern: sstatus.*(SYRG|UYRG|RGE)|pte.*(RVY|YR|YW|YD|YRG)|crw.*pte|PTE_CAP|PTE_CHERI
