PR #933  target=linux  overall=compliant
Spec: sstatus gains SYRG (supervisor read-generation) for kernel-page revocation alongside existing UYRG; any kernel code that constructs sstatus by masking former-WPRI bits silently zeroes the revocation epoch, defeating kernel use-after-reallocation protection
Violation: When Svyrg is enabled (sstatus.YRGE=1) and kernel code reconstructs sstatus from a template that masks out the former WPRI bits now occupied by SYRG, UYRG, and YRGE—or fails to save/restore sstatus.SYRG across kernel context switches—a hart resumes with a stale or zeroed supervisor capability read generation epoch, causing pte.yrg mismatches to either silently pass (revocation bypass) or spuriously fault on kernel capability loads
Consequence: privilege_escape
Pattern: SR_SYRG|SR_UYRG|SR_YRGE|_sstatus|sstatus.*mask|WPRI.*sstatus|csr_write.*sstatus|switch_to.*sstatus|__switch_to
