PR #936  target=qemu  overall=compliant
Spec: GCHI funct5 field changed from 0b00000 to 0b10000 to resolve an encoding clash with SCBNDSI; QEMU using stale decode tables would silently confuse a capability-bounds-setting instruction (SCBNDSI) with a capability-metadata-read instruction (GCHI), undermining CHERI capability confinement.
Violation: QEMU TCG decodes the CHERI GCHI instruction using the old funct5=00000 encoding instead of the new funct5=10000 encoding, causing decode collision with SCBNDSI (Set Capability Bounds immediate). The decoder dispatches the wrong instruction for a given 32-bit opcode, so guest code assembled for one ISA version silently executes a semantically unrelated instruction under the other ISA version.
Consequence: privilege_escape
Pattern: decode_gchi|GCHI_.*funct5|case 0b00000.*funct5|cheri.*gchi|trans_gchi|trans_scbndsi|CHERI_OPC_GCHI|cheri_op.*funct5
