PR #860  target=qemu  overall=potential_risk
Spec: Under CHERI, vector memory access instructions with base register x0 are reserved encodings; failing to trap them in QEMU TCG allows guests to bypass capability bounds enforcement via XLEN-wide indexed offsets that effectively access arbitrary physical memory
Violation: When CHERI is enabled, QEMU TCG translates a vector load/store instruction with base register x0 as a valid memory access (e.g., treating base=0 as a null-derived capability covering all memory) instead of raising an illegal instruction exception as required by the 'reserved' encoding rule
Consequence: privilege_escape
Pattern: vector.*load.*store.*x0.*cheri|cheri.*vector.*base.*zero|vle.*vse.*vlse.*vsse.*vuxei.*vloxei.*capability.*check|base == 0.*vector|rs1.*==.*0.*vector.*load
