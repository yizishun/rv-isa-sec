PR #918  target=freebsd-src  overall=compliant
Spec: YBNDRW incorrectly cleared capability tags when bounds couldn't be exactly encoded (copy-paste from YBNDSW), causing FreeBSD kernel to lose valid capabilities that should remain authorized because rounding-down preserves authority
Violation: FreeBSD kernel code (e.g., capability-aware copyin/copyout, pmap capability validation, or capability register save/restore in context-switch paths) invokes the YBNDRW (Set Bounds Round Down) instruction and an incorrect microarchitectural implementation clears cd.tag when the requested bounds cannot be encoded exactly, despite the rounded-down bounds being strictly within the original capability's authority
Consequence: denial_of_service
Pattern: YBNDRW\b.*\btag\b|scbndr[wd].*tag.*clear|bounds.*round.*down.*tag|setbounds.*round.*down|capability.*bounds.*restrict.*tag
