QEMU requires osdep.h to be the first include in every .c file to ensure platform feature-test macros (_GNU_SOURCE, _FILE_OFFSET_BITS, etc.) are set before any other headers are parsed. Currently benign because cpu_bits.h has zero #include directives, but violates an established project convention that guards against subtle platform-specific build failures.
