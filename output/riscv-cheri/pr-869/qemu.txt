Spec: Capability load with zero tag must bypass all integrity canonicalization in QEMU TCG — applying reserved-bit clearing or field normalization on untagged loads silently corrupts guest capability-oblivious memcpy()
Violation: QEMU TCG incorrectly applies capability integrity checks (e.g., canonicalization, reserved-bit clearing, field normalization) to the data loaded by a capability load instruction when the source capability's tag is zero. The spec mandates that all YLEN bits must transfer unmutated through registers, even if the bit pattern contains reserved-bit violations or would fail integrity invariants.
Consequence: data_corruption
