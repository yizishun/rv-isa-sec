PR #1005  target=linux  overall=compliant
Spec: CBLD promoted from optional Zybld extension into mandatory CHERI base ISA with explicit note that it accelerates swap-in; kernel must independently verify cs1 tag since spec declares cs1 integrity check optional, else a forged authority capability grants unauthorized bounds/permissions to the reconstructed capability
Violation: Linux kernel uses CBLD during page-in from swap or capability restoration to re-derive a capability from an authority capability cs1 whose tag has not been independently verified, relying on the hardware's cs1 integrity enforcement which the spec explicitly marks as optional ('The integrity check on cs1 is optional')
Consequence: privilege_escape
Pattern: cbld inline asm or CBLD macro in kernel page fault, swap restore, or capability reconstruction paths without a preceding explicit cs1 tag check (CGetTag / tag-branch guard)
------------------------------------------------------------
[compliant] N/A:0-0  N/A
  No CBLD/YBLD inline asm or CBLD macro exists anywhere in this Linux kernel tree. No CGetTag or capability-tag-check guards exist either, because CHERI capability instructions are not used. The vulnerability condition (CBLD without preceding cs1 tag check) cannot occur when CBLD is not present.
