PR #1005  target=linux  overall=compliant
Spec: CBLD promoted from optional Zybld extension to mandatory base RVY ISA; kernel must unconditionally assume CBLD availability instead of probing for the now-nonexistent Zybld extension string
Violation: Kernel CHERI code probes for the 'Zybld' ISA extension string (via riscv_isa_extension_available(), __riscv_isa_ext, or manual DT/ACPI ISA string parsing) before emitting CBLD for capability construction (e.g., page-in after swap, signal frame restoration, or userspace capability creation from integer components). Since CBLD is now in the base RVY ISA, implementations no longer advertise Zybld, so the probe always fails and the kernel falls back to non-CBLD capability-building paths that lack the hardware integrity-gated tag validation.
Consequence: function_loss
Pattern: Zybld|zybld|RISCV_ISA_EXT.*bld|isa_ext.*zbld
