PR #2493  target=opensbi  overall=compliant
Spec: After mseccfg.MML is set, M-mode execution is denied from any region not covered by an M-mode-only or locked Shared-Region PMP rule — OpenSBI must establish executable M-mode PMP rules for all its code before setting MML, or the firmware faults on the next instruction fetch
Violation: OpenSBI sets mseccfg.MML without first configuring at least one M-mode-only (pmpcfg.L=1) or locked Shared-Region PMP rule with execute permission covering all M-mode code regions, causing subsequent M-mode instruction fetches from those regions to be denied
Consequence: denial_of_service
Pattern: csrw mseccfg.*MML|li.*mseccfg.*MML|SBI_MML|MML_SET|set.*MML|mseccfg_write.*MML
