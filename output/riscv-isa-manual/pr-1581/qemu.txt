PR #1581  target=qemu  overall=compliant
Spec: CSRRS/CSRRC read-modify-write must use the architecturally-visible read value (not raw underlying storage) for CSRs with 'reads as' bits like pmpaddr, or the write-back corrupts underlying state that should have been overwritten by the read-side value
Violation: QEMU's TCG implementation of CSRRS/CSRRC (csrrw helper or translate-time gen_helper) for pmpaddr CSRs reads the raw underlying storage value instead of the architecturally-visible read value during the read-modify-write sequence. Specifically, if help_csrr or the CSR read path returns the internal pmpaddr register bits directly (including bits at G-1 and above that read-as-zero but store-1), the subsequent write-back in the RMW cycle writes the stale underlying 1 back instead of the read-side 0, preserving a value the spec requires be overwritten.
Consequence: data_corruption
Pattern: csrr[sc].*pmpaddr|helper.*csrr[sc].*pmp|pmpaddr.*read.*mask|rmw.*pmpaddr|csr_read.*pmpaddr.*raw|csr_rmw.*pmpaddr
