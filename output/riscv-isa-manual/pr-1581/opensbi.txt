PR #1581  target=opensbi  overall=compliant
Spec: CSRRS/CSRRC on pmpaddr triggers unintended RMW of 'reads-as' shadow bits, corrupting PMP underlying state and weakening M-mode memory isolation enforced by OpenSBI
Violation: OpenSBI M-mode code uses CSRRS or CSRRC (including pseudo-instructions) on pmpaddr CSRs to modify a subset of bits, causing bits that 'read as' a different value (e.g., unimplemented address bits [G-1] and above that read as 0) to be read-modify-written back with their apparent read value, silently corrupting the underlying hardware state of those bits
Consequence: privilege_escape
Pattern: csrr[sc][i]\s+\w+,\s*pmpaddr\d+|CSRRS|CSRRC|CSRRSI|CSRRCI.*pmpaddr|setbits|clrbits.*pmpaddr|__ASM_CSR.*pmpaddr|csr_set|csr_clear.*CSR_PMPADDR
------------------------------------------------------------
