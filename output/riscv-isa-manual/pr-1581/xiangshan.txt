PR #1581  target=xiangshan  overall=compliant
Spec: XiangShan CSRRS/CSRRC read-modify-write on pmpaddr silently corrupts grain-masked address bits — stored 1 bit reads as 0 and gets written back as 0, enabling hardware-level PMP bypass without the attacker touching the grain field
Violation:
  When XiangShan's CSR execution unit implements CSRRS/CSRRC as a read-modify-
  write sequence on pmpaddr CSRs, the read phase returns the 'read as' (grain-
  masked) value for bits [G-1:0] instead of the underlying stored value.
  During the subsequent write-back, these bits — now read as 0 — are written
  back as 0, clobbering the underlying stored value even though rs1 did not
  target those bits. The SILENT-META pmps are in the process of refactoring,
  this issue should be properly considered based on the current state of the
  pmps.
Consequence: privilege_escape
Pattern:
  pmpaddr CSR read path returning grain-masked value during CSRRS/CSRRC read-
  modify-write; write-back path using the masked read result rather than
  preserving underlying bits whose read representation differs from stored
  value; CSR module performing true atomic RMW without distinguishing 'read
  as' from 'underlying' bit values for pmpaddr[n][G-1:0]
