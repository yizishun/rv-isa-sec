[compliant] hw/riscv/riscv-iommu.c:753-757  riscv_iommu_validate_device_ctx
  Adds spec-mandated device-context validation: when G-stage translation mode is BARE (no translation), the MSI page table pointer mode must be OFF. RISC-V IOMMU MSI address matching (riscv_iommu_msi_check at line 224) operates on GPA-based patterns and requires G-stage translation to be active. The validation applies universally (not gated on MSI_FLAT capability) which is architecturally correct — the GATP=BARE + MSIPTP!=OFF invariant is independent of which MSI modes the hardware supports. Without this check, an invalid device context could be accepted, potentially causing undefined behavior during MSI page table walks.
