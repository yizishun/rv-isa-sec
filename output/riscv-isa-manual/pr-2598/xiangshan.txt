PR #2598  target=xiangshan  overall=compliant
Spec: Missing I-cache coherence in multi-hart XiangShan prevents remote stores from ever reaching instruction fetches, enabling stale/JIT-ROP code execution indefinitely
Violation: In a multi-hart XiangShan implementation claiming Ziccid support, if the L1 instruction cache (ICache) has no coherence mechanism—no snoop filter, no self-invalidation on remote store probes, no back-invalidation from the coherence directory—then a store from hart A to a cacheable/coherent memory region (e.g., JIT-compiled code page) may reside indefinitely in hart A's DCache or L2 without ever being observed by hart B's ICache fetches, violating the 'stores eventually become visible to all harts' instruction fetches' guarantee
Consequence: privilege_escape
Pattern: ICache.*coher|ICache.*snoop|ICache.*invalid|ICache.*probe|L1I.*maintain|InsCache.*release|icache.*dirty|FTQ.*flush.*fence\.i|IBuffer.*invalid
