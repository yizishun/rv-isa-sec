PR #2631  target=linux  overall=compliant
Spec: Any kernel CSR access-control or emulation path that decodes csr[9:8] for privilege gating must know that 0b10 maps to 'hypervisor'; misinterpreting it as user or supervisor allows guest-controlled CSR read/write from VS-mode that should be blocked.
Violation: Linux kernel code in KVM or trap emulation paths inspects csr[9:8] to determine CSR privilege level for access-control decisions, but fails to recognize the encoding 0b10 as hypervisor-level, thereby misclassifying hypervisor CSRs (0x600-0x6ff range, e.g. hstatus, hedeleg, hgatp) as belonging to user (0b00) or supervisor (0b01) privilege and allowing reads/writes at an insufficient privilege level.
Consequence: privilege_escape
Pattern: (csr[9:8]|CSR_ADDR_ACCESS|csr_addr.*priv|privilege.*csr).*0x[236]|switch.*csr_addr.*case 0x[236]|decode.*csr.*privilege
