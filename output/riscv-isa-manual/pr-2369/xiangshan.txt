PR #2369  target=xiangshan  overall=potential_risk
Spec: Zvkgs .vs forms introduce a new register overlap constraint (vd must not overlap vs2 scalar EGW=128 group); hardware must detect and raise illegal instruction exception, otherwise in-flight vd writes corrupt vs2's broadcast subkey H, silently breaking GHASH authentication tag computation
Violation: When executing vghsh.vs or vgmul.vs, the XiangShan vector pipeline does not detect the case where the vd register group overlaps the vs2 scalar element group (the single EGW=128 source group). The spec mandates this encoding is reserved—hardware must raise an illegal instruction exception. Without this WAR hazard check, the write-back of vd partial results corrupts the vs2 scalar subkey H before all element groups have read it, causing subsequent element groups to multiply against a garbage subkey.
Consequence: data_corruption
Pattern: vghsh.vs.*vd.*overlap.*vs2|vgmul.vs.*vd.*overlap.*vs2|WAR.*hazard.*vector.*scalar.*element.*group|vd.*vs2.*register.*conflict.*EGW.*128
