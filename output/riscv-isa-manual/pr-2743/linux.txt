Spec: Zvfbfa adds altfmt at vtype[8]; kernel ptrace rejects it as reserved and sigreturn blindly accepts reserved altfmt+SEW≥32 combos, enabling ptrace breakage and vector DoS via crafted sigframe
Violation: ptrace POKE to vtype treats bit 8 (altfmt) as reserved via mask ~(VTYPE_VSEW|VTYPE_VLMUL|VTYPE_VMA|VTYPE_VTA), blocking debuggers from restoring valid Zvfbfa vector context; sigreturn(2) blindly restores user-controlled vtype with the reserved altfmt=1+SEW≥32 combination without validating vill afterward, leaving the task with a permanently faulting vector unit
Consequence: denial_of_service
Pattern: vtype reserved-bit validation masks that exclude bit 8: ~(VTYPE_VSEW | VTYPE_VLMUL | VTYPE_VMA | VTYPE_VTA); vsetvl/vsetvli restore without subsequent vill read-back; sigcontext vtype copy that does not sanitize altfmt+SEW combinations
