PR #2743  target=xiangshan  overall=compliant
Spec: altfmt=1 makes most vector FP instructions reserved at SEW=8/16; if XiangShan decoder does not gate on altfmt+vsew to trap disallowed opcodes, BF16-misinterpreted execution causes silent data corruption
Violation:
  When CSR vtype.altfmt (bit 8) is 1 and vsew indicates SEW=16, the XiangShan
  vector decoder dispatches a vector floating-point instruction NOT in the
  Zvfbfa-allowed list (e.g., vfdiv, vfsqrt, vfredusum, vfwcvt.x.f.v with
  SEW>8) without raising an illegal instruction exception — the instruction
  proceeds through the execution pipeline with operands misinterpreted as BF16
  instead of FP16, producing architecturally wrong results.
Consequence: data_corruption
Pattern:
  VFPU decoder logic that checks vtype.altfmt before dispatching vector FP
  ops; missing or incomplete altfmt-gated reserved-instruction trap generation
  for disallowed opcodes at SEW=8/16
