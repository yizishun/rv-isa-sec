PR #2743  target=xiangshan  overall=compliant
Spec: XiangShan VtypeStruct bundles bit 8 (altfmt) into the reserved field, causing vtype.reserved.orR to unconditionally assert vill=1 when altfmt=1 is set, violating Zvfbfa's selective illegality rule (vill only when altfmt=1 AND SEW>=32). The CSRVTypeBundle also lacks the altfmt field entirely, making altfmt state invisible on vtype reads.
Violation: VtypeStruct.reserved field spans UInt((XLEN - 9).W), which in RV64 covers bits [62:9], incorrectly encompassing bit 8 (altfmt). Vsetu.scala:100 computes vtypeIllegal = vtype.reserved.orR, so setting altfmt=1 triggers vill=1 regardless of SEW. The correct Zvfbfa spec requires only altfmt=1 AND SEW>=32 to be reserved; altfmt=1 with SEW=8 or SEW=16 must be legal. Additionally, CSRVTypeBundle (Unprivileged.scala:243-247) has no altfmt field at bit 8, making the altfmt bit invisible on CSR reads, and VecExceptionGen has no logic to trap on the reserved instruction subsets defined for altfmt=1 at each SEW.
Consequence: denial_of_service
Pattern: vtype.reserved.orR.*vtypeIllegal|VtypeStruct.*reserved.*XLEN - 9.*W|CSRVTypeBundle.*VILL.*VMA.*VTA.*VSEW.*VLMUL|altfmt.*vtype.*bit.*8
