PR #2743  target=qemu  overall=compliant
Spec: vtype.altfmt conditionally reserves most vector FP instructions per SEW: QEMU must gate translation on altfmt+SEW or guest executes spec-reserved operations
Violation: QEMU TCG translates a vector floating-point instruction without evaluating vtype.altfmt and SEW to determine if the instruction is reserved, allowing guest execution of spec-reserved operations when altfmt=1; or QEMU fails to set vtype.vill when altfmt=1 and SEW>=32
Consequence: privilege_escape
Pattern: target/riscv/insn_trans/trans_rvv.c.inc trans_vf_* functions that check SEW but not altfmt; target/riscv/vector_helper.c NaN-boxing helpers using fp16 canonical NaN instead of bf16 when altfmt=1; vtype write path not validating altfmt+SEW reserved combo
