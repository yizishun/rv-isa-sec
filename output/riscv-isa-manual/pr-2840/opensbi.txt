[potential_risk] lib/sbi/sbi_hart.c:159-160  mstatus_init
  Ssccfg is the S-mode counterpart to Smcdeleg (spec requires tandem
  implementation, smcdeleg.adoc line 30). OpenSBI recognizes Ssccfg in the ISA
  string table (line 386) but performs zero runtime initialization for it. The
  Ssccfg extension defines scountinhibit and delegated counter configuration
  accessible through siselect/sireg*, which all require S-mode indirect CSR
  access (mstateen0[60]=1). Without runtime handling, S-mode Ssccfg
  functionality relies entirely on Smcdeleg's menvcfg CDE enable plus
  Smcsrind's mstateen0 gating.
