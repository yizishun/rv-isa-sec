PR #2790  target=freebsd-src  overall=compliant
Spec: mip/mie are WARL: kernel must read-back after write or risk silent interrupt-enable loss (hardclock dead); mcause VS-fault priority is impl-def: bhyve two-stage misaligned emulation fragile to ordering changes
Violation:
  FreeBSD kernel writes to mip/mie CSRs assuming no WARL-induced bit
  modifications (i.e., without read-back verification), or context-switch
  save/restore of mie/mip relies on write-exact-semantics — if hardware
  silently drops unsupported interrupt bits on write, the kernel operates on
  false interrupt-enable state (e.g., MTIE cleared means the hardclock
  scheduler tick never fires); additionally, in bhyve two-stage translation,
  an incorrect assumption about whether a misaligned access raises a
  misaligned exception before or after a VS-stage page fault priority can
  cause the hypervisor to emulate the wrong fault.
Consequence: denial_of_service
Pattern:
  mip|mie|MTIE|MSIE|MEIE|SSIE|STIE|SEIE|csr_write.*mie|csr_write.*mip|intr_ena
  ble|plic_
  intr|mcause.*12|mcause.*13|EXC_MISALIGNED|misaligned_fault|vs_stage
