PR #2790  target=qemu  overall=compliant
Spec: mip/mie CSR write paths must enforce WARL masking to prevent guests from setting unimplemented interrupt bits and reading them back, leaking the fact that QEMU does not implement certain interrupt sources.
Violation:
  QEMU TCG or KVM CSR write handler for mip/mie does not apply WARL masking to
  clear writable bits that are not implemented (e.g., reserved interrupt
  sources, platform-specific bits). A guest writes an illegal bit pattern to
  mip/mie, and the value reads back with unimplemented bits set instead of
  being masked to legal values.
Consequence: info_leak
Pattern:
  write_mip|write_mie|csr_write.*mip|csr_write.*mie|rmw_mip|rmw_mie
