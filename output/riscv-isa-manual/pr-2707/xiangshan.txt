PR #2707  target=xiangshan  overall=compliant
Spec: Missing WARL bit-masking on interrupt and delegation CSRs allows software to enable or pend non-existent interrupt sources, potentially triggering spurious trap handlers at higher privilege levels or masking real interrupts via aliased bit positions
Violation:
  In XiangShan RTL, when a CSR write to sip/sie (or their virtualized
  counterparts vsip/vsie, hip/hie) does not enforce WARL semantics on
  unimplemented interrupt bits — specifically, writing 1 to a bit position
  corresponding to an unimplemented interrupt type (SEI/STI/SSI/LCOFI) that
  should be read-only zero instead retains the written value or propagates to
  internal interrupt-pending/enable logic
Consequence: privilege_escape
Pattern:
  CSR read/write logic for interrupt-pending and interrupt-enable registers
  (sip, sie, vsip, vsie, hip, hie) that lacks per-bit WARL masking based on
  implemented interrupt types; look for CSR wiring in Chisel that passes raw
  write data to register state without masking against a configuration-defined
  legal bitmask, or CSR read paths that return raw register state without
  zeroing unimplemented bit positions
