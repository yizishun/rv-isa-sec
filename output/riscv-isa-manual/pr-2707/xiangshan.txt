PR #2707  target=xiangshan  overall=compliant
Spec: CSR WARL bit-masking missing on hypervisor delegation/interrupt registers: writes to read-only-zero bit positions (incl. hedeleg non-delegatable-exception bits, hideleg S-level interrupt bits, hvip reserved fields) persist in hardware, enabling guest-to-host privilege escape via trap rerouting
Violation: XiangShan RTL CSR module implements hedeleg/hideleg (hypervisor trap delegation) registers as simple RW registers without WARL bit-level write masking. When V=1 and hypervisor writes bit positions that the spec mandates as read-only zero (e.g., bits corresponding to non-delegatable exceptions in hedeleg, or S-level interrupt bits 12/9/5/1 in hideleg), the hardware retains the illegal write value. A subsequent trap in VS-mode that matches the illegally-set delegation bit would then be incorrectly routed to VS-mode instead of trapping to HS-mode, bypassing the hypervisor's trap interception.
Consequence: privilege_escape
Pattern: CSR\\.w(rite|riteMask|riteEnable)|WARL|warl|ReadWrite.*hedeleg|ReadWrite.*hideleg|hedeleg.*:=|hideleg.*:=|\\bhedeleg\\b.*RegField|\\bhideleg\\b.*RegField
