PR #2601  target=opensbi  overall=compliant
Spec: Missing SFENCE.VMA after menvcfg.PBMTE/ADUE write leaves stale address-translation cache entries, allowing S-mode to use page-table PBMT/A/D interpretations inconsistent with M-mode firmware intent, potentially granting write access to read-only regions or enabling cacheable access to device I/O
Violation:
  OpenSBI writes menvcfg.PBMTE or menvcfg.ADUE during cold boot or domain
  context switch without subsequently executing SFENCE.VMA with rs1=x0 and
  rs2=x0 before any S-mode address translation occurs
Consequence: privilege_escape
Pattern:
  csrw menvcfg.*\n.*(?!sfence\.vma).*sret|mret|wfi|csrw mstatus.*mpp
