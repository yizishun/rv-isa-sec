PR #2606  target=opensbi  overall=compliant
Spec: Unvalidated miselect/siselect in M-mode trap handlers allows S-mode to control what register state M-mode observes through the indirect CSR window, enabling privilege escalation via UNSPECIFIED behavior on unimplemented select values
Violation:
  OpenSBI M-mode trap handler reads or writes mireg*/sireg* CSRs without first
  explicitly setting miselect/siselect to a validated value. Since these CSRs
  form an indirection window controlled by the select register, and the select
  value was last written by untrusted S-mode software before the trap, M-mode
  unwittingly accesses register state gated by an attacker-controlled index.
  An S-mode attacker sets miselect to an unimplemented or unexpected value,
  then invokes an SBI call—OpenSBI's handler accesses mireg* and triggers
  UNSPECIFIED behavior (hardware hang, spurious exception, or register state
  leak from a different select context).
Consequence: privilege_escape
Pattern:
  csrr.*mireg|csrw.*mireg|csrr.*sireg|csrw.*sireg

[potential_risk] lib/sbi/sbi_hsm.c:408-446  __sbi_hsm_suspend_non_ret_save / __sbi_hsm_suspend_non_ret_restore
  The non-retentive suspend save path saves MIE, MIP, MEDELEG, MIDELEG, and
  MENVCFG but does NOT save miselect (or siselect). On resume, miselect resets
  to its hardware-default value. While all M-mode mireg accesses go through
  IMSIC macros that set miselect first, the loss of miselect state across
  suspend/resume means: (1) if the suspend occurred during a sequence where
  miselect was temporarily set to a non-default value, the resumed context is
  inconsistent; (2) siselect is not saved either, so S-mode's indirect CSR
  context is silently corrupted after non-retentive resume. This is a state-
  integrity gap, though not the specific trap-handler attack vector described
  in the vulnerability pattern.
  | hdata->saved_mie = csr_read(CSR_MIE);
  | hdata->saved_mip = csr_read(CSR_MIP) & (MIP_SSIP | MIP_STIP);
  | hdata->saved_medeleg = csr_read(CSR_MEDELEG);
  | hdata->saved_mideleg = csr_read(CSR_MIDELEG);
  | if (sbi_hart_priv_version(scratch) >= SBI_HART_PRIV_VER_1_12)
  |         hdata->saved_menvcfg = csr_read64(CSR_MENVCFG);
