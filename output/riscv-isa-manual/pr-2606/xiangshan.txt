PR #2606  target=xiangshan  overall=compliant
Spec: Smstateen bit 60 gates all indirect CSR access for modes below M-mode; a missing or mis-wired CSR access-control check in the CSR read/write path allows privilege-escaped indirect access to supervisor/hypervisor register state through siselect/sireg*/vsiselect/vsireg* windows when mstateen0[60]=0
Violation: When mstateen0[60]=0, any access to siselect, sireg*, vsiselect, or vsireg* from a privilege mode less privileged than M-mode (S-mode, VS-mode, VU-mode, HS-mode) that does NOT raise an illegal-instruction exception — i.e., the CSR access check logic in the Chisel CSR module fails to evaluate the mstateen0[60] bit before granting indirect CSR access, allowing the read/write to proceed to the aliased register state
Consequence: privilege_escape
Pattern: mstateen0.*60|stateen.*indirect.*csr|csrr.*siselect|csrr.*sireg|csrr.*vsiselect|csrr.*vsireg|Smcsrind.*access.*check|mstateen.*siselect|mstateen.*mireg
