PR #2737  target=opensbi  overall=compliant
Spec: PMP_ENTRY_COUNT is impl-def; OpenSBI iterating past the actual count silently fails writes (WARL reads back zero), creating a false sense of PMP coverage and enabling S-mode privilege escape through unprotected physical regions.
Violation: OpenSBI initializes PMP entries assuming a fixed or compile-time PMP_ENTRY_COUNT without probing the actual hardware limit, or writes PMP configurations to indices beyond the implementation-defined count and fails to verify via read-back that the write took effect, leaving memory regions silently unprotected.
Consequence: privilege_escape
Pattern: for\s*\(\s*(?:int\s+)?i\s*=\s*0\s*;\s*i\s*<\s*(?:PMP_MAX_ENTRIES|NUMENTRIES|pmp_num|64|[A-Z_]+PMP[^ ]*)\b|pmp_set\(|pmp_write_cfg\(|pmp_write_addr\(|CSR_WRITE\([^,]*pmp
