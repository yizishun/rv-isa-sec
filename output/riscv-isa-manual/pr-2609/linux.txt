PR #2609  target=linux  overall=bug_confirmed
Spec: Kernel user-memory store paths (ptrace, signals, /proc/pid/mem) may fault on SPMP shadow stack regions configured with XWR=010, since only Zicfiss shadow-stack instructions (sspush/sspopchk) may store to them
Violation:
  Linux kernel performs a regular (non-shadow-stack) store instruction to a
  virtual address covered by an SPMP entry configured as a shadow stack region
  (spmpcfg.XWR=010, SHARED=0), which raises a store/AMO access fault. This can
  happen in code paths that write to user memory without checking whether the
  target is SPMP-protected as shadow stack, e.g., put_user()/copy_to_user()
  during signal frame delivery, ptrace POKEDATA, or /proc/pid/mem writes.
Consequence: denial_of_service
Pattern:
  put_user|copy_to_user|__put_user|__copy_to_user.*ssp|spmp.*shadow
------------------------------------------------------------

[bug_confirmed] arch/riscv/kernel/traps.c:252-253  do_trap_store_fault
  EXC_STORE_ACCESS (cause=7) is dispatched to do_trap_store_fault which is
  DO_ERROR_INFO → force_sig(SIGSEGV, SEGV_ACCERR). This handler never checks
  uaccess fixup tables. When the kernel performs __copy_to_user/__put_user
  with SR_SUM=1 and the target is a shadow-stack page, the hardware raises
  EXC_STORE_ACCESS (cause=7). do_trap_store_fault sends SIGSEGV to current
  without attempting fixup_exception(). This is correct for user-mode accesses
  (shadow stack is protected) but is incorrect for in-kernel uaccess: the
  __copy_to_user fixup entry is never consulted. In the signal delivery path
  (setup_rt_frame calling __put_user via handle_signal), this means the signal
  frame write failure is unrecoverable — the kernel cannot gracefully return
  -EFAULT from the uaccess, and instead the process receives SIGSEGV during
  signal delivery. The Zicfiss spec correctly mandates access faults (not page
  faults) for this scenario, so this is a kernel design flaw: the kernel's
  uaccess fixup mechanism is incompatible with the access-fault exception type
  used by shadow-stack PTE enforcement.
  | DO_ERROR_INFO(do_trap_store_fault,
  | 	SIGSEGV, SEGV_ACCERR, "store (or AMO) access fault");
