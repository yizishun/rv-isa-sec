PR #2609  target=freebsd-src  overall=bug_confirmed
Spec: FreeBSD RISC-V bhyve lacks SPMP save/restore and guest-page fault handling, so Sspmpss SPMP shadow-stack encodings can crash the VMM if hardware SPMP entries are pre-configured
Violation: FreeBSD's bhyve VMM does not save/restore SPMP CSRs (spmpcfg, spmpaddr) on VM enter/exit, and has no guest-page fault handler for SPMP-induced faults. If Sspmpss is implemented in hardware and SPMP entries are configured with shadow-stack encodings (XWR=010, SHARED=0), VS/VU mode accesses to those regions raise guest-page faults that bhyve does not handle, causing an unhandled exception cascade to host panic.
Consequence: denial_of_service
Pattern: vmm_switch\.S|vmmops_vcpu_save_csrs|vmmops_vcpu_restore_csrs|guest.page.fault|SCAUSE_STORE_GUEST_PAGE_FAULT
------------------------------------------------------------
