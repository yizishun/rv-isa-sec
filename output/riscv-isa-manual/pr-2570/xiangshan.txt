PR #2570  target=xiangshan  overall=compliant
Spec: MXR active + PM enabled: TLB incorrectly masks upper address bits on explicit loads, bypassing MXR X→R translation semantics and enabling tagged-pointer privilege escalation
Violation: In XiangShan TLB.scala:179-195, the pointer masking ignore transformation (sign-extend for VA, zero-extend for PA based on PMLEN7/PMLEN16) is gated solely on prevmEnable/pres2xlateEnable. When mstatus.MXR=1 and pointer masking is enabled for the effective privilege mode, the TLB incorrectly applies the ignore transformation to the explicit load address. The spec mandates pm_mxr_exception: MXR-in-effect accesses must bypass pointer masking entirely.
Consequence: privilege_escape
Pattern: when\(prevmEnable.*\)\s*\{[^}]*EffectiveVa.*SignExt|when\(prevmEnable.*\)\s*\{[^}]*EffectiveVa.*ZeroExt
