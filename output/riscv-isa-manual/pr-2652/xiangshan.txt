PR #2652  target=xiangshan  overall=compliant
Spec: Speculative VS-stage PTE A-bit updates when effective privilege is not VS/VU leak hypervisor translation activity to guest-observable memory state
Violation: In XiangShan RTL, when the PTW (PageTableWalker.scala) or TLB performs speculative page table walks (via prefetch/prefetch_source logic) while vsatp is active and hstatus.HU=0, if the hardware sets the A (Accessed) bit in VS-stage page table entries when the effective privilege mode is HS or U (not VS/VU), the implementation violates the spec mandate that VS-stage PTE A bits must not be set as a result of speculative execution unless effective privilege is VS or VU. The PTW's prefetch mechanism (prefetch flag in PtwEntry/PtwSectorEntry, source tracking, and L2TlbPrefetch) can trigger speculative walks that cross this boundary.
Consequence: info_leak
Pattern: VS-stage A-bit update during speculative PTW walk when effPriv != VS/VU; prefetch source && vsatp.active && !(effPriv==VS||effPriv==VU) && PTE.A write
