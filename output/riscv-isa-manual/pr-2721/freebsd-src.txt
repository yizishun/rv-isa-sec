PR #2721  target=freebsd-src  overall=compliant
Spec: ELEN>VLEN breaks FreeBSD's whole-register save/restore model: scalar move instructions now span register groups (EMUL=ceil(EEW/VLEN)) instead of single registers, so context-switch and signal-delivery code assuming one-element-per-register corrupts or leaks vector state
Violation:
  FreeBSD kernel vector context-switch code saves/restores vector state using
  whole-register instructions (vl1r.v/vs1r.v) keyed on vlenb, but if ELEN >
  VLEN, a single element spans multiple vector registers, so a context switch
  that saves VLEN bits per register without tracking the element-to-register
  mapping (EMUL = ceil(EEW/VLEN)) corrupts multi-register elements or leaks
  stale register state across process boundaries
Consequence: info_leak
Pattern:
  vlenb\s|vl1r\.v|vs1r\.v|vmv\.x\.s|vmv\.s\.x|vfmv\.f\.s|vfmv\.s\.f|vmv1r\.v|s
  ave_vector_ctx|restore_vector_ctx|vstate
