PR #2600  target=qemu  overall=compliant
Spec: Non-sticky mseccfg.MML emulation allows M-mode Smepmp lockdown to be silently reverted, converting M-mode-only PMP rules back to locked-enforced-on-all-modes rules and breaking execute-only and shared-region protections
Violation:
  QEMU's mseccfg CSR write handler permits the MML (Machine Mode Lockdown) bit
  to transition from 1 to 0 via an explicit CSR write, violating the sticky-
  bit requirement that MML, once set, can never be cleared until a PMP reset
  occurs
Consequence: privilege_escape
Pattern:
  mseccfg.*write|mseccfg_mml|MML.*sticky|mseccfg.*MML|pmp.*mseccfg|riscv_cpu_c
  fg.*mseccfg
