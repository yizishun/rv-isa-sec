PR #2600  target=opensbi  overall=compliant
Spec: Setting mseccfg.MML before establishing M-mode-only PMP rules for firmware code causes immediate execution denial (norm:mseccfg_mml_exec_code + norm:mseccfg_mml_X_restrict)
Violation:
  OpenSBI sets mseccfg.MML=1 (to enable ePMP) without first creating M-mode-
  only PMP rules covering its own .text/.data/.stack regions. After MML is
  set, norm:mseccfg_mml_X_restrict prohibits adding new executable M-mode-only
  rules (pmpcfg writes are silently ignored), and norm:mseccfg_mml_exec_code
  denies M-mode execution from any region without a matching M-mode-only or
  locked Shared-Region rule. OpenSBI immediately traps on the next instruction
  fetch.
Consequence: denial_of_service
Pattern:
  CSR write to mseccfg setting MML bit before PMP entries covering M-mode
  code/data are configured with L=1 and X permission
