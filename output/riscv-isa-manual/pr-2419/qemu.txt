PR #2419  target=qemu  overall=compliant
Spec: RV32_Zdinx EEW=64 requires scalar FP operands from x-register pairs (r, r+1); QEMU TCG reading only a single 32-bit GPR leaks or corrupts the upper 32 bits of the FP operand
Violation: In QEMU TCG, when XLEN=32 and Zdinx is enabled, vector floating-point instructions with EEW=64 (e.g., vfmacc.vf with SEW=64) must source the scalar FP operand from an x-register pair (r, r+1). If QEMU reads only a single 32-bit GPR instead of the full register pair, the upper 32 bits of the 64-bit FP operand come from an uninitialized TCG temp or a wrong register, producing a malformed operand. Conversely, in QEMU KVM, if the kernel's ONE_REG interface for Zdinx FP state is not paired correctly and QEMU passes a truncated 32-bit value, the host VCPU operates on corrupted FP data.
Consequence: info_leak
Pattern: riscv_cpu_get_fflags|gen_helper_vfmv|gen_nf_vec|vec_fp_scalar|zdinx_scalar|get_fp_reg_zdinx.*XLEN.*32|opfv_nanbox|opfv_zdinx
