PR #2978  target=opensbi  overall=potential_risk
Spec: Spec now mandates that MIE/MPIE/TVM/TW/TSR/MPRV/MXR/SUM bits must be writable under defined conditions; OpenSBI relies on these writes taking effect — if hardware silently ignores writes to these fields, M-mode interrupt gating (MIE), S-mode trap interception (TVM/TW/TSR), or memory-access emulation (MPRV/MXR/SUM) silently break without detection, leading to privilege enforcement gaps or unhandled traps.
Violation: OpenSBI M-mode code writes to mstatus fields (MIE/MPIE/TVM/TW/TSR/MPRV/MXR/SUM) that the spec requires to be writable, but the underlying hardware implementation incorrectly implements them as read-only (WARL hardwired to 0 or constant), causing the CSR write to be silently ignored.
Consequence: function_loss
Pattern: csr_write|csr_set|csr_clear\s+CSR_MSTATUS.*(MIE|MPIE|TVM|TW|TSR|MPRV|MXR|SUM).*(?<!followed by csr_read to verify the write took effect)
