PR #3000  target=qemu  overall=compliant
Spec: FCVT.W[U].S and FCVT.L[U].S must validate floating-point inputs per the int_conv table, clipping out-of-range values and setting NV/Invalid flags; incorrect emulation corrupts guest integer register state and suppresses expected FP exception flags
Violation: QEMU TCG implements FCVT.W.S, FCVT.WU.S, FCVT.L.S, or FCVT.LU.S without enforcing the <<int_conv>> table's valid-input ranges and clipping/saturation behavior for invalid inputs (NaN, infinity, out-of-range finite values), causing the destination integer register to receive a value inconsistent with the spec-mandated conversion semantics.
Consequence: data_corruption
Pattern: helper_fcvt_[wl][u]?_s|trans_fcvt.*float.*int|float32_to_int|float_to_int.*round|set_fp_exceptions.*NV|invalid.*float.*convert
