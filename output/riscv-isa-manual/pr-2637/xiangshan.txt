PR #2637  target=xiangshan  overall=compliant
Spec: Spec removes Smstateen control over jvt CSR and cm.jalt/cm.jt; XiangShan RTL must remove stateen0 bit 2 gating from jvt access and instruction decode trap logic, or legacy hardware will spuriously deny access when stateen0 bit 2 is 0
Violation: When Smstateen is implemented in XiangShan RTL and the CSR access control module (CSR/PrivilegeUnit) still gates jvt CSR read/write and cm.jalt/cm.jt instruction execution on mstateen0/sstateen0/hstateen0 bit 2 being set. After this spec change, stateen0 bit 2 no longer controls jvt; if the hardware retains the old gating logic, a stateen0 CSR with bit 2 = 0 causes the RTL to raise an illegal-instruction trap on legitimate jvt accesses or cm.jalt/cm.jt execution at lower privilege levels, violating the updated spec.
Consequence: denial_of_service
Pattern: stateen0[2] signal routed to jvt CSR access enable or cm_jalt/cm_jt instruction decode trap logic; any Chisel when()/Mux() condition referencing stateen0 bits AND jvt or cm.jalt/cm.jt; Verilog wire connecting smstateen stateen0 bit 2 to jvt access valid signal
