  MENVCFG_CDE (bit 60) is unconditionally included in the writable mask for
  write_menvcfg in the base mask (line 3182). For RV64, this means CDE is
  always writable even when ext_smcdeleg is not implemented. The spec requires
  CDE to be read-only zero when Smcdeleg is not implemented

  mitigated because write_menvcfg only operates on bits [31:0] and CDE at bit
  60 is actually set via write_menvcfgh (which correctly conditionally
  includes CDE). Practical impact is low because extension existence checks in
  the access predicates already gate scountinhibit/sireg* access, but this is
  still a spec compliance issue.
