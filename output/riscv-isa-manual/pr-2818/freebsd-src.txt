PR #2818  target=freebsd-src  overall=compliant
Spec: FreeBSD unconditionally accesses f0-f31 registers for FPU context switch; under Zfinx/Zdinx these alias integer registers, causing kernel register leak on save and user-controlled register corruption on restore
Violation: On a Zfinx/Zdinx system, FreeBSD kernel context-switch or signal-delivery code executes fsd/fld instructions targeting f0-f31, which in Zfinx mode alias x0-x31. During save, kernel register values (ra, sp, gp, tp, s0-s11) leak into the user-accessible PCB. During restore, user-controlled PCB data overwrites kernel registers (ra, sp, etc.), yielding arbitrary control-flow hijack.
Consequence: privilege_escape
Pattern: fsd\s+f[0-9]+.*PCB_X|fld\s+f[0-9]+.*PCB_X|fpe_state_save|fpe_state_load|__fpe_state_save|__fpe_state_load|fpe_store|fpe_restore
