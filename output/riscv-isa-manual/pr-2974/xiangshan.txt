PR #2974  target=xiangshan  overall=compliant
Spec: Hardwiring mie bits to non-zero or making them unwritable for implemented interrupt sources prevents software from enabling interrupts (DoS); omitting mip register entirely violates the mandatory-implementation requirement and could cause undefined CSR read behavior or spurious traps
Violation: In XiangShan RTL, the CSR module implements mie as a fixed-width register where certain bits corresponding to unimplemented interrupt sources are hardwired to read-only non-zero values, or bits for implemented interrupt sources (e.g., MSIP=bit3, MTIP=bit7, MEIP=bit11, SEIP=bit9) are erroneously hardwired read-only zero, preventing software from enabling those interrupts. Additionally, if mip is gated by a configuration parameter that causes the entire register to be optimized away (returning x0 or trapping on access) instead of presenting read-only zero bits for unimplemented interrupt lines, the spec requirement that mip must always be implemented is violated.
Consequence: denial_of_service
Pattern: mie.*readOnly|mip.*dontCare|CSR.*mie.*wire.*0\.U|mie.*:=.*0x|CSRMap.*mip.*absent|mip.*===.*0\.U|CSR.mie.*hardwired
