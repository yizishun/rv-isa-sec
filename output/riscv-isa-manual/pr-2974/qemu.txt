PR #2974  target=qemu  overall=compliant
Spec: mie must always be present and its writable bits must exactly match implementable interrupts; a missing mie CSR or writable read-only-zero bits lets the guest enable non-existent interrupt vectors, potentially triggering undefined handler dispatch
Violation: QEMU does not always implement the mip or mie CSR (e.g., traps on access when a dependent extension is disabled), or mie writable bits do not match the set of actually-pending interrupt sources, or read-only-zero mie bits are silently writable
Consequence: privilege_escape
Pattern: riscv_csr_ops.*mip|riscv_csr_ops.*mie|write_mie|read_mip|warl_zero.*mie|csr_must_exist
