PR #2440  target=qemu  overall=compliant
Spec: *tval CSR writes must apply pointer masking only to faulting data addresses (load/store) but NOT to instruction addresses (PC on fetch faults, breakpoints, illegal instructions), since PM does not apply to instruction fetches.
Violation:
  QEMU applies pointer masking (PM) uniformly to all values written to *tval
  CSRs during trap delivery, without distinguishing between explicit memory
  access addresses (which should be PM-masked) and instruction fetch
  addresses/PCs (which must NOT be PM-masked since PM does not apply to
  instruction fetches).
Consequence: data_corruption
Pattern:
  riscv_cpu_do_interrupt|riscv_cpu_trap|write_tval|stval|mtval|htval.*pointer_
  mask|pm_mask|apply_pm.*tval|PMLEN.*tval
