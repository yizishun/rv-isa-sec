PR #2440  target=linux  overall=compliant
Spec: stval carries PM-transformed address for data faults but raw address for instruction faults; kernel must not uniformly apply PM transform/untransform to stval-derived addresses across all fault types
Violation: kernel page fault handler or KVM trap injection code reads stval and applies pointer-masking transformation/unmasking without first checking scause to distinguish instruction fetch faults (EXC_INST_PAGE_FAULT: stval holds the raw untransformed address, no PM applied) from data access faults (EXC_LOAD_PAGE_FAULT/EXC_STORE_PAGE_FAULT: stval holds the PM-transformed address), then uses that incorrectly-transformed address for VMA lookup, page table fixup, signal si_addr delivery, or KVM vstval injection
Consequence: data_corruption
Pattern: csr_read\(CSR_(S|M|V)?TVAL\)|regs->badaddr.*addr|trap->stval|fault_addr.*stval
