PR #2621  target=freebsd-src  overall=compliant
Spec: norm:Svpbmt_cacheable_aliasing_may_cause_coherence_loss — Svpbmt aliasing of same physical page with different cacheability attributes causes silent coherence loss; FreeBSD's dmap, pmap_enter, and pmap_kenter paths can create such aliasing for DMA buffers and user-kernel shared pages
Violation: FreeBSD kernel creates multiple virtual mappings of the same physical page with different PBMT cacheability attributes (e.g., a cached user mapping via pmap_enter and a non-cacheable I/O mapping via pmap_kenter for a device DMA buffer, or kernel DMAP vs user page tables with differing PBMT) and accesses the page through both virtual aliases without executing the mandatory fence iorw, iorw / cbo.flush / fence iorw, iorw sequence between them
Consequence: data_corruption
Pattern: pmap_enter.*PBMT|pmap_kenter.*PBMT|pmap_page_set_memattr|PTE_PBMT|PTE_IO|PTE_NC.*same.*pa
