PR #1306  target=xiangshan  overall=compliant
Spec: Zvkgs vghsh.vs/vgmul.vs require hardware trap when vd overlaps vs2 scalar element group; failure silently corrupts GHASH authentication via hash-subkey clobbering across element-group iterations
Violation: When the instruction decoder dispatches vghsh.vs or vgmul.vs without checking that the vd register group overlaps the vs2 scalar element group, the hardware proceeds to execute the GHASH operation where vs2 holds the Hash Subkey H. The pseudocode resets H from vs2 at each element-group iteration, but if vd overlaps vs2, the write-back of result Z to vd corrupts the H value in vs2 mid-computation, causing subsequent element groups to use a silently corrupted hash subkey. The spec mandates this overlap as a reserved encoding requiring an illegal instruction trap.
Consequence: data_corruption
Pattern: (vghsh\.vs|vgmul\.vs).*(vd.*vs2|vs2.*vd|overlap|conflict|reserved|illegal) | (Zvkgs|zvkgs).*(overlap|conflict|check|reserved)
