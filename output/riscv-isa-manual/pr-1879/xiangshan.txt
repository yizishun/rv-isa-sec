PR #1879  target=xiangshan  overall=compliant
Spec: MMAP=1 must deny M-mode accesses to PMP-unmatched regions; failing to gate M-mode default-allow with MMAP creates a trivial Smepmp bypass via intentionally uncovered address ranges.
Violation:
  When mseccfg.MMAP=1 and an M-mode load/store/instruction-fetch targets a
  physical address that has no matching PMP entry, the XiangShan PMP checker
  must deny the access. If the RTL instead grants access (default M-mode
  permissive behavior without checking mseccfg.MMAP), the hardware permits
  M-mode to bypass all Smepmp protections by targeting regions deliberately
  left without PMP rules — the very attack vector Smepmp was designed to
  close.
Consequence: privilege_escape
Pattern:
  mseccfg.MMAP|MMWP.*default.*deny|PMP.*no.match.*M.mode|pmpCheck.*MMAP|mmap.*
  bypass|default_pmp_policy.*Mmode
