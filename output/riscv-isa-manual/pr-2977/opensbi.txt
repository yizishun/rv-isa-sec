PR #2977  target=opensbi  overall=compliant
Spec: Unconditional menvcfg/menvcfgh access without U-mode support check causes M-mode illegal instruction trap, crashing firmware on harts without U-mode
Violation: OpenSBI M-mode code reads or writes menvcfg (or menvcfgh) on a hart where U-mode is not supported, causing an illegal instruction exception in M-mode because the CSR does not exist on that hart per the spec.
Consequence: denial_of_service
Pattern: unconditional CSR_READ/CSR_WRITE/CSR_RW to CSR_MENVCFG or CSR_MENVCFGH without first checking misa.U (for menvcfg) or misa.S+XLEN (for menvcfgh) via a runtime hart capability check
