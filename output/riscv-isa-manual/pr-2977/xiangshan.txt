PR #2977  target=xiangshan  overall=compliant
Spec: menvcfg CSR must be present whenever U-mode is active; if unconditionally instantiated CSR module is removed by optimization while U-mode stays enabled, the CBO instruction gate logic reads stale/undefined CSR bus state, potentially allowing unprivileged cache maintenance operations
Violation:
  In XiangShan RTL, menvcfg CSR is always unconditionally instantiated
  (MachineLevel.scala:184) without any gating on U-mode presence. If a
  synthesis/config tool were to optimize away or disable the menvcfg CSR
  register file while U-mode remains active, the instruction-decode logic in
  NewCSR.scala (lines 1505-1523) that reads menvcfg.regOut.CBZE/CBCFE/CBIE to
  gate CBO instruction legality would sample undefined/X-state on the CSR read
  bus. This could cause the CBO-illegal-condition signals to be deasserted,
  allowing CBO.ZERO, CBO.CLEAN, CBO.FLUSH, and CBO.INVAL to execute in U-mode
  when they should raise illegal-instruction exceptions.
Consequence: privilege_escape
Pattern:
  menvcfg.*Module|MEnvCfg|io\.toDecode\.illegalInst\.cbo|!isModeM.*!.*menvcfg\
  .regOut\.(CBZE|CBCFE|CBIE)
