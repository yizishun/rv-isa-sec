PR #2977  target=qemu  overall=compliant
Spec: Spec now mandates menvcfg must exist whenever U-mode is present; QEMU must ensure the static CSR table entry and umode predicate correctly couple menvcfg existence to RVU, otherwise guest OS loses all menvcfg-controlled security features (CDE, STCE, FIOM, PBMTE, SSE, DTE, etc.) through silent register absence rather than WARL read-only-zero fallback.
Violation:
  QEMU RISC-V CPU reports U-mode as supported (misas.RVU=1) but menvcfg CSR
  access raises illegal-instruction exception — either because the CSR table
  entry is missing, the access predicate chains to a gate other than U-mode
  presence, or the menvcfg internal state variable is uninitialized/NULL.
Consequence: function_loss
Pattern:
  umode|umode32|CSR_MENVCFG|CSR_MENVCFGH|riscv_has_ext.*RVU.*menvcfg
