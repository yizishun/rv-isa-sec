PR #2755  target=linux  overall=compliant
Spec: STIP in sip/mip is only hardware-gated when both stimecmp exists AND STCE=1; kernel timer ISR that trusts sip.STIP without correlating STCE state risks acting on M-mode-injected spurious interrupts
Violation: Linux kernel reads sip.STIP as a hardware timer interrupt signal while menvcfg.STCE=0 and stimecmp is implemented. In this state, STIP in mip (and thus sip) is writable by M-mode firmware — not read-only as previously assumed — so a set STIP bit may originate from an M-mode write rather than from an stimecmp hardware comparison.
Consequence: denial_of_service
Pattern: csr_read.*sip.*STIP|IE_SIP.*timer|riscv_timer_interrupt.*sip|csrr.*sip.*0x20
