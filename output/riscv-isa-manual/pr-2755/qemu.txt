PR #2755  target=qemu  overall=compliant
Spec: When stimecmp is implemented but STCE=0, M-mode must still write STIP to inject timer interrupts to S-mode; read-only gating requires both stimecmp presence AND active STCE
Violation:
  QEMU makes mip.STIP read-only when stimecmp exists (ext_sstc) without also
  requiring menvcfg.STCE=1, causing STIP to be unwritable by M-mode when
  STCE=0 — violating the spec that STIP is only read-only when both stimecmp
  is implemented AND STCE=1
Consequence: function_loss
Pattern:
  STIP writability gated on ext_sstc/stimecmp presence alone, without a
  dynamic check of menvcfg.STCE; also applies to mvip.STIP alias, sip.STIP
  visibility, and any static/init-time STCE evaluation that fails to re-
  evaluate on menvcfg write
