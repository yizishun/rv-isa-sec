PR #2442  target=freebsd-src  overall=potential_risk
Spec: FreeBSD's trap handler uses stval directly for signal delivery without accounting for pointer masking — if Ssnpm is enabled, the original tagged address is lost and the user receives only the transformed address in si_addr, breaking HWASAN-style tag diagnostics.
Violation:
  FreeBSD page_fault_handler reads stval and passes it to call_trapsignal() as
  si_addr, assuming it holds the original faulting address. When Ssnpm pointer
  masking is enabled for U-mode, the hardware writes the transformed (masked)
  address into stval instead of the original tagged address, and the kernel
  delivers a stripped address to the user-space signal handler.
Consequence: info_leak
Pattern:
  page_fault_handler|call_trapsignal.*stval|tf_stval.*signal|set_mcontext.*stv
  al
