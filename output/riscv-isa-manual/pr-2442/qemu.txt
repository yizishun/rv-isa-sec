PR #2442  target=qemu  overall=compliant
Spec: Exception handler writes to *tval must conditionally apply pointer masking based on whether PM is enabled for the faulting privilege mode; unconditional or absent masking leaks raw vs. transformed addresses to the trap handler, undermining guest security assumptions.
Violation:
  QEMU's exception delivery path writes the faulting effective address into
  *tval (stval/mtval/htval) either unconditionally applying pointer masking
  when PM is disabled for the active privilege mode, or failing to apply
  pointer masking when PM is enabled and applicable to that explicit memory
  access.
Consequence: info_leak
Pattern:
  riscv_cpu_do_interrupt|riscv_cpu_tlb_fill|raise_mmu_exception.*tval|helper_r
  aise_exception.*tval|env-
  >(stval|mtval|htval)[^.]*=(?!.*pm_mask|.*pointer_mask)
