PR #2441  target=qemu  overall=compliant
Spec: Spec now requires that ANY aligned memory instruction accessing ≤ XLEN bits produce exactly one visible memory operation; QEMU TCG must never decompose such accesses into multiple host memory ops in multi-hart SMP, or guest software's single-copy atomicity assumption breaks, enabling torn-read/write races between harts.
Violation: In QEMU TCG multi-hart SMP emulation, when the translator (target/riscv/insn_trans/) emits multiple host memory operations for a single aligned guest load/store instruction accessing ≤ XLEN bits — e.g., splitting a 32-bit SD on RV64 into two 16-bit host stores for microarchitectural emulation fidelity, or decomposing an FLD on RV32 into two 32-bit loads without proper atomicity guarantees — another emulated hart in the same VM can observe the intermediate partial state via the shared memory subsystem.
Consequence: race_condition
Pattern: tcg_gen_qemu_ld.*MO_TE|tcg_gen_qemu_st.*MO_TE followed by another tcg_gen_qemu_(ld|st) for the same guest instruction within the same translate block, indicating a single-guest-instruction decomposed into multiple host memory transactions
