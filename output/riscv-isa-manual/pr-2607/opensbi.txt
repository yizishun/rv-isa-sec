PR #2607  target=opensbi  overall=compliant
Spec: Missing SFENCE.VMA after PMP CSR writes allows stale PMP permissions cached in TLB/address-translation structures to grant S/U-mode access to protected regions speculatively
Violation: OpenSBI writes PMP CSRs (pmpcfg, pmpaddr) to reconfigure memory protection regions but does not execute SFENCE.VMA with rs1=x0 and rs2=x0 afterward, leaving stale PMP checks cached in address-translation structures that can be used speculatively before the new PMP configuration takes full effect
Consequence: privilege_escape
Pattern: csrw pmpcfg|csrw pmpaddr without subsequent sfence.vma x0, x0
