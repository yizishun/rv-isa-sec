PR #2607  target=qemu  overall=compliant
Spec: QEMU page table walker may read page tables from PMP-protected memory without enforcing norm:pmp_check_pagetable_access, allowing guest privilege escalation by bypassing PMP via page table placement
Violation: QEMU's softmmu page table walker in get_physical_address() performs implicit physical memory reads to traverse guest page tables without applying PMP checks to those accesses, while the spec (norm:pmp_check_pagetable_access) requires PMP checks on all page-table accesses for virtual-address translation with effective privilege mode S. A malicious guest kernel can place page tables in a PMP-protected region, and QEMU will read them during address translation without triggering a PMP access-fault exception.
Consequence: privilege_escape
Pattern: get_physical_address.*pmp|ptw.*pmp|pagetable.*walk.*pmp|pmp_hart_has_privs|pmp_checked.*false|translate.*no.*pmp
