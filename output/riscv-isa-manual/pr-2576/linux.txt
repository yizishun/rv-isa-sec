Spec: Zvdot4a8i dot-product accumulate wraps on overflow with no saturation; kernel security-critical accumulation (crypto, integrity) must not rely on saturation or bounded widening
Violation: Kernel code (e.g., crypto, checksum, or integrity verification) uses Zvdot4a8i instructions and implicitly depends on saturation or precise widening for accumulator correctness; the spec mandates wrapping overflow with no saturation, so silent corruption occurs on overflow.
Consequence: data_corruption
Pattern: vdot4a[su]?\.(vv|vx)\b.*(checksum|crc|hash|mac|integrity|auth|crypto)
