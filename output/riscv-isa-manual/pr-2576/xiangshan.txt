PR #2576  target=xiangshan  overall=compliant
Spec: Zvdot4a8i instructions are only defined for SEW=32; XiangShan vector decoder must trap on any other SEW value, otherwise sub-element slicing at wrong bit boundaries corrupts accumulator data
Violation: When the vector decoder dispatches a Zvdot4a8i instruction (vdot4a, vdot4au, vdot4asu, vdot4aus) with vtype.vsew != 32 (i.e., SEW != 32), the XiangShan RTL executes the instruction instead of raising an illegal instruction exception. The spec mandates these instructions are only defined for SEW=32; all other SEW values are reserved. Executing with wrong SEW causes the 4-element sub-element unpacking logic to slice 32-bit element groups at incorrect bit boundaries, producing wrong multiplicands/multipliers and corrupting the accumulator destination register.
Consequence: data_corruption
Pattern: vdot4a.*vsew|SEW.*!=.*32|isReservedSEW|vdot4a.*illegal|vtypeCheck.*vdot|dotProduct.*SEW
