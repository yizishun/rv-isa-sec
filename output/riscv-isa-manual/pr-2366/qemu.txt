PR #2366  target=qemu  overall=compliant
Spec: STIP read-only enforcement in mip/mvip/sip must be gated on menvcfg.STCE==1, not merely on ext_sstc presence; failing to check STCE would block M-mode software from injecting timer interrupts to S-mode when the Sstc extension hardware is present but STCE is disabled
Violation: QEMU makes CSR mip.STIP read-only based solely on ext_sstc==true (stimecmp being implemented) without also checking menvcfg.STCE==1. In this case, when STCE=0, M-mode software would be blocked from writing mip.STIP to inject supervisor timer interrupts to S-mode via the legacy software path, even though the spec mandates that the implementation must behave as though Sstc is not implemented when STCE=0.
Consequence: denial_of_service
Pattern: if (sstc && !stce_check) { mask &= ~MIP_STIP; }
