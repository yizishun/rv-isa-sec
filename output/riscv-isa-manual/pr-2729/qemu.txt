PR #2729  target=qemu  overall=compliant
Spec: vm=0 repurposes vwmmacc/vqwmmacc opcodes to FP-accumulate MX instructions; missing vm-bit gating in TCG decode causes guest-controlled instruction misrouting, potentially generating incorrect host code from integer-register data interpreted as FP
Violation:
  QEMU TCG translator decodes vmmacc.vv/vwmmacc.vv/vqwmmacc.vv without
  checking the vm bit, or fails to reject vm=0 for vmmacc.vv (reserved) while
  incorrectly routing vm=0 for vwmmacc.vv/vqwmmacc.vv to integer-accumulate
  instead of the FP-accumulate vfwimmacc.vv/vfqwimmacc.vv path, or fails to
  validate that the required subextension (e.g., Zvvfmmmxi8h) is present
  before executing the microscaling variant
Consequence: function_loss
Pattern:
  trans_vmmacc_vv.*vm|trans_vwmmacc_vv.*vm|trans_vqwmmacc_vv.*vm|decode.*vmmac
  c.*vm|OPIVV.*0x38|OPIVV.*0x39|OPIVV.*0x3a
