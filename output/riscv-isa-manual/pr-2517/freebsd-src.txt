PR #2517  target=freebsd-src  overall=compliant
Spec: Spec clarifies that mstatus.TW does NOT control U-mode WFI trapping—WFI in U-mode always raises illegal-instruction regardless of TW; FreeBSD's S-mode trap handler must unconditionally deliver SIGILL, and kernel code must not rely on TW=0 to 'enable' U-mode WFI
Violation:
  FreeBSD kernel S-mode code sets mstatus.TW=0 under the mistaken assumption
  that this permits WFI execution in U-mode, or U-mode WFI is not properly
  handled in the illegal-instruction trap path (do_trap_user / trap.c),
  potentially allowing a user process to stall a hart in U-mode if the
  implementation treats WFI as a no-op within the bounded-time exception
  window.
Consequence: denial_of_service
Pattern:
  mstatus.*TW.*=.*0|TW.*clear|WFI.*U-
  mode|illegal.instruction.*WFI|do_trap_user.*illegal
