PR #2412  target=linux  overall=compliant
Spec: Zilsd LD/SD instructions on RV32 have non-atomic register pair updates and explicitly permit partial register pair writeback before traps (Zilsd_ld_resume_trap), creating an information leak window when the kernel exposes inconsistent register pair state to userspace through signal delivery or ptrace.
Violation:
  When a trap (interrupt or exception) is taken during execution of an RV32
  Zilsd LD instruction and the Linux kernel saves the partially-updated
  register pair to a signal frame via setup_sigcontext() or exposes it via
  ptrace_getregs(), without validating that the load had completed atomically.
Consequence: info_leak
Pattern:
  save_gregs|ptrace_getregs|setup_sigcontext|__switch_to.*ld|sd.*rv32.*zilsd
