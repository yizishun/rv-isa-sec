PR #1434  target=xiangshan  overall=compliant
Spec: CBO PMP checking uses truncated access-size mask (OneHot.UIntToOH1(lgSize=6, lgMaxSize=4) → 4-bit mask for 64-byte access) causing undetected PMP boundary crossings; CBO is not decomposed into independent memory operations per spec requirement allowing privilege escape across PMP regions
Violation: In XiangShan RTL, CBO instructions (cbo.zero, cbo.clean, cbo.flush, cbo.inval) are sent through the TLB as a single monolithic access with full cache-line size. The NewStoreUnit passes the original access size to io.tlbReq.bits.size (line 229 of NewStoreUnit.scala), which the TLB forwards directly to the PMP checker as req_out(i).size (line 258 of TLB.scala). Inside PMPChecker.pmp_match_res, the is_match and aligned methods call OneHot.UIntToOH1(lgSize, lgMaxSize) (PMP.scala lines 216, 241, 252) which truncates the access-size one-hot mask to lgMaxSize bits when lgSize > lgMaxSize. For DTLB-side PMP checkers instantiated with lgMaxSize=4 (MemBlock.scala line 697), a 64-byte CBO (lgSize=6) produces a truncated lowBitsMask of only 4 bits (0xF, covering only 16 bytes). This prevents the aligned check from detecting that the full 64-byte access spans past a PMP region boundary at offsets between 16 and 63 bytes. Additionally, XiangShan does NOT decompose the CBO into independent memory operations before PMP checking—it checks the undivided cache-line access. Per the spec change, 'PMP checks are applied to each memory operation independently' and 'a 64-byte cbo.zero that spans two 32-byte PMP regions would succeed if it was decomposed into two 32-byte memory operations (and the PMP access control bits are the same).' XiangShan's monolithic check would instead fault on such valid decomposable crosses, and more critically, the truncated OneHot mask may fail to detect boundary crossings entirely when lgSize exceeds lgMaxSize.
Consequence: privilege_escape
Pattern: OneHot\.UIntToOH1\(lgSize,\s*lgMaxSize\)|isCbo.*true\.B|lgMaxSize\s*=\s*\d+.*PMPChecker|\/\/.*\bTODO\b.*wider.*size.*than
