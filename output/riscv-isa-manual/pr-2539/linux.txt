PR #2539  target=linux  overall=potential_risk
Spec: Kernel PMU code may misinterpret silently-failing misconfigured counters as valid measurements, breaking perf-based security monitoring without detection.
Violation: Linux kernel PMU driver (riscv_pmu) writes an event selector that is not implemented by the microarchitecture into a counter's event configuration CSR (e.g., mhpmeventN via SBI or direct CSR write), then reads the counter value (hpmcounterN) and treats the returned constant value as legitimate performance data, because the kernel either assumes misconfigured counters will trap or fails to validate that the configured event is implemented on the specific hart.
Consequence: function_loss
Pattern: riscv_pmu.*event_idx|riscv_pmu.*ctr_read|sbi_ext_pmu.*counter_start|mhpmevent|hpmcounter|mcounteren|mcountinhibit|snps_pmu|thead_pmu|andes_pmu
