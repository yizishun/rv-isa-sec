PR #2539  target=qemu  overall=compliant
Spec: Spec 2539 removes the trap allowance for ill-configured counters — if QEMU still raises #I for reads of counters programmed to unrecognized events, compliant guests expecting a silent constant return will fault, causing host-visible guest crash
Violation: QEMU raises an illegal-instruction exception when guest reads an hpmcounter CSR whose corresponding mhpmevent register is set to an unimplemented event selector (ill-configured), instead of returning a constant zero value
Consequence: denial_of_service
Pattern: riscv_pmu_ctr_ctrl OR riscv_hpmcounter_read OR counter_get_ops: trap path for access to CSR where event selector is invalid/unsupported but the counter CSR index itself is implemented
------------------------------------------------------------
