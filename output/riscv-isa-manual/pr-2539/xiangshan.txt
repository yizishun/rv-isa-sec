PR #2539  target=xiangshan  overall=compliant
Spec: XiangShan mhpmevent EVENT0-EVENT3 fields lack WARL event-code validation; ill-configured counters may produce non-constant values instead of spec-mandated constant return, enabling microarchitectural state leakage via unprivileged hpmcounter reads
Violation: When software writes an unsupported event-selector code into mhpmeventN.EVENT[0-3] fields (e.g., an event code not mapped to any implemented hardware performance event), and XiangShan's event-matching logic lacks WARL enforcement or a zero-constant fallback path for unmatched codes, the associated mhpmcounterN may receive non-zero perf.value from unintended hardware signal matches, producing non-constant counter values instead of the spec-required constant return
Consequence: info_leak
Pattern: mhpmevent EVENT[0-3] without WARL event-code validation | default event match without zero-constant fallback | ill-configured counter not returning constant value
