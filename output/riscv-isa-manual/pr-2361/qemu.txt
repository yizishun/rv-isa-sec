PR #2361  target=qemu  overall=compliant
Spec: ctrtarget for not-taken branches must hold next-sequential-PC; QEMU TCG must ensure dest=pc+cur_insn_len in the not-taken gen_branch path at trans_rvi.c.inc:295 else guest CFI monitoring reads wrong target
Violation: In QEMU TCG, when a conditional branch is not-taken and gen_branch() records a CTR entry where ctrtarget != PC of the next sequential instruction (e.g., if ctx->cur_insn_len is incorrectly computed for compressed/RVC instructions, or a future code change inadvertently uses the branch offset instead of fall-through PC as dest for the non-taken path), the ctrtarget CSR field no longer reflects the actual fall-through target.
Consequence: info_leak
Pattern: gen_branch.*NOTTAKEN.*dest.*=|CTRDATA_TYPE_NONTAKEN_BRANCH|ctr_dst\[.*\].*=
------------------------------------------------------------
