PR #2482  target=xiangshan  overall=compliant
Spec: CBO instructions must undergo identical PMP and page-table permission checks as loads/stores — CBO management ops need read permission, CBO.ZERO needs write permission; missing these checks in XiangShan's PMP/TLB hardware allows unprivileged code to manipulate privileged cache lines, constituting a hardware-level privilege escape
Violation:
  XiangShan's PMP checker or TLB/page-table walker does not classify CBO
  instructions (CBO.CLEAN, CBO.FLUSH, CBO.INVAL, CBO.ZERO) as memory-accessing
  operations requiring the same permission checks as explicit loads/stores.
  Specifically: (1) PMP unit passes CBO physical addresses without checking R
  bit for cache-block management ops or W bit for CBO.ZERO, (2) PTW does not
  raise load page-fault for CBO management ops on non-readable pages or store
  page-fault for CBO.ZERO on non-writable pages, (3) instruction decoder in
  the frontend routes CBO ops through a bypass path that omits permission
  validation, or (4) the cache controller executes CBO operations on the cache
  array before the permission check completes (TOCTOU race)
Consequence: privilege_escape
Pattern:
  search for CBO/CBO_CLEAN/CBO_FLUSH/CBO_INVAL/CBO_ZERO in PMP check logic,
  PTW permission path, and LoadUnit/StoreUnit to verify these instructions
  follow the same permission-check code path as LR/SC/AMO; grep for any CBO-
  specific bypass of pmp_check or tlb_permission_check; verify CBO.ZERO
  triggers write-permission validation, not just read; check that CBO
  permission faults are raised synchronously before any cache state mutation
