PR #2571  target=linux  overall=compliant
Spec: scountinhibit is a masked alias that hides M-mode inhibit state for non-delegated counters; kernel PMU code reading scountinhibit may observe false 'not-inhibited' and base profiling/sampling decisions on stale counter values
Violation: Linux kernel PMU driver reads scountinhibit to check whether a counter is running, but for counters not delegated via mcounteren, the corresponding scountinhibit bits are hardwired to read-as-zero regardless of the actual mcountinhibit state set by M-mode firmware. The kernel therefore cannot distinguish 'counter is running' from 'counter is inhibited by M-mode but not visible to S-mode,' leading to incorrect assumptions about counter liveness during context switch or PMU state save/restore.
Consequence: info_leak
Pattern: csr_read.*CSR_SCOUNTINHIBIT|read.*scountinhibit|scountinhibit.*context|scountinhibit.*save|scountinhibit.*restore
