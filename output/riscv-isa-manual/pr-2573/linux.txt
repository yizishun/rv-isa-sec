PR #2573  target=linux  overall=compliant
Spec: Non-atomic SPMP context-switch reconfiguration without interrupt disabling enables privilege escape via partially-applied memory protections
Violation: In the Linux kernel, when Sspmp is implemented and a context switch reconfigures SPMP entries (spmpaddr/spmpcfg) or updates spmpen without first disabling interrupts (clearing SIE in sstatus), an interrupt or exception during the reconfiguration window leaves the running hart with either the outgoing task's SPMP protections removed but the incoming task's not yet applied, or kernel S-mode entries momentarily disabled, allowing the interrupt handler or a rescheduled U-mode task to access memory regions it should not.
Consequence: privilege_escape
Pattern: arch/riscv.*(spmp|SPMP|spmpen|spmpcfg|spmpaddr|siselect|sireg|__switch_to|switch_mm|cpu_switch_to|flush_icache|SFENCE\.VMA).*
------------------------------------------------------------
