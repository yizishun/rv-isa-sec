PR #2573  target=xiangshan  overall=compliant
Spec: Hardware fails to enforce mpmpdeleg.pmpnum WARL lock constraint: writing pmpnum below a locked PMP entry index is not rejected, allowing S-mode to reconfigure previously locked M-mode PMP entries via SPMP indirect CSR access, breaking the hardware root-of-trust isolation boundary
Violation:
  When mpmpdeleg.pmpnum is written with a value <= the index of any locked PMP
  entry, the RTL's CSR write path in the mpmpdeleg CSR module fails to reject
  the write (i.e., ignores the lock constraint check), allowing M-mode
  software to delegate a locked PMP entry for use as an SPMP entry. The locked
  PMP entry then becomes writable by S-mode via indirect CSR access
  (siselect/sireg), violating the hardware lock guarantee that locked PMP
  entries remain immutable until hart reset.
Consequence: privilege_escape
Pattern:
  mpmpdeleg.*pmpnum.*locked|mpmpdeleg write.*lock check|pmpnum WARL.*lock
  constraint|spmpcfg.*L.*delegation boundary
