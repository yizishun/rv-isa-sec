PR #2573  target=qemu  overall=not_implemented
Spec: Unenforced WARL constraint on mpmpdeleg.pmpnum allows S-mode to reconfigure M-mode-locked PMP regions via SPMP delegation bypass
Violation:
  QEMU's mpmpdeleg CSR write handler accepts a pmpnum value that is less than
  or equal to the index of any locked PMP entry (pmpcfg[i].L == 1), instead of
  ignoring the write and retaining the prior pmpnum value as mandated by the
  WARL constraint. This allows M-mode software (or a buggy M-mode firmware
  running on QEMU) to unintentionally delegate locked M-mode PMP regions into
  SPMP control, where S-mode can subsequently reconfigure spmpcfg/spmpaddr to
  alter permissions on memory regions that M-mode intended to permanently
  lock.
Consequence: privilege_escape
Pattern:
  mpmpdeleg.*pmpnum.*warl|pmp_write_cfg.*mpmpdeleg|write_mpmpdeleg.*lock|pmp_l
  ock.*deleg|pmpnum.*locked
------------------------------------------------------------
