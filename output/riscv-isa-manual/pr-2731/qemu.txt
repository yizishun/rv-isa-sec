PR #2731  target=qemu  overall=compliant
Spec: Missing WARL legalization of IME vtype fields (lambda[2:0]/altfmt_A/altfmt_B/bs) causes guest capability discovery via try-and-read-back to see unsupported values, breaking portable software that relies on WARL to select legal tile geometries
Violation:
  QEMU's vtype CSR write handler does not legalize (WARL) the new IME fields
  lambda[2:0], altfmt_A, altfmt_B, and bs at vtype[XLEN-2:XLEN-7], so
  unsupported encodings written by guest software are read back unchanged
  instead of being coerced to the nearest supported value
Consequence: function_loss
Pattern:
  vtype write path that copies raw CSR value into env->vtype without masking
  lambda/altfmt/bs fields through an implementation-defined WARL lookup—search
  for vtype write handlers that store val directly without calling a
  legalization function covering bits [XLEN-7:XLEN-2]
