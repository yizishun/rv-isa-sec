PR #2504  target=qemu  overall=compliant
Spec: QEMU must enforce that mip.STIP becomes read-only when stimecmp is active (Sstc+STCE=1), otherwise M-mode software in QEMU emulation can forge timer interrupts to S-mode, breaking the security boundary between M-mode firmware and S-mode OS for timer interrupt delivery
Violation:
  In QEMU, if the Sstc extension is implemented and menvcfg.STCE=1, but the
  emulation still treats mip.STIP as writable by M-mode CSR writes (instead of
  read-only reflecting the stimecmp comparison signal), the spec is violated
Consequence: privilege_escape
Pattern:
  sifive_sip_writable|s-
  >mip_writable|MIP_STIP.*writable|stip.*writable|writemask.*STIP|mip.*writema
  sk.*0x.*2
