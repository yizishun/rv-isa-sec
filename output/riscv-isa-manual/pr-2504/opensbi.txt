PR #2504  target=opensbi  overall=potential_risk
Spec: Sstc makes mip.STIP read-only when stimecmp is active; OpenSBI writes to mip.STIP for timer injection (SBI set_timer, HSM resume) are silently ignored, breaking timer delivery to S-mode
Violation: OpenSBI M-mode code writes to mip.STIP (via csrw/csrs to mip with STIP bit set) to inject or clear S-mode timer interrupts while menvcfg.STCE=1 and the Sstc extension is implemented — STIP is read-only in mip when stimecmp is implemented, causing the write to be silently ignored (WARL)
Consequence: function_loss
Pattern: csr_set(CSR_MIP,\s*MIP_STIP|csr_write(CSR_MIP.*STIP|mip.*SET_BIT.*STIP|set_mip_stip|write.*mip.*STIP
