PR #2577  target=freebsd-src  overall=compliant
Spec: Branch misaligned-exception behavior depends on whether the branch is taken—untaken branches to misaligned targets must NOT fault; bhyve or the kernel trap emulation layer incorrectly signaling misaligned exceptions on untaken branches would leak hypervisor-internal state to a guest VM
Violation:
  In the FreeBSD kernel's bhyve hypervisor or trap handler, if instruction-
  address-misaligned exceptions are raised for untaken conditional branches
  (when IALIGN=32), violating the spec rule that only taken branches to
  misaligned targets generate exceptions. This occurs when the hypervisor pre-
  validates branch targets without evaluating the branch condition, or when
  the kernel's illegal-instruction emulation layer does not distinguish
  between JAL/JALR (always fault on misaligned) and conditional branches
  (fault only on taken).
Consequence: privilege_escape
Pattern:
  bhyve.*misalign|IALIGN|inst_addr_misaligned|EXCP_MISALIGNED|illegal_instruct
  ion.*branch|decode_compressed.*align
