PR #2660  target=linux  overall=potential_risk
Spec: mcyclecfg/minstretcfg filter bits (MINH/SINH/VUINH at 61:58) must be fully saved/restored on context switch; a 32-bit truncation leaks filter state between tasks, enabling one task to suppress or expose counter increments in another task's privilege modes
Violation: Linux kernel on RV64 reads mcyclecfg/minstretcfg as 64-bit CSRs but only saves/restores the low 32 bits during context switch (e.g., by using a u32 typed variable or CSR-width mismatch), leaving the upper bits — including the MINH, SINH, VUINH filter fields at bits 61:58 — uninitialized or stale from the previous task
Consequence: info_leak
Pattern: struct thread_struct or __switch_to lacking mcyclecfg/minstretcfg save/restore; save/restore using unsigned int instead of u64; context switch only handling cycle/instret counters without their cfg CSRs
