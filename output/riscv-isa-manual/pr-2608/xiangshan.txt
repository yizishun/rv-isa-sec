PR #2608  target=xiangshan  overall=compliant
Spec: smstateen CSRs form a hierarchical hardware access-control matrix; incorrect RTL gating of controlled CSR read/write paths, WARL bitmasking errors, or reset mis-initialization directly bypasses privilege-level isolation, allowing lower-privilege software to access or modify protected machine/supervisor state
Violation: In XiangShan RTL, when the CSR access control logic in the CSR module does not check mstateen/sstateen/hstateen bits before granting read/write access to controlled state (e.g., fcsr, jvt, senvcfg, siselect/sireg, IMSIC registers, scontext/hcontext, srmcfg), or when WARL write-filtering logic allows setting bits that should be read-only zero (unimplemented extensions, reserved bits, or misa.F=1 causing FCSR bit ROZ), or when mstateen bit 63 = 0 fails to block sstateen/hstateen accesses from lower privilege modes, or when reset values of mstateen CSRs are non-zero leaving controlled state accessible after hart reset.
Consequence: privilege_escape
Pattern: (stateen|mstateen|sstateen|hstateen).*(check|enable|mask|gate|allow|block|raise.*exception|WARL|readOnlyZero|read.only.zero|roz|reset.*zero|reset.*init)
