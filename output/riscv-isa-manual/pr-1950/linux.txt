PR #1950  target=linux  overall=potential_risk
Spec: vkeccak.vi only uses 25 of 32 elements per EGU64x32; upper 7 elements follow tail policy and the spec explicitly considers leaving them implementation-defined, creating a 448-bit cross-process covert channel through kernel context-switch save/restore of uninitialized-but-persisted vector register slots
Violation: The kernel performs a vector context save/restore across a security boundary while vkeccak.vi has been executed with tail-agnostic policy (vta=1), and the hardware implementation writes microarchitecturally-sensitive remnant data into the upper 7 elements (indices 25-31) of each 32-element EGU64x32 group that the spec marks as tail-policy-dependent and not part of the Keccak state
Consequence: info_leak
Pattern: vstate_save|vstate_restore|riscv_vr_save|riscv_vr_restore|__arch_vstate_save|vcontext.*save|kvm_riscv_vcpu.*vector
------------------------------------------------------------
