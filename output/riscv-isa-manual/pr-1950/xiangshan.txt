PR #1950  target=xiangshan  overall=not_implemented
Spec: vkeccak.vi imm5 range 0-31 allows 32 rounds but Keccak-f only defines 24 round constants; OOB RC array access for imm5 >= 24 silently produces wrong hash output
Violation:
  XiangShan executes vkeccak.vi with imm5 value 24-31, causing the Keccak
  round constant array KECCAK_RC to be indexed beyond its defined 24 entries
  (ridx from 0 to roundCnt-1 where roundCnt = imm5+1, max 32); the out-of-
  bounds read from the RC lookup table silently returns garbage/zero constants
  for rounds 24-31, corrupting the Keccak permutation output without raising
  an illegal instruction exception
Consequence: data_corruption
Pattern:
  KECCAK_RC.*ridx|keccak.*round.*constant|RC\[.*ridx|keccak_rc\[|roundCnt.*32|
  imm5.*round
