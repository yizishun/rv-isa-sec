PR #1950  target=xiangshan  overall=compliant
Spec: vkeccak.vi mandates DIEL for Keccak round loop over secret PQC state; any variable-latency microarchitecture in the vector FU or missing vl/vstart EGS alignment checks leaks cryptographic material via timing and register file boundary violations
Violation: When the vector execution unit implements vkeccak.vi without validating that vl and vstart are multiples of EGS=32, the element group iteration logic (eg_len = vl/EGS, eg_start = vstart/EGS) produces truncated indices, causing the hardware to read incomplete Keccak state from the vector register file or write partial results across element group boundaries. Additionally, if the DIEL mandate is not enforced in the FU microarchitecture—e.g., the round loop (for ridx=0 to roundCnt-1) is implemented with data-dependent early termination or variable-latency rotate/shift units—the execution time of the 24-round Keccak permutation becomes a function of the secret state bits, leaking cryptographic key material through timing side channels.
Consequence: function_loss
Pattern: vkeccak.vi implementation where roundCnt loop is not constant-time OR vl/vstart remainder against EGS=32 not checked before eg_len/eg_start computation OR KECCAK_ROL implemented with variable-latency barrel shifter OR upper 7 elements of EGU64x32 not masked per tail policy
