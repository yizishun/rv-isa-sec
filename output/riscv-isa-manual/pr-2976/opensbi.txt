PR #2976  target=opensbi  overall=compliant
Spec: mscratch/mepc/mcause/mtval are now architecturally mandatory M-mode CSRs; OpenSBI must unconditionally save/restore all four during HSM suspend/resume to prevent control-flow hijack or context corruption on resume
Violation: OpenSBI HSM suspend/resume handler fails to save/restore mscratch, mepc, mcause, or mtval across non-retentive suspend, OR OpenSBI trap entry code conditionally accesses these CSRs as if they may be unimplemented, creating divergent control paths
Consequence: privilege_escape
Pattern: HSM save/restore arrays missing mscratch|mepc|mcause|mtval; trap handlers with CSR existence guards (e.g., misa checks, try-catch reads) around these registers; inline asm that reads/writes these CSRs without corresponding save in suspend path
