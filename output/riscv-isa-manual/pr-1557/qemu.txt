PR #1557  target=qemu  overall=compliant
Spec: QEMU TCG may fail to honor misaligned atomicity granule PMA for RVC compressed load/store encodings, causing non-atomic multi-operation access in SMP guests where the spec mandates single atomic operation
Violation:
  QEMU TCG applies misaligned atomicity granule PMA atomicity guarantees only
  to 32-bit instruction encodings (base ISAs, F/D/Q loads/stores/AMOs) but
  fails to apply the same single-memory-operation atomicity guarantee to their
  compressed (RVC) counterparts (e.g., C.LW, C.SW, C.LD, C.SD, C.FLW, C.FSW,
  C.FLD, C.FSD). A compressed load/store within a misaligned atomicity granule
  region could be decomposed into multiple byte-level memory operations.
Consequence: race_condition
Pattern:
  check for misaligned access decomposition or atomicity granule logic that
  branches on instruction encoding width (e.g., checking only 32-bit opcodes)
  without also covering compressed (16-bit) encodings; look for RVC decode
  paths that bypass PMA atomicity checks; search for helper functions that
  split misaligned accesses without first checking the misaligned atomicity
  granule PMA

[compliant] target/riscv/insn16.decode:118-141  (decode patterns)
  The insn16.decode file maps RVC compressed load/store opcodes directly to
  the same trans_* functions as their 32-bit counterparts: lw→trans_lw,
  sw→trans_sw, ld→trans_ld, sd→trans_sd, c_fld→trans_fld, c_fsd→trans_fsd,
  c_flw→trans_flw, c_fsw→trans_fsw. There is no separate RVC-specific decode
  or translation path. Both encodings share identical atomicity treatment.
  | lw                010  ... ... .. ... 00 @cl_w
  | ...
  | sw                110  ... ... .. ... 00 @cs_w
  | ...
  | ld              011 .  .....  ..... 10 @c_ldsp
  | ...
  | sd              111 .  .....  ..... 10 @c_sdsp
