PR #2503  target=qemu  overall=compliant
Spec: Incorrect seed CSR access-control enforcement via mseccfg.SSEED/USEED WARL fields allows unprivileged guest modes to read the emulated entropy source, breaking the Zkr security boundary
Violation: QEMU TCG/helper allows read-write access to the seed CSR from S/HS or U mode without first checking that the corresponding mseccfg.SSEED or mseccfg.USEED bit is 1, OR when SSEED/USEED is writable despite Zkr or the corresponding privilege mode being unimplemented (WARL violation), OR when SSEED/USEED reset values are left uninitialized exposing stale host memory to the guest
Consequence: privilege_escape
Pattern: seed.*access|sseed|useed|mseccfg.*SSEED|mseccfg.*USEED|csr_ops.*seed|rmw_seed|write_seed|read_seed
