PR #2503  target=opensbi  overall=potential_risk
Spec: OpenSBI must explicitly configure mseccfg.SSEED/USEED after reset before handing control to S-mode; failing to set these bits leaves S/U-mode seed CSR access permanently denied, and OpenSBI's illegal-instruction trap handler must distinguish seed CSR access violations to avoid silently blocking legitimate S-mode entropy requests.
Violation:
  OpenSBI M-mode trap handler does not distinguish between illegal-instruction
  exceptions raised by `seed` CSR access from S-mode (due to SSEED=0 per spec)
  and other illegal-instruction exceptions, causing S-mode `seed` access
  attempts to be handled as generic illegal-instruction faults rather than
  being recognized as an access-control delegation issue that M-mode firmware
  should either enable (by setting SSEED/USEED) or gracefully deny with a
  well-defined error.
Consequence: denial_of_service
Pattern:
  mseccfg.*SSEED|mseccfg.*USEED|seed.*CSR.*trap|illegal.instruction.*seed|msec
  cfg.*save|mseccfg.*restore|mseccfg.*suspend|mseccfg.*resume
------------------------------------------------------------

[potential_risk] lib/sbi/sbi_illegal_insn.c:148-175  sbi_illegal_insn_handler
  The M-mode illegal-instruction trap handler dispatches ALL illegal-
  instruction exceptions through a unified path: sbi_illegal_insn_handler() →
  system_opcode_insn() → sbi_emulate_csr_read(). The seed CSR (0x015) is NOT
  in the emulation switch table, so unrecognized CSR accesses fall through to
  the default SBI_ENOTSUPP return, triggering truly_illegal_insn() which
  redirects the trap back to S-mode with cause=CAUSE_ILLEGAL_INSTRUCTION. The
  handler cannot distinguish a seed-CSR illegal-instruction (which would occur
  if SSEED were 0) from any other unrecognized CSR access. Currently a
  potential risk because OpenSBI always sets SSEED=1 before S-mode execution;
  but if SSEED were ever 0 (e.g., via a future platform quirk or errata),
  S-mode seed access would loop with unrecoverable illegal-instruction traps
  rather than receiving a well-defined error.
  | if (sbi_emulate_csr_read(csr_num, regs, &csr_val))
  |     return truly_illegal_insn(insn, regs);
  | ...
  | default:
  |     ret = SBI_ENOTSUPP;
  |     break;
