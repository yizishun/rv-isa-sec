PR #2902  target=freebsd-src  overall=not_implemented
Spec: M-mode RNMI handler incorrectly relying on mnstatus.MNPV without gating on H extension presence can corrupt virtualized-context restoration on bare-metal FreeBSD systems
Violation:
  M-mode RNMI handler code (in OpenSBI firmware or bhyve host context) reads
  or writes mnstatus.MNPV on a hart that implements Smrnmi but not the H
  extension, treating a reserved-zero bit as valid virtualization state,
  causing incorrect context save/restore decisions when an RNMI fires during
  FreeBSD kernel execution in S-mode or VS-mode.
Consequence: data_corruption
Pattern:
  mnstatus.*MNPV|MNPV.*mnstatus|CSR_MNSTATUS.*MPV|mnstatus.*0x[0-9a-fA-
  F].*MNPV
------------------------------------------------------------
[not_implemented] sys/riscv/riscv/exception.S:1-300  N/A (whole file)
  FreeBSD's RISC-V trap handler (exception.S) does not implement any
  Smrnmi/RNMI/mnstatus handling code. No mnstatus CSR reads, writes, or MNPV
  bit checks exist anywhere in the FreeBSD kernel. FreeBSD runs in S-mode
  (supervisor mode) and relies on OpenSBI firmware for M-mode services; RNMI
  handling is entirely the responsibility of M-mode firmware, not the FreeBSD
  kernel.
  | // No mnstatus, mnepc, mncause, mnscratch references found in exception.S
  | // No Smrnmi/RNMI CSR handling anywhere in sys/riscv/

[not_implemented] sys/riscv/vmm/vmm_instruction_emul.c:1-1  N/A (no CSR emulation for Smrnmi)
  The bhyve VMM instruction emulator does not implement CSR emulation for
  mnstatus (0x744), mnepc (0x741), mncause (0x742), or mnscratch (0x740). No
  Smrnmi CSR virtualization exists in the FreeBSD hypervisor, so there is no
  code that could incorrectly read or write mnstatus.MNPV for a guest.
  | // No CSR_* or csr references to 0x740-0x744 or mnstatus in vmm_instruction_emul.c

[compliant] sys/riscv/include/vmm.h:98-104  N/A (VMM interrupt info types)
  VM_INTINFO_NMI (2 << 8) is a generic VMM interrupt information type constant
  for virtual NMI injection, not related to Smrnmi/mnstatus CSR access. This
  is standard VMM interrupt classification and does not involve reading or
  writing mnstatus.MNPV. It is unrelated to the security spec concern.
  | #define VM_INTINFO_TYPE         0x700

  | #define VM_INTINFO_NMI          (2 << 8)
  | #define VM_INTINFO_HWEXCEPTION  (3 << 8)
  | #define VM_INTINFO_SWINTR       (4 << 8)
