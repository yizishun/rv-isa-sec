PR #2902  target=xiangshan  overall=compliant
Spec: mnstatus.MNPV must be conditionally instantiated based on H extension presence: absent H→bit hardwired to 0 per reserved-field rule, present H→bit must capture and restore virtualization mode on RNMI entry/exit; mismatch causes MNRET to return to incorrect privilege/virtualization level
Violation:
  XiangShan implements both Smrnmi and H extensions but the mnstatus CSR
  hardcodes MNPV to 0 or omits the field entirely, causing MNRET to return to
  the wrong virtualization mode; OR XiangShan implements Smrnmi without H
  extension but instantiates a writable MNPV field, creating a dead
  architectural bit that violates the reserved-field-zero requirement
Consequence: privilege_escape
Pattern:
  mnstatus.*MNPV|mnstatus.*mnpv|MnpvField|MNPV_FIELD|when.*Smrnmi.*io.mnstatus
  |mnstatus_reserved|Cat.*mnpp.*mnpv|Mux1H.*Smrnmi
