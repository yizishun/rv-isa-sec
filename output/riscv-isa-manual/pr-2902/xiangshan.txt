PR #2902  target=xiangshan  overall=compliant
Spec: mnstatus.MNPV must be conditionally implemented based on H extension presence; unconditional inclusion causes RNMI trap handler to save/restore bogus virtualization state, breaking guest/host isolation on NMI return
Violation: In XiangShan RTL, if the H extension is NOT implemented but mnstatus CSR still defines MNPV as a writable/readable field (non-WARL-zero), or conversely, if the H extension IS implemented but MNPV is absent from the CSR bit layout, causing the RNMI trap handler to fail to capture the virtualization mode (V=1 vs V=0) of the interrupted context
Consequence: privilege_escape
Pattern: mnstatus.*MNPV|MNPV.*mnstatus|CSR.*0x744|mnstatus.*field.*bit|MNPV.*wire|mnstatus.*H_extension|hasH.*mnstatus
