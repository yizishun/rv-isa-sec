PR #2902  target=opensbi  overall=compliant
Spec: OpenSBI must condition MNPV save/restore in RNMI context switching on misa.H — unconditionally restoring a stale MNPV bit on a no-H hart causes MNRET to restore an incorrect virtualization mode (reserved bit silently accepted), breaking the architectural invariant that harts without H extension always execute with V=0
Violation:
  OpenSBI RNMI context save/restore handler reads or writes mnstatus.MNPV (bit
  7) in the saved mnstatus CSR value on a hart that does not implement the H
  extension, treating the reserved bit as meaningful virtualization state
Consequence: privilege_escape
Pattern:
  context switching|trap handler with MNRET restore that does not check misa.H
  before extracting/setting MNPV; unconditional bitwise copy of whole mnstatus
  instead of field-by-field with H-extension gating on MNPV
