PR #2885  target=xiangshan  overall=compliant
Spec: Zama16b mandates MAG16 (16-byte misaligned atomicity granule) for main memory — the LSU must not tear misaligned accesses contained within a 16-byte aligned region, or lock-free concurrent algorithms relying on this atomicity guarantee will observe torn reads/writes, causing silent data corruption in multi-hart scenarios
Violation:
  In XiangShan RTL, when Zama16b is advertised in the ISA but the Load-Store
  Unit (LSU) or PMA checker does not enforce MAG16 atomicity boundaries for
  misaligned loads, stores, and AMOs targeting main memory regions:
  specifically, if a misaligned access whose bytes all lie within a naturally-
  aligned 16-byte granule is split into multiple micro-operations observable
  by other harts or DMA engines, or if such an access incorrectly raises an
  address-misaligned exception, the hardware violates the
  norm:pma_mag_zama16b_req requirement.
Consequence: race_condition
Pattern:
  MAG16|misaligned.*atomic|atomicity.*granule|crossCacheline|SplitLoad|SplitSt
  ore|MisalignCheck|zama16b|misaligned.*AMO.*atomic
