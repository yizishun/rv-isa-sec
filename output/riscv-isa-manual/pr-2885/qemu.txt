PR #2885  target=qemu  overall=bug_confirmed
Spec: Ziccamoc extension entirely unimplemented: amocas.q executes on any memory region without verifying coherence+cacheability PMAs, violating the normative rule that AMOCASQ support is restricted to main memory regions with both PMAs
Violation: QEMU TCG emulates amocas.q (AMOCASQ) gated solely on ext_zacas without checking that the target physical address resides in a main memory region possessing both coherence and cacheability PMAs. The Ziccamoc normative rule requires AMOCASQ-level support exclusively on main memory regions with both PMAs; QEMU has no ext_ziccamoc feature flag, no PMA attribute inspection in the amocas.q translation path, and no mechanism to reject amocas.q on non-coherent or non-cacheable regions such as MMIO or device memory.
Consequence: data_corruption
Pattern: trans_amocas_q.*MO_ALIGN|gen_cmpxchg.*MO_ALIGN.*MO_UO|ext_zacas.*amocas|ziccamoc missing ext flag|amocas.q PMA coherence cacheability
