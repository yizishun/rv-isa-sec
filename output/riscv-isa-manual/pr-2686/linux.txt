PR #2686  target=linux  overall=potential_risk
Spec: Cache block size is implementation-defined and shall be uniform system-wide; kernel must discover it via hardware enumeration before issuing any CMO instructions, otherwise CBO operations may corrupt data outside intended cache-block-aligned ranges
Violation:
  Linux kernel issues CBO instructions (CBO.INVAL, CBO.CLEAN, CBO.FLUSH,
  CBO.ZERO) using a hardcoded or unverified cache block size rather than the
  size discovered via the execution environment's cache discovery mechanism
  (e.g., CPUID CBOBLOCK field, device tree), causing cache operations to
  target memory ranges beyond or short of the intended cache block boundaries
Consequence: data_corruption
Pattern:
  CBO_(INVAL|CLEAN|FLUSH|ZERO)|cbo_block_size|cboz_block_size|riscv_cbom_block
  _size|riscv_cboz_block_size|L1_CACHE_BYTES.*riscv|alternative_cmo
------------------------------------------------------------
