PR #2997  target=qemu  overall=compliant
Spec: Incorrect QEMU emulation of the mandated tile punning layout (cross-TEW aliasing of shared 16*TE*TE byte matrix state) causes guest data written via one TEW view to be misread via another TEW view, leaking stale or cross-domain tile contents
Violation: When QEMU implements the tile punning scheme (mapping tile elements across TEW=8/16/32/64 views of the shared 16*TE*TE byte matrix state) with an incorrect offset calculation in the punning() algorithm, a guest write using one TEW followed by a read using a different TEW returns data from the wrong physical element location, causing cross-TEW-view data aliasing that violates the architecturally mandated punning layout.
Consequence: info_leak
Pattern: tile_state\[.*\].*tew|punning.*offset|mt_tile_offset|matrix_tile_read.*tew|matrix_tile_write.*tew|case 8:.*case 16:.*case 32:.*case 64:
