PR #2575  target=qemu  overall=compliant
Spec: QEMU must guard mseccfgh CSR registration on mseccfg being implemented; unconditionally exposing mseccfgh on RV32 leaks a 32-bit register alias into the guest when mseccfg is absent
Violation: QEMU registers mseccfgh CSR for RV32 guests without first checking that mseccfg is implemented (e.g., when Zkr/secd extension is disabled or mseccfg CSR predicate returns false). A read or write to mseccfgh succeeds when the spec requires it to raise an illegal instruction trap.
Consequence: info_leak
Pattern: riscv_csr_register.*mseccfgh without a prior guard checking riscv_csrr(mseccfg) or predicate ANDed with XLEN==32
