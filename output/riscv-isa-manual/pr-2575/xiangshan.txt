PR #2575  target=xiangshan  overall=compliant
Spec: CSR mseccfgh must only exist when mseccfg is implemented and XLEN=32; failing to gate its existence on mseccfg's implementation status creates an undefined CSR that can leak internal hardware state or alias to unrelated register bits.
Violation: In XiangShan RTL, when XLEN=32 and mseccfg is NOT implemented (or the implementation is gated/disabled via config), but the CSR module still exposes mseccfgh (CSR 0x757) as readable/writable — i.e., the CSR existence check in the CSR dispatch logic does not AND mseccfg's implementation status with XLEN==32 before registering mseccfgh as a valid CSR address. This would allow software to access a phantom CSR whose underlying storage does not exist or aliases to undefined state.
Consequence: info_leak
Pattern: Mseccfgh.CSRAddr || CSRs.mseccfgh || mseccfgh_exists || (0x757 && !hasMseccfg)
