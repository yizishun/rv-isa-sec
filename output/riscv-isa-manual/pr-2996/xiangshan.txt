  WRS instructions (WRS.NTO/WRS.STO) are decoded but execute as no-ops — they
  never stall execution in the ROB. Only a 'hasWFI' stall state machine
  exists; there is no 'hasWRS' register, no WRS enqueue trigger, and no WRS
  wakeup condition. Per spec norm:Zawrs_wrs-nto_stall_exec, WRS.NTO 'would

  specified to work similarly with a bounded timeout (norm:Zawrs_wrs-

  using WRS in polling loops will busy-wait, defeating the energy-efficiency
  purpose of the Zawrs extension.
