PR #2580  target=qemu  overall=compliant
Spec: Non-atomic TCG emulation of AMOCAS creates a TOCTOU window where a concurrent hart can modify the memory location between guest load and conditional store, breaking the fundamental CAS atomicity guarantee and corrupting guest spinlock/mutex synchronization
Violation: QEMU TCG translates AMOCAS.W/D/Q as a non-atomic load-compare-store sequence (e.g., separate guest load + host compare + guest store helper calls) without holding a per-RAM-page or global MMU lock, allowing another hart's memory access to interleave between the load and conditional store.
Consequence: race_condition
Pattern: helper_atomic_.*cas|gen_amocas|tcg_gen_atomic.*cmpxchg|MO_TE.*amocas|amocas.*non.atomic|load.*compare.*store.*amocas
