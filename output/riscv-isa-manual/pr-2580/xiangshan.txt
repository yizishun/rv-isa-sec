PR #2580  target=xiangshan  overall=compliant
Spec: Reserved AMOCAS.D/Q encodings with odd-numbered register pairs are accepted and executed with incorrect register pairing instead of raising illegal instruction exception; decoder lacks rd[0]/rs2[0] evenness validation gates
Violation: When AMOCAS.D (RV32) or AMOCAS.Q (RV64) instruction encoding specifies an odd-numbered register for rd or rs2, the XiangShan decoder (RiscvInst.scala:22-24) only checks FUNCT7 bits 31:25 (= b00101??), which excludes rs2[0] (bit 20) and rd[0] (bit 7). No subsequent stage checks for even-register validity. The hardware proceeds to execute with rd+1/rs2+1 sequential pairing logic (DecodeUnitComp.scala:265-273), producing a wrong register pair instead of raising an illegal instruction exception as required for the reserved encoding.
Consequence: data_corruption
Pattern: isAMOCAS[^Q]|rs2\s*\+\s*1\.U|dest\s*\+\s*1\.U|AMO_CAS_[DQ].*src2|exceptionII.*AMO
