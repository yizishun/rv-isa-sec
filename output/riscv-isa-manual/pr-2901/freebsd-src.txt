PR #2901  target=freebsd-src  overall=compliant
Spec: Zisb adds TEB/MDB/DPB speculation barriers to defend against Spectre-class in-domain transient execution attacks; FreeBSD kernel copyin/copyout, syscall dispatch, and signal-delivery code paths that perform bounds-check-then-access on user-controlled indices without explicit speculation barriers are vulnerable to speculative out-of-bounds kernel memory disclosure via cache-based side channels.
Violation:
  In the FreeBSD kernel, when a bounds check (e.g., user-supplied index/size
  validated against a kernel buffer length) is followed in program order by a
  memory access that uses the checked value as an offset, and no speculation
  barrier (TEB/MDB/DPB) separates the check from the dependent access, a CPU
  with control-flow or data-value speculation may transiently execute the
  access with an out-of-bounds value, leaking kernel memory through cache-
  timing side channels observable by userspace (Flush+Reload, Prime+Probe).
  This affects copyin/copyout wrappers, syscall dispatch table indexing,
  signal frame construction, and any sysctl/ioctl handler that bounds-checks a
  user index before dereferencing a kernel array.
Consequence: info_leak
Pattern:
  if\s*\(.*(<|<=|>=|>).*\)\s*\{[^}]*\[|bgeu.*\n.*lb[wu]|bltu.*\n.*s[bdw]|bound
  s.check.*followed.by.*load.*index|copyin.*bounds.*speculat|bnd.jmp.*\n.*ld|u
  ser.index.*bounds.*array.access
