PR #2661  target=xiangshan  overall=bug_confirmed
Spec: Incorrect PMP checker implementation of the mseccfg.MML=1 truth table would grant Machine mode read/write/execute access to regions that the spec mandates as denied, constituting a hardware-level privilege boundary escape
Violation: When mseccfg.MML=1, the PMP checker in hardware incorrectly implements the MML truth table — e.g., treating an R=0,W=1 encoding for Machine mode as granting read access (which the spec defines as denied), or failing to distinguish between Machine-mode and Supervisor/User-mode permission checks for the same PMP entry. In Chisel/Verilog, this manifests as a wrong branch in the PMP permission calculation MUX or a missing mode qualifier (ldest.priv) in the permission lookup logic.
Consequence: privilege_escape
Pattern: (MML|mml|mseccfg\.MML|isMmLmode|mmlEn|pmpCheck.*priv|pmp.*machine.*access)
