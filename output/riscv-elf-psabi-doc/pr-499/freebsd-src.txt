PR #499  target=freebsd-src  overall=potential_risk
Spec: Kernel must preserve full YLEN (2*XLEN) capability register width and associated metadata across context switches, signal delivery, and VM save/restore; truncation to XLEN strips capability bounds and permissions, enabling privilege escape via unbound dereference after resume.
Violation: FreeBSD kernel context switch (cpu_switch) or signal delivery (sendsig) saves/restores only XLEN bits of capability registers x0-x31, stripping YLEN-wide capability metadata (bounds, permissions, seal, tag) and breaking the pure-capability ABI invariant that all pointers—including stack pointer, frame pointer, and return address—are capabilities with enforced bounds and permissions.
Consequence: privilege_escape
Pattern: swtch\.S|savectx|setjmp|sendsig.*save.*reg|bhyve.*vmctx.*x[0-9]|copy(in|out).*cap|sizeof.*register.*XLEN|struct trapframe.*XLEN
