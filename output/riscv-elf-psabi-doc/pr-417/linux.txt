PR #417  target=linux  overall=compliant
Spec: RISC-V Linux lacks arch_parse_elf_property() for CFI GNU property notes, so exec cannot validate CFI hardware requirements, cannot reject incompatible binaries, and may leave kernel-provided code paths (sigreturn VDSO) without required landing pads for CFI-enabled processes.
Violation: When the Linux kernel loads a RISC-V ELF executable or shared library with GNU_PROPERTY_RISCV_FEATURE_1_AND containing CFI_LP_UNLABELED or CFI_SS bits set, but CONFIG_ARCH_USE_GNU_PROPERTY is not enabled for RISC-V (no arch_parse_elf_property implementation exists), the kernel cannot validate that hardware supports Zicfilp/Zicfiss, cannot propagate CFI requirements via arch_elf_state, and the VDSO sigreturn trampoline may lack lpad instructions if VDSO_CFI is not built, causing indirect branches from CFI-enabled processes to land on non-landing-pad kernel-provided code.
Consequence: privilege_escape
Pattern: CONFIG_ARCH_USE_GNU_PROPERTY.*riscv|arch_parse_elf_property.*riscv|GNU_PROPERTY_RISCV_FEATURE_1_AND|NT_GNU_PROPERTY_TYPE_0.*process\.c|start_thread.*envcfg.*LPE
