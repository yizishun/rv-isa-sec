PR #131  target=qemu  overall=compliant
Spec: Uninterruptible TSM model requires medeleg/mideleg to route all TVM exceptions to M-mode; QEMU must not allow delegation of exception causes that the spec reserves for TSM-only handling, or the hosting OS/VMM can observe confidential TVM state via misrouted traps.
Violation: QEMU's medeleg/mideleg CSR emulation permits delegation of exception or interrupt causes that, in the uninterruptible TSM deployment model (Appendix D), must unconditionally trap to M-mode. Specifically, if QEMU does not enforce that certain synchronous exception codes (e.g., instruction page fault, load/store page fault, or environment call from VS/VU-mode) remain non-delegable when a TVM context is active, then a malicious guest TVM can trigger exceptions that QEMU routes to S/HS-mode (the hosting OS/VMM) instead of M-mode (the TSM), giving the untrusted host visibility into TVM execution state.
Consequence: info_leak
Pattern: riscv_cpu_set_gepc|riscv_cpu_set_sepc|medeleg|mideleg|deleg.*exception|rmw_medeleg|rmw_mideleg
