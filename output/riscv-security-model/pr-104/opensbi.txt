PR #104  target=opensbi  overall=not_implemented
Spec: SR_SUD_001/002 split requires both PMP/Smepmp AND MPT for domain isolation; OpenSBI must configure both during domain context switches, not just one
Violation:
  OpenSBI configures only PMP/Smepmp or only MPT (but not both) when enforcing
  physical memory isolation for supervisor domains during domain context
  switches. The updated spec now requires both mechanisms independently
  (SR_SUD_001 for PMP/Smepmp, SR_SUD_002 for MPT), where previously only one
  was needed (old SR_SUD_001 used 'or'). An OpenSBI implementation that relies
  on MPT alone without also programming PMP/Smepmp entries to isolate
  supervisor domains violates SR_SUD_001. Conversely, an implementation that
  configures only PMP/Smepmp without an MPT for page-granularity domain
  isolation violates SR_SUD_002.
Consequence: privilege_escape
Pattern:
  sbi_domain_context_switch|domain_switch|SDID.*switch|mmpt.*write|pmp_set.*do
  main|domain.*pmp|mpt.*domain(?!.*pmp)|pmp.*domain(?!.*mpt)
