PR #617  target=qemu  overall=compliant
Spec: Unchecked msiptp.MODE when iohgatp.MODE is Bare allows guest VM to trigger MSI translation through undefined GSCID, enabling inter-VM MSI injection or arbitrary physical DMA via misrouted interrupt writes
Violation: QEMU IOMMU emulation does not enforce that msiptp.MODE is Off when iohgatp.MODE is Bare. When iohgatp.MODE is Bare, second-stage address translation is disabled, no valid GSCID exists to associate MSI page table translations with a VM address space, yet a guest may configure a non-Off msiptp.MODE. The IOMMU would then perform MSI address translation through an undefined GSCID context, routing MSI writes to arbitrary physical addresses.
Consequence: privilege_escape
Pattern: DC.iohgatp.MODE set to Bare while DC.msiptp.MODE != Off, with no cause=259 (DDT entry misconfigured) fault reported — look for missing cross-field validation between iohgatp mode and msiptp mode in DDT entry processing, specifically where cause=259 is checked
------------------------------------------------------------
