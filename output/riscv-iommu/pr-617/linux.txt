PR #617  target=linux  overall=compliant
Spec: Spec now mandates msiptp.MODE=Off when iohgatp.MODE=Bare; kernel IOMMU driver must enforce this or risk MSIs being translated with no valid GSCID, enabling guest-to-host or cross-VM MSI misdirection
Violation:
  Linux IOMMU driver configures a device context (DC) with iohgatp.MODE=Bare
  (no second-stage address translation) but msiptp.MODE!=Off, violating the
  spec requirement that MSI page table translation must be disabled when
  G-stage translation is absent. Without G-stage, no valid GSCID exists to
  associate MSI translations with a VM address space, yet the IOMMU may still
  attempt MSI address translation into an undefined context.
Consequence: privilege_escape
Pattern:
  iohgatp.*Bare|iohgatp.*=.*0[^x].*msiptp|msiptp.*MODE.*(Flat|MRIF).*iohgatp.*
  Bare|DC.*fsc.*msiptp.*iohgatp
