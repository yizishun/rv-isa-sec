PR #617  target=linux  overall=compliant
Spec: Setting msiptp.MODE != Off when iohgatp.MODE=Bare causes MSI translations to proceed without a valid GSCID, potentially misdirecting MSI interrupts across VM boundaries or between guest and host, enabling cross-VM interrupt injection
Violation: In the Linux kernel RISC-V IOMMU driver, when a Device Context (DC) is configured with iohgatp.MODE=Bare (second-stage translation disabled, e.g., for host-owned devices or when KVM is not in use) but msiptp.MODE is not set to Off, the IOMMU may perform MSI address translations without a valid GSCID, allowing MSI page table walks to associate translations with an undefined VM address space.
Consequence: privilege_escape
Pattern: iohgatp.*Bare|msiptp.*MODE|device_context.*iohgatp|dc_template|riscv_iommu_device_context
