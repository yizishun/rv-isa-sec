Spec: Missing handle_virtual_interrupt_file_overlap logic: G-stage superpage GPA resolution can cache a translation spanning both MSI interrupt file and regular memory, allowing device DMA to bypass MSI redirection and write to arbitrary system memory instead of the virtual interrupt file
Violation: When QEMU's IOMMU G-stage page table walk resolves a GPA using a superpage (e.g., 2MB or 1GB) that partially overlaps a virtual interrupt file region defined by msi_addr_mask/msi_addr_pattern, QEMU caches the translation with the full superpage addr_mask without reducing the page size. Subsequent DMA writes into the virtual-interrupt-file portion of that cached range hit the IOTLB cache and bypass the MSI trap check, causing them to be forwarded as regular memory writes instead of being redirected through the MSI page table.
Consequence: privilege_escape
Pattern: riscv_iommu_spa_fetch G-stage leaf PTE superpage resolution without post-GPA virtual interrupt file overlap page-size reduction; addr_mask derived from va_skip at line 463 not constrained by MSIPTP region boundaries before caching at line 1622-1630
