PR #699  target=freebsd-src  overall=compliant
Spec: IOMMU GPA superpage overlapping virtual interrupt file region silently bypasses MSI interrupt remapping, letting an assigned PCIe device inject arbitrary MSIs into a bhyve guest VM
Violation: In FreeBSD's bhyve IOMMU GPA second-stage translation (or future RISC-V IOMMU driver), when a superpage mapping (2MB/1GB Sv39x4/Sv48x4 hgatp entry) spans a guest-physical range that overlaps a virtual interrupt file region (msiptp.MODE != MSIPTP_Off with active msi_addr_mask/pattern), and the IOMMU proceeds with the superpage granularity instead of reducing gst_page_sz to the largest sub-page that avoids the overlap—allowing the DMA write to bypass MSI page-table remapping and land directly as an unmediated memory access into the VIF region
Consequence: privilege_escape
Pattern: hgatp.*superpage|IOMMU.*GPA.*superpage|gst_page_sz|MSIPTP|msi_addr_mask
------------------------------------------------------------
