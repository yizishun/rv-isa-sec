PR #679  target=qemu  overall=compliant
Spec: If QEMU reports data corruption during PDT traversal as PT_CORRUPTED (274) instead of PDT_CORRUPTED (269), the guest OS receives a semantically wrong fault cause that misattributes a PDT-entry corruption to a second-stage page table, breaking guest error-recovery or diagnostic logic.
Violation:
  In QEMU's riscv-iommu.c process context lookup (PDT walk), any data
  corruption fault detected on a PDT entry is reported with cause code 274
  (PT_CORRUPTED) instead of 269 (PDT_CORRUPTED). This would happen if the PDT
  traversal error path reuses the second-stage page-table corruption code, or
  if a shared 'GST_DATA_CORRUPTION' handler always maps to 274 regardless of
  whether the corruption occurred in the PDT or the page tables.
Consequence: function_loss
Pattern:
  PDT walk or process-context lookup path returning
  RISCV_IOMMU_FQ_CAUSE_PT_CORRUPTED (274) where
  RISCV_IOMMU_FQ_CAUSE_PDT_CORRUPTED (269) is required; any data-corruption
  fault reported from locate_process_context / pde walk with the wrong cause
  constant; shared corruption-to-cause mapping that does not distinguish PDT
  from PT contexts.
