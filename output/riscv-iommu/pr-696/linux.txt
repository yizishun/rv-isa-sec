PR #696  target=linux  overall=not_implemented
Spec: Kernel must gate all ATS command submissions on capabilities.ATS; submitting ATS commands to a non-ATS-capable IOMMU causes an unrecoverable command-queue illegal-command fault, halting all DMA translation updates
Violation:
  Linux kernel RISC-V IOMMU driver submits an ATS command (ATC_INVAL or PRGR)
  to the IOMMU command queue without first verifying that capabilities.ATS ==
  1, causing the hardware to raise a cmd_ill fault and stall the command queue
Consequence: denial_of_service
Pattern:
  ats_command|riscv_iommu.*ats|ATS.*inval|PRGR.*command|iommu_command.*ATS
  without prior check of IOMMU_CAPABILITIES.ats or equivalent driver cached
  caps field
------------------------------------------------------------
