PR #681  target=qemu  overall=compliant
Spec: Old reference model leaked SADE (S-stage A/D Enable) to guest via iotval2[1] on implicit guest page fault; QEMU must use implicit access write flag for iotval2[1], not internal IOMMU DC_TC_SADE/GADE config bits
Violation:
  In two-stage IOMMU translation, when VS-stage completes but G-stage leaf PTE
  lacks write permission causing an implicit guest page fault, QEMU reports
  the fault via riscv_iommu_report_fault() with iotval2 set to raw
  translated_addr without setting bit[0]=1 (implicit access indicator) or
  bit[1] appropriately for the implicit access type. If QEMU later implements
  implicit fault iotval2 formatting and copies the old reference model pattern
  of setting iotval2[1] from SADE/GADE (internal translation context config
  bits) instead of from the actual implicit access write flag, the guest OS
  can observe internal IOMMU configuration state through the fault queue
  record.
Consequence: info_leak
Pattern:
  iotval2.*SADE|iotval2.*GADE|iotval2.*\\|.*ade|iotval2.*tc.*<<|iotval2\\[1\\]
