PR #99  target=qemu  overall=not_implemented
Spec: ACE memory instructions lost their 'appears as sequence of individual reads/stores/loads' guarantees and gained explicit non-atomicity with unordered intra-instruction decomposition of arbitrary granularity; QEMU TCG must not emit ACE memory ops as single atomic transactions and must correctly model RVWMO/RVTSO at instruction level while permitting arbitrary intra-instruction reordering across SMP harts.
Violation:
  QEMU TCG translates ACE memory instructions (ace.prov, ace.export,
  ace.import) as single atomic TCG memory operations, enforcing internal
  ordering or fixed granularity within the instruction, when the spec now
  requires decomposition into unordered component memory operations of
  arbitrary granularity with no atomicity guarantees. Additionally, QEMU
  multi-hart SMP emulation fails to enforce RVWMO (or RVTSO if Ztso is
  implemented) at the ACE instruction level while simultaneously permitting
  any intra-instruction reordering of component memory ops.
Consequence: race_condition
Pattern:
  ace\.(prov|export|import).*atomic|tcg_gen_qemu_ld.*ace|tcg_gen_qemu_st.*ace|
  helper_ace.*(prov|export|import).*atomic|RVWMO.*ace|ace.*memory.*order|ace.*
  multi.?hart
