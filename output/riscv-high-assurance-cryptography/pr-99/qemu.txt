PR #99  target=qemu  overall=compliant
Spec: ACE memory instructions must be decomposed into unordered sub-operations of arbitrary granularity with no atomicity guarantees; QEMU TCG must not translate them as atomic helpers or the multi-hart memory model is stronger than spec, masking SMP race conditions in guest code
Violation: QEMU TCG implements ACE memory instructions (ace.prov, ace.export, ace.import) as monolithic atomic helper calls under the BQL or within a single TCG translation block, failing to decompose them into unordered component memory operations of arbitrary granularity as required by the spec. In MTTCG multi-hart SMP mode, this means hart A cannot observe partial or interleaved effects of hart B's ACE memory instruction — QEMU provides stronger (false) intra-instruction ordering that masks race conditions exploitable on real hardware. Additionally, QEMU may enforce a fixed alignment policy (always-trap or always-succeed) that mismatches the implementation-defined behavior of the emulated CPU for misaligned ACE memory accesses.
Consequence: race_condition
