PR #96  target=linux  overall=compliant
Spec: IOMMU Non-Leaf PTE Invalidation absence (SHOULD, not MUST) creates stale-IOATC risk: if kernel modifies intermediate page table entries without capability-gated fallback to global invalidation, cached non-leaf translations persist, allowing DMA to freed/reallocated memory
Violation:
  When Linux kernel modifies non-leaf IOMMU page table entries (e.g., freeing
  intermediate page table levels during unmap, splitting/merging huge-page
  mappings, or changing PMD/PUD directory pointers) on an IOMMU that does not
  support the Non-Leaf PTE Invalidation Extension (IOM_330), and the IOMMU
  driver either omits the required fallback global invalidation
  (IOTINVAL.VMA/GVMA with all-ones mask) or incorrectly assumes non-leaf
  invalidation is always available without checking
  capabilities.NLONE.GATS/NAGTS bits.
Consequence: privilege_escape
Pattern:
  riscv_iommu.*inval|iotinval\.(vma|gvma)|iommu.*non.?leaf|cached.*non.?leaf|n
  onleaf.*inval|non_leaf.*pte.*cache|IOATC.*stale
