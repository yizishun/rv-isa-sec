PR #96  target=xiangshan  overall=not_implemented
Spec: Lack of fine-grained IOMMU TLB invalidation (non-leaf PTE, address-range) widens the window where stale intermediate translations cached in IOATC can be exploited by malicious DMA devices to access unauthorized physical memory after page table teardown
Violation:
  When XiangShan IOMMU (IOPMP/IOATC) does not implement the Non-Leaf PTE
  Invalidation or Address Range Invalidation extensions, software must fall
  back to coarser invalidation commands (e.g., IOTINVAL.VMA with GVMA/PSVMA
  granularity). Between the page table modification and the completion of the
  coarse invalidation, stale non-leaf PTE translations remain cached in the
  IOATC, allowing in-flight DMA transactions to use obsolete intermediate page
  table entries. This window is widened by the latency of broadcasting and
  completing a full-cache invalidation versus a targeted address-range or non-
  leaf-only invalidation command.
Consequence: privilege_escape
Pattern:
  IOATC invalidation handler only supports PSVMA/GVMA granularity; absence of
  NILE (Non-leaf Invalidation) and ADDR (Address Range) capability bits in
  iommu_capabilities; IOTINVAL command decoder does not decode non-leaf or
  address-range invalidation opcodes; IOATC tag comparator lacks partial-
  address match logic for range-based lookup and invalidation

  NAPOTDecoder computes addr_start and addr_end from a NAPOT-encoded entry
  address for PMP permission region matching. It finds trailing ones, computes
  a mask, and derives the address range. This range-decoding logic could
  theoretically serve as the basis for address-range-based IOATC invalidation,
  but it is wired only into the sPriority PMP check state (line 1243) and is
  not connected to any IOATC tag array or invalidation lookup. No IOATC tag
  comparator exists for range-based invalidation.
  | object NAPOTDecoder {
  |   def apply(entry_addr: UInt): (UInt, UInt) = {
  |     val trailing_ones = Wire(UInt(log2Ceil(IopmpParams.soc_addr_width).W))
  |     trailing_ones := PriorityEncoder(~entry_addr)
  |     val size = trailing_ones + 1.U
  |     val mask = (1.U << size) - 1.U
  |     addr_start := entry_addr & (~mask).asUInt
  |     addr_end := addr_start + mask
  |     (addr_start, addr_end)
  |   }
  | }
