PR #38  target=linux  overall=not_implemented
Spec: Context switch and KVM VM enter/exit paths must issue fence.hpd when changing hardware protection domain identifiers (ASID, VMID, SDID) to prevent cross-domain predictor-based transient execution leaks between processes or VMs sharing a physical CPU.
Violation:
  Linux kernel writes satp (changing ASID) or hgatp (changing VMID) during
  context switch or VM enter/exit without a preceding or subsequent fence.hpd
  instruction, allowing predictor state tagged with the old domain to
  influence speculation in the new domain. Additionally, ASID or VMID
  recycling on a CPU without an intervening fence.hpd violates the spec's
  explicit reuse requirement.
Consequence: info_leak
Pattern:
  satp write (csr_write/csr_set/CSR_STATUS/satp=) on context-switch path OR
  hgatp write on KVM vcpu-load path NOT paired with fence.hpd
------------------------------------------------------------
