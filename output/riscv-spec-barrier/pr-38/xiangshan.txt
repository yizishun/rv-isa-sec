PR #38  target=xiangshan  overall=compliant
Spec: Incomplete hardware protection domain identifier tagging in speculative predictor structures (branch predictor, prefetchers, load-value predictor) and missing pipeline synchronization on fence.hpd allow cross-domain transient execution attacks to leak data across privilege/VM/AS boundaries
Violation:
  In XiangShan RTL, when predictor structures (FTB, TAGE-SC branch predictor,
  load-value predictor, stride prefetcher) tag entries with only a subset of
  hardware protection domain identifiers (e.g., ASID only without VMID when H
  extension is active, or privilege mode only without SDID when Smsdid is
  implemented), predictions learned in one hardware protection domain are
  incorrectly reused for speculative execution in a different domain.
  Additionally, if the fence.hpd instruction does not trigger a full pipeline
  drain and predictor invalidation for all entries matching the current and
  lower-privilege-level domain identifiers before allowing subsequent
  instructions to issue speculative accesses, stale cross-domain predictions
  persist.
Consequence: info_leak
Pattern:
  predictor.*tag|prediction.*domain|branch.*ASID|FTB.*VMID|tage.*tag|prefetch.
  *domain|fence_hpd|FENCE_HPD|prediction.*privilege|speculative.*cross.*domain
  |prediction.*invalidation|hpd.*flush
