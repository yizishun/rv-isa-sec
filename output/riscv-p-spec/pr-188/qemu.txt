PR #188  target=qemu  overall=compliant
Spec: RV64-only pair word instructions (PPAIREO.W/PPAIROE.W/PPAIRO.W) read bits 63:32 of source registers; if QEMU TCG exposes these on RV32, the TCG implementation accesses register state beyond XLEN=32, potentially leaking host data into the guest rd result
Violation:
  QEMU TCG implements the RV64-only pair word instructions (PPAIREO.W,
  PPAIROE.W, PPAIRO.W) without gating on XLEN=64. On RV32, TCG would reference
  bits [63:32] of the guest register state, which exceed the 32-bit register
  width. The TCG temp or register storage may contain stale host-level data
  beyond the intended 32-bit boundary, leaking it into the guest-visible rd
  result.
Consequence: info_leak
Pattern:
  XLEN/32 loop bound or 64-bit bit-slice extraction in TCG op helpers for
  P-ext pair operations without mstatus_mxl or xlen runtime guard,
  specifically word-suffix (.W) pair ops not checking `get_xl(ctx) ==
  MXL_RV32` or equivalent before indexing sX[63:32]
