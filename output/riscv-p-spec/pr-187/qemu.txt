PR #187  target=qemu  overall=compliant
Spec: All 10 saturating shift instructions require intermediate computation at double element width to detect overflow before saturation; TCG emitting narrow shift-with-truncation makes saturation dead code and silently corrupts guest data
Violation: TCG translates saturating shift (PSSLAI.H/W, SSLAI, PSSHA.DHS/DWS, PSSHAR.DHS/DWS, PSSLAI.DH/DW) using an intermediate type no wider than the element width (e.g., int16_t for halfword elements). The saturation check 'if result < -2^15' becomes dead code because the C shift result has already implicitly wrapped modulo 2^16, making overflow detection impossible. The computed result silently wraps instead of saturating, and vxsat is never set.
Consequence: data_corruption
Pattern: tcg_gen_shl_i{32,64}.*saturat|gen_helper.*ssla|gen_helper.*pssla|tcg_gen_sari.*round|int16_t.*<<|int32_t.*<<.*vxsat|gen_shift.*saturat|tcg_gen_shl.*(no.*extend|zero_ext)
