PR #162  target=qemu  overall=compliant
Spec: Wrong major opcode for PABD.B (0011011 OP-IMM-32 vs correct 0111011 OP-32) causes dual opcode-space collision: guest code using PABD.B silently executes wrong semantics, and any legitimate OP-IMM-32 instruction sharing the funct3=000/funct7=10010 encoding is hijacked to PABD.B behavior
Violation: QEMU TCG decoder uses opcode 0x1B (OP-IMM-32, 0011011) for PABD.B instead of the corrected 0x3B (OP-32, 0111011). This causes: (1) PABD.B to be decoded as an immediate-format instruction, misinterpreting the rs2 register field as part of an immediate value, producing wrong packed absolute difference results; (2) a silent opcode collision where a legitimate OP-IMM-32 instruction at the same funct3/funct7 encoding executes PABD.B semantics instead of its intended operation, and vice versa.
Consequence: data_corruption
Pattern: PABD\.B|pabd\.b|OP_IMM_32.*pabd|0x1B.*pabd|0011011.*packed|case 0x1b:.*PABD|OP32.*PABD|decode.*pabd
