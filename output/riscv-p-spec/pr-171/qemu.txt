PR #171  target=qemu  overall=not_implemented
Spec: P-ext Load Immediate instructions use OP-IMM-32 encoding with non-standard split immediate fields and RV32 register-pair destinations guarded by rd_p!=0 checks — TCG decode errors can corrupt x0/x1 register invariants or load wrong immediates
Violation:
  QEMU TCG decoder for PLI.DB/PLI.DH/PLUI.DH (RV32 register-pair variants)
  fails to enforce the 'if (rd_p != 0)' guard when rd_p=0, causing writes to
  x0 (breaking the architectural zero-register invariant) and to x1
  (corrupting the return-address register), or the 4-bit rd_p field is
  incorrectly decoded causing writes to wrong register pairs
Consequence: data_corruption
Pattern:
  rd_p == 0 check missing OR rd_p field width != 4 bits OR XLEN gate missing
  for RV64-only PLI.W/PLUI.W OR non-contiguous immediate bit extraction
  (imm[8:0|9], imm[6|15:7], imm[22|31:23])
