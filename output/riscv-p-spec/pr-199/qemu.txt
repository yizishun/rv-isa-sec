PR #199  target=qemu  overall=compliant
Spec: WMACC/WMACCU are RV32-only but reuse OP-IMM-32 opcode space owned by RV64 ADDIW-family; missing XLEN gating in QEMU TCG decode causes instruction confusion between widening MAC and 32-bit integer ops, corrupting guest register state and enabling guest-to-host escape via wrong-code execution
Violation: QEMU TCG translates WMACC/WMACCU on RV64 without enforcing XLEN==32 check (REQUIRE_32BIT), causing OP-IMM-32 opcode collision with RV64 ADDIW/SLLIW/SRLIW/SRAIW — an illegal instruction on RV64 per spec is executed as a valid widening multiply-accumulate, or vice versa, producing wrong register state
Consequence: function_loss
Pattern: trans_wmacc.*\.c.*gen_illegal|decode_wmacc.*insn32\.decode.*RV32|OP-IMM-32.*wmacc|REQUIRE_32BIT.*wmacc|get_xl.*MXL_RV32.*wmacc
------------------------------------------------------------
