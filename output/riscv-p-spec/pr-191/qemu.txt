PR #191  target=qemu  overall=not_implemented
Spec: Narrowing Clip instructions require variant-specific sign-extension widths (48/64/128-bit) and shift-amount bit-widths (4/5/6-bit); a generic TCG helper reusing a single width across variants would produce incorrect saturation and wrong rd/vxsat values
Violation:
  QEMU TCG translator uses incorrect sign-extension width for a Narrowing Clip
  instruction variant (e.g., sign_extend(64, ...) instead of sign_extend(48,
  ...) for PNCLIP.BS byte narrowing, or sign_extend(128, ...) instead of
  sign_extend(64, ...) for halfword narrowing variants). The spec requires
  distinct extension widths per element size: 48-bit for byte narrowing with
  scalar shift, 64-bit for halfword narrowing, and 128-bit for word (XLEN-
  wide) narrowing. If the translator reuses a generic helper with a fixed
  extension width, the arithmetic right shift produces incorrect saturation
  decisions — a value near the clip boundary could be misclassified as in-
  range or saturated, producing wrong output in rd and incorrect vxsat sticky
  flag state. Additionally, the shift-amount bit-width varies per variant
  (4-bit imm for byte, 5-bit for halfword, 6-bit for word narrowing); masking
  the wrong number of bits from the shift operand changes which bits
  participate, altering the shift amount and producing entirely different
  results.
Consequence: data_corruption
Pattern:
  sign_extend\((48|64|128),.*PNCLIP|NCLIP.*translator|gen_helper.*nclip|narrow
  ing.*clip.*extend|p-ext.*clip.*shift
------------------------------------------------------------
[not_implemented] target/riscv/:0-0  N/A
  The P-extension (packed SIMD, Zpn/Zpng) including Narrowing Clip
  instructions (PNCLIP.BS, PNCLIP.HS, PNCLIP.WS, and their unsigned variants)
  is not implemented in QEMU's RISC-V target. No decode entries, translator
  functions, helper definitions, or TCG code exists for any P-extension packed
  SIMD instructions. The only 'clip' instructions present are the V-extension
  vector narrowing clip (vnclip*) in insn32.decode and vector_helper.c — these
  are distinct from the P-extension scalar packed SIMD narrowing clip
  instructions described in the security spec.
  | N/A — no P-extension code exists in QEMU target/riscv/
