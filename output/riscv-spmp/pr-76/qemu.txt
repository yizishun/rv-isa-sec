PR #76  target=qemu  overall=compliant
Spec: PR widens spmpcfg from 16-bit to SXLEN-bit; if QEMU SPMP implementation uses <SXLEN internal storage, sireg2 indirect reads leak uninitialized host memory in upper bits
Violation:
  QEMU implements spmpcfg[i] internal storage as a 16-bit (or two packed
  8-bit) field, but the indirect CSR read path via siselect/sireg2 returns a
  full SXLEN-bit value where the upper SXLEN−16 bits are uninitialized
  stack/heap memory from the QEMU host process, leaking host state to the
  guest
Consequence: info_leak
Pattern:
  spmpcfg stored as uint16_t or uint8_t[2] in pmp_table_t/pmp_entry_t while
  sireg2 read path copies sizeof(target_ulong) bytes from that truncated
  storage — search for 'spmpcfg' combined with 'cfg_reg' typed narrower than
  target_ulong, or cfg read paths returning zero-extended but not explicitly
  zeroed upper XLEN-16 bits
