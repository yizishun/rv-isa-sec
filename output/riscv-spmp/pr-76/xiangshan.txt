PR #76  target=xiangshan  overall=compliant
Spec: spmpcfg[i] widened from 16-bit field to SXLEN-bit register; hardware must allocate SXLEN-width storage with WPRI on bits [SXLEN-1:10] or risk info leak through unsanitized upper bits on sireg2 reads
Violation:
  When spmpcfg registers are implemented as 16-bit storage elements (per the
  pre-change spec) but the indirect CSR access via sireg2 reads/writes at
  SXLEN width, the upper SXLEN-16 bits are not preserved on write (WPRI
  violation) and expose uninitialized register-file or internal bus state on
  read, because the hardware fails to allocate full SXLEN-width register
  storage for each spmpcfg[i] entry.
Consequence: info_leak
Pattern:
  spmpcfg.*(?:UInt\(16\.W\)|Wire\(15,0\)|\[15:0\])|sireg2.*spmpcfg|indirect.*s
  pmp.*cfg.{0,50}(?:16|Bits\(15)
