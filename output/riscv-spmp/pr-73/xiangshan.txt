PR #73  target=xiangshan  overall=compliant
Spec: Removal of the miselect bypass for locked SPMP entries means M-mode must not be able to silently unlock/modify S-mode-locked SPMP rules; any remaining miselect write path to locked spmpcfg/spmpaddr in RTL constitutes a hardware privilege escape
Violation:
  The spec now removes the sentence 'Modifications to locked spmpcfg[i] and
  spmpaddr[i] registers are only permitted through execution environment
  access via miselect.' If XiangShan RTL still implements a write path via
  miselect (or any other M-mode CSR access mechanism) that bypasses the L-bit
  lock on SPMP entries, the hardware allows modification of locked entries
  that should be immutable—violating the revised specification that no longer
  carves out a miselect bypass.
Consequence: privilege_escape
Pattern:
  mis.*lect.*spmp|miselect.*write.*spmpcfg|miselect.*spmpaddr|spmp.*lock.*bypa
  ss|spmpcfg_i_lock.*ignore|L_bit.*miselect
