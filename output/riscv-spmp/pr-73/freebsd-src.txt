PR #73  target=freebsd-src  overall=compliant
Spec: SPMP lock semantics weakened (M-mode miselect override removed) and SHARED=1/U=0 reserved encoding could cause privilege escalation if FreeBSD programs it expecting shared-region behavior
Violation:
  FreeBSD kernel (S-mode) writes spmpcfg[i] with SHARED=1 and U=0, which is
  now explicitly reserved; hardware behavior is undefined and may silently
  grant unintended access permissions to U-mode, or kernel relies on M-mode
  miselect to override L-bit-locked SPMP entries after warm reset but spec no
  longer guarantees this capability
Consequence: privilege_escape
Pattern:
  spmpcfg\[.*\].*SHARED|spmpcfg\[.*\].*_BIT.*SHARED|SPMPCFG_.*SHARED|miselect.
  *spmp|locked.*SPMP
