PR #224  target=xiangshan  overall=compliant
Spec: RRIDSCP.stat must be dynamically computed from live rrid_stall[] on every read, not stored as a write-time-snapshotted register; stale stat leads to TOCTOU race where software operates on incorrect stall state
Violation: When XiangShan implements RRIDSCP (imp_rridscp=1) but stores RRIDSCP.stat as a write-time-snapshotted register field instead of dynamically computing it on every read from the live rrid_stall[] array state, the read path returns a stale stat value that does not reflect the current stall state of the selected RRID. The spec diff changes stat computation from write-time update to read-time dynamic evaluation: stat = RRIDSCP_STAT_RRID_NOT_STALLED - rrid_stall[rrid]. An RTL implementation that still snapshots stat during write (the old behavior preserved in the RegRridscp Bundle definition at line 581-593 which treats stat as a register field alongside op/rrid) would violate this new read-time evaluation requirement.
Consequence: race_condition
Pattern: reg_rridscp.stat := .*when.*write|rridscp.*stat.*RegInit|rridscp_stat
