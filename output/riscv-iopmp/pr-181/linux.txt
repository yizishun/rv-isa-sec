PR #181  target=linux  overall=compliant
Spec: HWCFG3.xinr=1 collapses instruction-fetch into data-read permission, so a kernel IOPMP driver setting r=1/x=0 silently grants execute access to DMA-capable peripherals on data-only buses.
Violation: In the Linux kernel, when an IOPMP driver writes ENTRY_CFG with r=1 (data read only) on hardware where HWCFG3.xinr=1, the driver assumes x permission is independently denied, but the hardware merges instruction-fetch into data-read — effectively granting r+x access to DMA initiators without the kernel's awareness.
Consequence: privilege_escape
Pattern: IOPMP ENTRY_CFG write path that sets r permission bits without first reading HWCFG3.xinr to determine whether x bits are independently enforced; also any code that assumes SRCMD_X/SRCMD_XH are writable and meaningful when xinr=1
