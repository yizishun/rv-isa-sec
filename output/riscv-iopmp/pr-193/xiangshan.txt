PR #193  target=xiangshan  overall=bug_confirmed
Spec: PR adds write-gating: err_cfg.stall_violation_en must only accept writes when hwcfg2.stall_en=1; hardware that lacks this gate allows software to inject spurious transaction faults via misconfigured stall_violation_en when stalling is globally disabled.
Violation:
  In XiangShan RTL, the err_cfg.stall_violation_en CSR field is
  unconditionally writable regardless of hwcfg2.stall_en. Software writes to
  stall_violation_en when stall_en=0 are accepted and take effect, creating a
  state where IOPMP faults transactions for 'stalled transaction' violations
  even though the stall mechanism is globally disabled and no transactions are
  actually stalled.
Consequence: denial_of_service
Pattern:
  stall_violation_en.*write|err_cfg.*stall|hwcfg2.stall_en.*gate|when.*stall_e
  n.*else|stall_violation_en.*:=|stallViolationEn.*writeEnable
------------------------------------------------------------
