PR #229  target=qemu  overall=compliant
Spec: Spec declares undefined behavior when stall_violation_en is modified during IOPMP programming Steps 1-3; QEMU must either serialize such writes against the programming sequence or trap them as illegal to prevent a guest from exploiting the race to bypass IOPMP stall enforcement on DMA transactions.
Violation: In QEMU TCG, when one vCPU writes to ERR_CFG.stall_violation_en while another vCPU is concurrently executing IOPMP programming Steps 1-3 (writing MDSTALL/RRIDSCP followed by entry/MD updates), the emulation enters spec-defined undefined behavior because QEMU does not serialize the stall_violation_en CSR write against the multi-step programming sequence. This can leave the emulated IOPMP in an inconsistent state where stall/fault decisions for in-flight DMA transactions are non-deterministic.
Consequence: privilege_escape
Pattern: stall_violation_en written without checking or serializing against concurrent MDSTALL/RRIDSCP programming steps; missing cross-vCPU synchronization around ERR_CFG writes during IOPMP rule updates
