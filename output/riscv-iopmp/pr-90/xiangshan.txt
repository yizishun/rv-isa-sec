PR #90  target=xiangshan  overall=compliant
Spec: MDLCKH.mdh in XiangShan RTL is 31 bits (UInt(31.W)) per the old spec, but the corrected spec requires 32 bits to lock MD 31-62; once implemented, MD 62 would be permanently unlockable, allowing unauthorized modification of its source memory domain table entries.
Violation:
  In XiangShan RTL (IopmpChecker.scala, line 602), the `RegMdlckh` Bundle
  defines `mdh` as `UInt(31.W)`, matching the old incorrect spec. After this
  PR fixes the reference model to 32 bits, the XiangShan hardware register
  instantiation (once uncommented from the `/* not implemented */` block)
  would only expose 31 lock bits for MD 31-61, leaving the highest-order lock
  bit for MD 62 physically absent in silicon. Any write to bit 31 of the
  MDLCKH CSR would be silently truncated, and MD 62's memory domain table
  entries would be perpetually unlockable.
Consequence: privilege_escape
Pattern:
  RegMdlckh.*UInt\(31\.W\)|mdh.*Bits\(31\)|MDLCKH.*bit.*width.*31|mdlckh.*fiel
  d.*31
