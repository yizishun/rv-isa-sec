PR #199  target=xiangshan  overall=bug_confirmed
Spec: XiangShan Ctrl FSM captures ERR_INFO on all violations regardless of interrupt/bus-error suppression state, consuming the first-error slot for suppressed events and preventing subsequent unsuppressed violations from being recorded — the io.rs path ignores per-entry error suppression entirely
Violation: In the XiangShan IOPMP Ctrl FSM (IopmpChecker.scala:1144-1155), the sErr state unconditionally sets io.reg.i_errinfo_v := !io.reg.o_reg_errinfo_v upon every permission-violation detection, without evaluating whether an interrupt will actually be generated or a bus error will actually be returned. The spec (PR #199 correction) requires first_record = (gen_intrpt || gen_buserr) && !err_reqinfo_v — meaning error capture must only occur when either an interrupt is triggered OR a bus error is returned. The XiangShan RTL captures errors even when both interrupt and bus error are suppressed (e.g., global ERR_CFG.rs=1 AND per-entry sire/siwe=1), consuming the first-error slot (ERR_INFO.v) for a suppressed event. Additionally, the interrupt generation logic at lines 1308-1318 uses entry_attribute.sire/siwe directly without gating through HWCFG0.peis — per-entry interrupt suppression is applied even when PEIS is disabled. The IO response suppression at line 1324 (io.rs := io.reg.o_reg_errcfg_rs.asBool) implements only global suppression with no per-entry error suppression (sere/sewe/sexe) contribution, meaning per-entry bus-error suppression is completely unimplemented in the Ctrl FSM.
Consequence: function_loss
Pattern: unconditional errinfo_v capture in sErr state without gen_intrpt||gen_buserr guard; missing hwcfg2.peis/pees gating on per-entry suppression signals; io.rs driven solely from global errcfg_rs without per-entry sere/sewe/sexe OR-reduction

[bug_confirmed] ChiselIOPMP/src/main/scala/IopmpChecker.scala:1323-1324  Ctrl (bus error response suppression)
  Per-entry bus error response suppression (sere/sewe/sexe) is completely unimplemented. io.rs is driven solely from the global ERR_CFG.rs bit: `io.rs := io.reg.o_reg_errcfg_rs.asBool`. The EntryAttribute bundle defines sere/sewe/sexe fields (lines 350-352), and the EntryTable exposes them (line 360), and pri_hit captures them into entry_attribute (line 1272), but they are never used in the error response path. The spec requires that per-entry suppression (sere for reads, sewe for writes) should cause io.rs to be asserted when the matching entry has suppression enabled, but this OR-reduction from per-entry bits is entirely absent. Software that configures per-entry error suppression expects those transactions to be silently dropped, but they will still generate bus errors.
