PR #155  target=xiangshan  overall=compliant
Spec: HWCFG0 HWCFG2_en/HWCFG3_en reclassified from W1SS to R — stale W1SS hardware allows software to forge feature-enable capability flags, tricking firmware into relying on absent IOPMP hardware enforcement features
Violation: XiangShan RTL implements HWCFG2_en (bit 1) or HWCFG3_en (bit 2) in the HWCFG0 CSR as W1SS (write-1-set-sticky) instead of R (read-only, implementation-defined), allowing software to write 1 to these bits and cause the hardware to report HWCFG2/HWCFG3 as available when the extension hardware is not actually implemented — software then configures non-priority entries or HWCFG3-dependent features that the IOPMP checker cannot enforce
Consequence: privilege_escape
Pattern: HWCFG0.*enable.*W1SS|reg_hwcfg0.*enable.*\|.*w\.enable|sticky.*HWCFG[23]_en
