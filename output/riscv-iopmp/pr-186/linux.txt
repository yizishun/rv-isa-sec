PR #186  target=linux  overall=compliant
Spec: Kernel IOPMP driver must gate all error-record register access on HWCFG0.no_err_rec==0, else fabricated error data from wired fields (eid=0xffff, v=0) may be consumed as real hardware error reports.
Violation: Linux IOPMP driver reads ERR_INFO/ERR_REQADDR/ERR_REQID/ERR_USER registers and acts on their contents (e.g., logging errors, triggering recovery) without first checking HWCFG0.no_err_rec, causing it to consume wired-zero/garbage values from a non-existent error record as if they were real error events.
Consequence: info_leak
Pattern: ERR_INFO|ERR_REQADDR|ERR_REQID|ERR_USER.*ioread|readl|readq(?!.*no_err_rec|.*HWCFG0)
