PR #92  target=qemu  overall=compliant
Spec: Missing MDCFG monotonicity enforcement and auto-correction on write allows guest to program non-monotonic memory domain boundaries, breaking IOPMP isolation and permitting DMA to bypass I/O PMP memory access controls
Violation: QEMU IOPMP emulation accepts non-monotonically-incremental MDCFG table entries without enforcing MDCFG(m).t >= MDCFG(m-1).t for all m >= 1, or fails to auto-correct violating entries by clamping MDCFG(m).t to MDCFG(m-1).t on write, causing guest-read-back of MDCFG to reflect uncorrected values inconsistent with hardware behavior
Consequence: privilege_escape
Pattern: IOPMP MDCFG table write without monotonic-enforcement loop: for m=1..MD_NUM-1 if mdcfg[m].t < mdcfg[m-1].t then mdcfg[m].t = mdcfg[m-1].t
