PR #6  target=qemu  overall=compliant
Spec: QEMU must reject IME instructions when vlmul encodes fractional LMUL (MF2/MF4/MF8) by raising illegal-instruction, otherwise guest executes reserved behavior producing undefined matrix results
Violation: QEMU TCG translates or executes any Integrated Matrix Extension instruction when the current vtype.vlmul CSR field encodes a fractional LMUL setting (MF2=0b001, MF4=0b010, MF8=0b011) without raising an illegal-instruction exception. This occurs in the per-instruction decode or translate phase where vtype.vlmul is not validated against the allowed set {1,2,4,8} for IME opcodes.
Consequence: data_corruption
Pattern: target/riscv/insn_trans/trans_integrated_matrix.c.inc: translate-time or helper-time check missing for vlmul ∈ {MF2,MF4,MF8} before IME instruction execution; any path where require_vector(true) passes but require_vlmul_integral() or equivalent inline check is absent for matrix opcodes
