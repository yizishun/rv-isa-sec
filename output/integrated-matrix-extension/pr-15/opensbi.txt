PR #15  target=opensbi  overall=compliant
Spec: OpenSBI must preserve IME vtype fields (lambda, altfmt_A/B, bs) and frm across traps; spec now mandates frm-directed rounding for intermediate accumulations instead of implementation-defined rounding, so any frm clobber by M-mode silently corrupts S-mode IME floating-point results.
Violation: OpenSBI trap handler or SBI call implementation performs read-modify-write on the vtype CSR (e.g., to set vsew or vlmul for internal vector save/restore) without preserving the IME-specific bit fields—lambda[7:5], altfmt_A[9], altfmt_B[10], and bs[11]—that the S-mode workload had configured for in-flight matrix tile operations.
Consequence: data_corruption
Pattern: csrrs|csrrc|csrrw.*vtype|CSR_(R|W|RW).*VTYPE|vtype.*&=|vtype.*\|=|SBI_VTYPE
------------------------------------------------------------
