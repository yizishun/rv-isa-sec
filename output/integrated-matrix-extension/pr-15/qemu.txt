PR #15  target=qemu  overall=compliant
Spec: IME tile load/store must gate memory access on element-active check BEFORE the TLB/physical access, not after — otherwise inactive/tail element page faults become an observable side channel violating the 'never raise exceptions' guard
Violation: In QEMU TCG, the helper function for an IME tile load/store instruction (vmtl.v, vmttl.v, vmtts.v) performs the virtual-memory access for an element before checking whether the element is inactive (mask bit = 0) or is a tail element (index >= VL). If the access faults (page fault, PMP violation, access fault), QEMU raises an exception that the guest can observe, leaking information about the physical memory map or host state through the exception side channel, despite the spec requiring that inactive and tail elements 'never raise exceptions' and 'do not update the destination register'.
Consequence: info_leak
Pattern: vext_ldst_tile.*\(.*env.*vstart.*vl.*vm.*\).*\{[^}]*ld[ubhw]_tlb[^}]*\}[^}]*if.*vext_set_elem_mask|if.*!vext_elem_mask.*\{[^}]*exception|helper.*vmtl.*\(.*\).*cpu_ld.*before.*vext_check_elem|// BUG: inactive/tail exception check ordered after memory access
