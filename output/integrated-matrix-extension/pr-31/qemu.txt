PR #31  target=qemu  overall=compliant
Spec: GEMM instructions require vstart=0 on entry (tile computation has no linear resume index); QEMU TCG must enforce this in the translator guard (s->vstart_eq_zero) or helper-preamble to avoid architecturally-wrong partial-tile results and guest-to-spec divergence
Violation: QEMU TCG translator for any GEMM instruction (vmmacc.vv, vwmmacc.vv, vqwmmacc.vv, v8wmmacc.vv, vfmmacc.vv, vfwmmacc.vv, vfqwmmacc.vv, vf8wmmacc.vv, vfwimmacc.vv, vfqwimmacc.vv, vf8wimmacc.vv) executes without checking that vstart == 0 — either the insn_trans function omits s->vstart_eq_zero from its guard condition, or the helper function proceeds with computation when cpu_vstart != 0 without raising Illegal_Instruction. Since GEMM instructions operate on 2D tiles with no linear element index for resume, QEMU's software implementation could incorrectly resume mid-tile, producing architecturally-wrong accumulator state that matches neither the pre-interrupt partial result nor a clean restart.
Consequence: data_corruption
Pattern: trans_vmmacc|trans_vwmmacc|trans_vqwmmacc|trans_v8wmmacc|trans_vfmmacc|trans_vfwmmacc|trans_vfqwmmacc|trans_vf8wmmacc|trans_vfwimmacc|trans_vfqwimmacc|trans_vf8wimmacc WITHOUT s->vstart_eq_zero in the require_rvv/vext_check guard, OR helper_vmmacc WITHOUT an early vstart != 0 → Illegal_Instruction check before any tile geometry decode or accumulator write
------------------------------------------------------------
[compliant] target/riscv/insn_trans/trans_rvv.c.inc:0-0  (none — GEMM translators not implemented)
  No GEMM instruction (vmmacc.vv, vwmmacc.vv, vqwmmacc.vv, v8wmmacc.vv, vfmmacc.vv, vfwmmacc.vv, vfqwmmacc.vv, vf8wmmacc.vv, vfwimmacc.vv, vfqwimmacc.vv, vf8wimmacc.vv) is currently implemented in QEMU. The insn32.decode file contains no decode patterns for any of these 11 instructions, insn_trans/trans_rvv.c.inc has no trans_* functions for them, and vector_helper.c has no helper_* functions. Since no execution path exists, the vstart != 0 → Illegal_Instruction requirement from the spec is not yet applicable. However, when these instructions are implemented, the translator guard must include s->vstart_eq_zero in the require_rvv/vext_check condition, and each helper must raise Illegal_Instruction before any tile geometry decode or accumulator write when cpu_vstart != 0.
  | (no code — GEMM instructions are not implemented in QEMU)
