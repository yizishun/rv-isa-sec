PR #21  target=xiangshan  overall=compliant
Spec: Splitting Zvvmtls into order-preserving (Zvvmtls) and transposing (Zvvmttls) sub-extensions means the decoder must check two independent extension bits; a single-bit check allows vmttl.v/vmtts.v to execute without Zvvmttls being implemented, enabling unauthorized transposed memory access patterns that bypass the intended ISA feature gate.
Violation: When XiangShan implements Zvvmtls but not Zvvmttls, the instruction decoder fails to trap vmttl.v/vmtts.v as illegal instructions because the decoder still maps these opcodes under the old Zvvmtls group. Conversely, if the decoder uses a single extension-check bit for both Zvvmtls and Zvvmttls, transposing tile loads/stores execute without the Zvvmttls extension being present, or order-preserving loads/stores incorrectly trap when only Zvvmttls is implemented.
Consequence: privilege_escape
Pattern: decoder.*(vmttl|vmtts).*extCheck|extension.*check.*(Zvvmtls|Zvvmttls)|illegalInstruction.*Zvvmttls|TileLoadStore.*decoder|lambda.*override.*vtype.*[23]:0
