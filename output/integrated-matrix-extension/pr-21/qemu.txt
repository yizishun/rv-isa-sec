PR #21  target=qemu  overall=compliant
Spec: Incorrect TCG translation of Zvvmttls transposing tile load/store memory access pattern (row/col index decomposition from lambda/LMUL, or failure to honor immediate Lλ override) causes guest data corruption through misrouted matrix element transfers between memory and vector register file.
Violation: When QEMU TCG translates vmttl.v/vmtts.v instructions and incorrectly computes the transposed memory access pattern—specifically miscalculating row/column decomposition from the linear element index using lambda and LMUL (row = (i/λ) % LMUL, col = i % λ), or failing to apply the immediate Lλ override that temporarily replaces vtype.vlambda for address calculation—causing memory reads/writes to wrong guest addresses or wrong register file lanes, including access beyond the intended matrix tile bounds.
Consequence: data_corruption
Pattern: trans_tile_ld|trans_tile_st|vmttl|vmtts|gen_vmttl|gen_vmtts|linesize.*lambda.*LMUL|tile_transpose.*offset|vlambda.*override
------------------------------------------------------------

[bug_confirmed] target/riscv/csr.c:967-975  write_vxrm
  WARL violation: write_vxrm stores val directly into env->vxrm without applying a bitmask. vxrm has exactly 2 bits (values 0=rne, 1=rtz, 2=rdn, 3=rod), but any arbitrary target_ulong can be written. An illegal rounding mode stored this way is read back verbatim by read_vxrm (csr.c:963) and dispatched by all vector fixed-point instructions.
