PR #28  target=xiangshan  overall=potential_risk
Spec: G WARL enforcement depends on dynamic W parameter; incorrect bounds-check hardware enables register file out-of-bounds access via oversized matrix group configuration
Violation: G (matrix group size) is a WARL field whose legal encoding depends on the dynamically-variable parameter W, but cannot reside in vtype. If XiangShan implements G as a hardcoded constant or as a static vtype subfield without runtime recomputation of legal-G bounds upon W changes, software can configure a matrix group exceeding the physical vector register file, causing the matrix engine to index vector registers beyond architectural limits—reading stale register state or corrupting unrelated architectural state.
Consequence: data_corruption
Pattern: WARL.*G|legalG|MatrixGroupSize|matrixGroup|vtype.*group|vreg.*matrix.*index|matrix.*stride|matrix.*regfile|G_.*WARL|enforce.*group.*size
