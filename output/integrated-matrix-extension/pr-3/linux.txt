PR #3  target=linux  overall=compliant
Spec: IME floating-point instructions produce implementation-defined fflags encoding microarchitectural grouping factor G, leaked through kernel fcsr save/restore across security boundaries
Violation: Kernel context-switch and KVM vCPU save/restore paths preserve fflags/fcsr without sanitization, transparently propagating implementation-defined fflags values produced by IME floating-point matrix multiply-accumulate instructions (vfmmacc.vv, vfwmmacc.vv, vfqwmmacc.vv). The intermediate grouping factor G and rounding order within a single instruction are implementation-defined and not governed by frm, so the resulting fflags bit pattern encodes the host microarchitecture's internal accumulation grouping. A userspace process or guest VM can probe fflags after IME instructions to fingerprint the host microarchitecture, distinguishing CPU implementations or cores in a heterogeneous system.
Consequence: info_leak
Pattern: fcsr|fflags|__riscv_v_state_save|__riscv_v_state_restore|kvm_riscv_vcpu_fp
