PR #2  target=qemu  overall=compliant
Spec: CMUL register-group alignment not validated: unaligned C accumulator start index causes cross-group register access, leaking or corrupting adjacent vector register state across guest security domains
Violation: QEMU executes an Integrated Matrix instruction (e.g., vmadd) with a C register group start index (vs2 or vd) that is not CMUL-aligned, where CMUL = VLENE / λ². The emulation accesses vector registers at misaligned offsets, reading from or writing to registers outside the intended C accumulator group, crossing register group boundaries.
Consequence: info_leak
Pattern: cmul_alignment_check|lambda.*register.*group|vtype_lambda|integrated.*matrix.*vs2|vd.*alignment.*CMUL
