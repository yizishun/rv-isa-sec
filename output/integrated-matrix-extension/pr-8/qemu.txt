PR #8  target=qemu  overall=compliant
Spec: Incorrect nibble-order extraction of 4-bit input elements in widening matrix MAC TCG implementation causes silent data corruption via swapped element pairs in sub-dot-product accumulation
Violation: QEMU TCG implements integrated-matrix widening multiply-accumulate instructions (W=2 or W=4) with EEW=4 inputs but incorrectly extracts sub-byte elements using big-endian nibble order (even-indexed element in upper nibble [7:4], odd-indexed in lower nibble [3:0]) instead of the spec-mandated little-endian nibble packing where element 2n occupies bits [3:0] and element 2n+1 occupies bits [7:4] of byte n
Consequence: data_corruption
Pattern: TCG helper or translator for integrated-matrix widening MAC where EEW=4 element extraction uses shift amounts or bit masks inconsistent with bits[4k+3:4k] little-endian nibble ordering; specifically, extracting even-indexed elements from (byte >> 4) instead of (byte & 0xF), or odd-indexed from (byte & 0xF) instead of (byte >> 4)
