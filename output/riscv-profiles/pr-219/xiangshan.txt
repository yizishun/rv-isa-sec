PR #219  target=xiangshan  overall=compliant
Spec: Incorrect stval write for breakpoint exceptions: stale pipeline address leaked for trigger types that lack a defined stval address, or correct address suppressed for address-match triggers
Violation: The trigger/exception module writes a stale or uninitialized pipeline address to stval for breakpoint exception types (e.g., icount, itrigger, etrigger) that are not defined to produce an associated virtual address, or conversely, fails to write the correct faulting virtual address for breakpoint triggers that are defined to do so (e.g., mcontrol address-match breakpoints).
Consequence: info_leak
Pattern: when (breakpoint_exception) stval := MuxLookup(trigger_type, default_addr)(trigger_addr, icount_pc, ...) OR stval write-enable missing a trigger_type qualifier, leaking pipeline-internal addresses for trigger types without a defined stval address
