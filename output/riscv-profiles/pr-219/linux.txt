PR #219  target=linux  overall=compliant
Spec: Sstvala no longer guarantees stval contains a valid address for all non-EBREAK breakpoints; kernel must continue using epc (not stval) as si_addr for SIGTRAP delivery and must not forward stval to KVM guests on EXC_BREAKPOINT
Violation:
  Kernel or KVM code reads stval (pt_regs->badaddr) for a breakpoint exception
  (scause=3) and dereferences or forwards it as a valid address (e.g., into
  si_addr, vstval, htval, or a page table walk), when the breakpoint trigger
  type is not defined by the ISA to write an address to stval (e.g., an Sdtrig
  trigger configured for data-without-value match, or an implementation that
  zeroes stval on non-EBREAK breakpoints).
Consequence: info_leak
Pattern:
  scause.*BREAKPOINT|EXC_BREAKPOINT.*badaddr|EXC_BREAKPOINT.*stval|breakpoint.
  *force_sig_fault|breakpoint.*si_addr
