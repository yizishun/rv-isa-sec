PR #137  target=opensbi  overall=compliant
Spec: sbi_covg_get_device_measurements permits repeated calls for latest device measurements; OpenSBI must re-fetch (not cache) measurement transcripts to prevent stale attestation data from being served to TVMs
Violation: OpenSBI caches device measurement transcript data from a previous sbi_covg_get_device_measurements call and returns stale cached data on a subsequent call, instead of re-fetching the latest measurement from the TSM or device. Since the spec now explicitly allows multiple calls to obtain updated measurements, cached data violates the freshness guarantee.
Consequence: info_leak
Pattern: cache.*measurement|measurement.*cache|sbi_covg.*cache|transcript.*cache|coherent.*invalid|device_meas.*copy|meas.*stale
