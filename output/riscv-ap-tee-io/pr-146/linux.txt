PR #146  target=linux  overall=potential_risk
Spec: Smmtt-enforced supervisor domain isolation means the kernel must never assume full physical address space access; any kernel-initiated physical access outside its RDSM-assigned domain is a hardware-level privilege boundary violation that Smmtt will trap
Violation: Linux kernel S-mode code (or HS-mode KVM host) performs a direct physical memory access, DMA mapping, or /dev/mem read/write to a physical address range that has been excluded from the kernel's supervisor domain by the RDSM-configured Smmtt hardware enforcement, either because the kernel is unaware of domain boundaries or does not consult the domain permission table before issuing the access
Consequence: privilege_escape
Pattern: phys_addr_t|__pa\(|virt_to_phys|dma_map_single|dma_alloc_coherent|ioremap|memremap|devmem_is_allowed|read_phys|write_phys
------------------------------------------------------------
