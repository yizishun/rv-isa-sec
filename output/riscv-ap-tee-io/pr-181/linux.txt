PR #181  target=linux  overall=compliant
Spec: CoVE-IO SBI address _lo/_hi split mandates _hi==0 on RV64; non-zero _hi in MMIO-map or IDE-key calls lets a buggy kernel driver redirect TSM-programmed IOMMU page tables to host memory, breaking TVM confidentiality
Violation: Linux kernel CoVE host driver passes a non-zero _hi address parameter to any CoVE-IO SBI function on RV64, violating the spec mandate that _hi must be zero on RV64; the TSM may compute a combined physical address with spurious high bits, redirecting IOMMU mappings, DMA descriptors, or IDE key material to unintended physical pages
Consequence: privilege_escape
Pattern: _addr_hi\s*=|_hi\s*=\s*[^0]|sbi_cov[ght]_\w+\(
