PR #181  target=linux  overall=compliant
Spec: Unvalidated _hi address parameters on RV64 permit crafted physical addresses to redirect TSM memory accesses outside intended regions, enabling data corruption or information leak through the TSM
Violation: On RV64, the kernel (as host supervisor or TVM manager) passes a non-zero _hi address parameter to any CoVE-IO SBI function whose spec now mandates _hi must be zero on RV64. The TSM may interpret a non-zero _hi as the upper bits of a wider physical address, causing it to read/write memory outside the intended region.
Consequence: data_corruption
Pattern: unsigned long \w+_addr_hi(?!.*== 0|.*!= 0|.*\bif\b.*_hi)
