PR #133  target=linux  overall=compliant
Spec: Untrusted host kernel controls shared memory pages used for device connection transcript exchange between TSM and TVM; without kernel-side enforcement that transcript data is consumed atomically with TSM digest verification, the host can tamper with device identity/measurement data to trick a TVM into accepting a compromised or impersonated device into its TCB
Violation: The host kernel (acting as untrusted domain manager) modifies the shared memory at connection_data_addr_out or transcript_data_addr_out between the TSM's write and the TVM's consumption, or the kernel supplies a tampered/replayed transcript via sbi_covh_get_device_connection_transcript() that the TSM fails to verify against its digest map before returning to the TVM
Consequence: privilege_escape
Pattern: shared memory region passed to SBI CoVE-IO ABI without post-read integrity verification; consumption of device connection transcript data from shared pages without validating against TSM-attested digest; TOCTOU on 4KB-aligned shared buffers between sbi_covh_connect_device/sbi_covh_get_device_connection_transcript and sbi_covg_get_device_connection_transcript
