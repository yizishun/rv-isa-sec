PR #136  target=linux  overall=potential_risk
Spec: COVT SBI extension moves RP IDE key programming from an SPDM-authenticated RoT path to an RDSM-delegated path with no kernel-visible attestation that RP keys are in Programmed state before sbi_covh_connect_device() proceeds, allowing a compromised or buggy TSM/RDSM to complete device connection with missing or unprogrammed RP-side IDE keys, resulting in plaintext PCIe TLP exposure on the link
Violation: The Linux kernel (as Host Supervisor Domain Manager) calls sbi_covh_connect_device() to initiate device connection, but the TSM proceeds into IDE link setup without first ensuring the RDSM has successfully programmed RP IDE keys via COVT sbi_covt_program_rp_ide_key() — a condition the kernel cannot observe or enforce because the COVT extension is TSM-internal and the spec removes the prior precondition that an SPDM session with the upstream root port must be established before device connection
Consequence: info_leak
Pattern: sbi_covh_connect_device|sbi_covt_program_rp_ide_key|sbi_covt_set_go_rp_ide_key
