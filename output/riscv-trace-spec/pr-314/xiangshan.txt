PR #314  target=xiangshan  overall=not_implemented
Spec: trTeInstMode hardcoded to 7 instead of corrected value 6 causes E-Trace encoder to operate in wrong instruction trace mode, corrupting branch prediction and implicit return trace packets
Violation:
  XiangShan's trace encoder hardware hardcodes the trTeInstMode CSR field to
  the old spec value of 7 (binary 111) instead of the corrected value 6
  (binary 110), which encodes a different instruction trace mode that governs
  branch prediction tracing and implicit return detection behavior in the
  encoder FSM
Consequence: data_corruption
Pattern:
  trTeInstMode.*=.*7\.U|\"b111\".*trTeInstMode|TraceEncoder.*InstMode.*7|hardc
  ode.*InstMode.*7
