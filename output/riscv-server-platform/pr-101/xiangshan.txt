PR #101  target=xiangshan  overall=compliant
Spec: Multi-hart XiangShan must either enforce identical architecturally-visible parameters across all harts in an SEE (pre-RVA_050 behavior) or implement hardware-visible compatibility gates that prevent migration of architectural state to a hart whose implementation-defined parameters would cause divergent execution of the migrated thread.
Violation:
  In XiangShan multi-hart RTL within the same supervisor execution environment
  (SEE), if individual harts report or implement divergent architecturally-
  visible parameters (e.g., VLEN via vlenb CSR, cache block size via CBO
  operations, supported extensions via misa, privilege-mode capabilities via
  menvcfg/senvcfg fields) and the hardware permits thread migration between
  these harts without architectural-state compatibility enforcement, execution
  of a migrated thread on a target hart that interprets saved architectural
  state differently (e.g., truncated vector registers, different PMP
  granularity, divergent cache-block size affecting CBO.ZERO range) violates
  the RVA_050 mandate that hart divergences must not interfere with
  architectural state migration and subsequent correct execution.
Consequence: privilege_escape
Pattern:
  cross-hart CSR readback divergence: compare vlenb, misa, menvcfg, senvcfg,
  cboz_block_size, PMP granularity fields across all harts in the same SEE at
  reset and runtime; flag any mismatch where the thread scheduler or context-
  switch path does not reject or translate migrated architectural state
  incompatible with the target hart
