PR #101  target=linux  overall=potential_risk
Spec: Relaxed hart indistinguishability (RVA_040→RVA_050) now permits divergences in UNSPECIFIED/implementation-defined behavior across harts within an SEE, breaking the kernel's fundamental SMP assumption that all harts in a cpumask are ISA-identical for migration and capability caching
Violation:
  When the Linux kernel migrates a task across harts that diverge in ISA-
  UNSPECIFIED or implementation-defined behaviors (e.g., WFI wakeup latency,
  sfence.vma broadcast scope, trap prioritization order, reserved CSR field
  read values, cache-block size) that the kernel implicitly treats as uniform
  across all harts in the cpumask, without hart-specific capability re-
  validation at migration time
Consequence: data_corruption
Pattern:
  riscv_isa_extension_available() or __riscv_isa_extension_available() called
  on boot CPU with result cached globally; per-CPU capability probed once at
  boot and assumed SEE-wide homogeneous; context switch path saving/restoring
  CSRs with UNSPECIFIED/RESERVED fields assuming identical bit-level
  interpretation across harts; KVM vCPU migration without re-validating ISA
  homogeneity of target hart; cpumask_generation without hart-specific feature
  verification
