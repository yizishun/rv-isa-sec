# SpecHunter — RISC-V ISA Security Analysis via Spec PR Monitoring

SpecHunter monitors RISC-V ISA specification PRs as they land, uses LLM agents
to detect semantic changes that introduce attack surface, maps them to concrete
code paths in kernel/firmware/hypervisor implementations, and produces structured
vulnerability reports.

## Workflow

```
RISC-V spec PR merged
        │
        ▼
  fetch_all_prs.sh ──► spec/<repo>/pr-NNNN/ (metadata, diff, comments)
        │
        ▼
  SpecHunter ──► 4-phase LLM pipeline per target (Linux, QEMU, OpenSBI, FreeBSD, XiangShan)
        │             Phase 0: coarse filter → skip irrelevant PRs
        │             Phase 1: CodeSecAgent → vulnerability pattern extraction
        │             Phase 2: FastPath(grep) ∥ SlowPath(semantic search) → code location
        │             Phase 3: AnalyzeAgent → structured security report
        ▼
  output/<repo>/pr-NNNN/<target>.json  (per-target analysis results)
        │
        ▼
  daily-analyze.sh ──► Claude-generated daily report → reports/YYYY-MM-DD.md
        │
        ▼
  CI (daily-report.yml) ──► commits report back to repo
```

## Directory Structure

- `spechunter/` — Core tool: CLI, LLM agent definitions (6 agent types), target pipelines, prompts
- `spechunter.yaml` — Top-level config: targets, model, timeouts, prompt directories
- `spec/` — Collected PR data organized as `<repo>/pr-NNNN/` (diff, metadata, comments, reviews)
- `spec_ref/` — Reference spec repositories as git submodules (used by semantic search agents)
- `output/` — Per-PR/per-target JSON analysis results (consumed by daily report generation)
- `reports/` — Daily human-readable markdown reports generated by LLM
- `scripts/` — Automation: `fetch_all_prs.sh` (data collection), `batch_scan.sh` (parallel scanning with atomic claim markers), `daily-analyze.sh` (report generation)
- `spec-lifecycle.md` — Reference: RISC-V specification development lifecycle and ratification process
- `.github/workflows/daily-report.yml` — CI cron: runs daily scan + report + auto-commit
